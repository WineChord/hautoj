??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：阿正的学期准备

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1540>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行一个整数，代表阿正购物卡中最多的金币数量。

    **核心思路**：享受某个优惠至少要为它单独充值对应门槛金额；按门槛从小到大 充值即可同时享受选中的多项优惠。因此枚举 5 种优惠的 32 个子集， 若门槛总和不超过本金，就用其奖金总和更新最大值。剩余金币并入任意 一次充值，不会减少已经得到的优惠。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(2⁵·5) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long money;
        cin >> money;
        const long long need[5] = {6, 36, 108, 324, 648};
        const long long bonus[5] = {1, 6, 18, 54, 108};
        long long bestBonus = 0;
        for (int mask = 0; mask < (1 << 5); ++mask) {
            long long cost = 0, gain = 0;
            for (int i = 0; i < 5; ++i) {
                if (mask >> i & 1) {
                    cost += need[i];
                    gain += bonus[i];
                }
            }
            if (cost <= money)
                bestBonus = max(bestBonus, gain);
        }
        cout << money + bestBonus << '\n';
        return 0;
    }
    ```
