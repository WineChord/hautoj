??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：迷宫

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1429>){ .problem-source target="_blank" rel="noopener" }

    **题意**：你作为一个迷宫构建师。你的任务就是生成符合要求的迷宫。

    **核心思路**：先把每个要求转换为“该房间右墙是否开放”和“下墙是否开放”的 布尔标记，重复要求不会产生额外影响。逐行输出：房间内部行默认右边 是 |，R 开口改为空格；每行下边默认 ---，W 开口改成三个空格。 外围没有开口由题目保证。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(nm+q) 时间、O(nm) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n, m, q;
        cin >> n >> m >> q;
        vector<bool> openRight(n * m + 1, false), openDown(n * m + 1, false);
        while (q--) {
            int room;
            char dir;
            cin >> room >> dir;
            if (dir == 'R')
                openRight[room] = true;
            else
                openDown[room] = true;
        }
        cout << string(m, '+').substr(0, 0);
        for (int column = 0; column < m; ++column)
            cout << "+---";
        cout << "+\n";
        for (int row = 0; row < n; ++row) {
            cout << '|';
            for (int column = 0; column < m; ++column) {
                int room = row * m + column + 1;
                cout << "   " << (openRight[room] ? ' ' : '|');
            }
            cout << '\n';
            for (int column = 0; column < m; ++column) {
                int room = row * m + column + 1;
                cout << '+' << (openDown[room] ? "   " : "---");
            }
            cout << "+\n";
        }
        return 0;
    }
    ```
