??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：韩信点兵

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1202>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出最小答案，如果无法得出科学的答案，则输出"Wrong count!"

    **核心思路**：人数 x 对 a、b、c 都余 1，等价于 x-1 同时被三数整除，所以 $x=1$+k·lcm(a,b,c)。军队至少 2 人，最小取 $k=1$，即 lcm(a,b,c)+1。若它超过给定上限 n，则没有科学答案。计算最小公倍数 时使用 \_\_int128，避免中间乘法溢出。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(log max(a,b,c)) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    long long gcdll(long long a, long long b) {
        while (b) {
            long long r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    using i128 = __int128_t;
    i128 lcm128(i128 a, i128 b) {
        long long x = (long long)a;
        long long y = (long long)b;
        return a / gcdll(x, y) * b;
    }
    int main() {
        long long a, b, c, limit;
        cin >> a >> b >> c >> limit;
        i128 common = lcm128(lcm128(a, b), c);
        i128 ans = common + 1;
        if (ans > limit)
            cout << "Wrong count!\n";
        else
            cout << (long long)ans << '\n';
        return 0;
    }
    ```
