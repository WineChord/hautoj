    **题目**：小明的午餐难题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1826>){ .problem-source target="_blank" rel="noopener" }

    **题意**：9:00,10:00,11:00,11:55...终于快放学了，伴随着时钟的滴答声，小明的思绪早已飞向餐厅，今天是吃一餐的烤鱼，还是二餐的烤鸡，又或是三餐的牛肉面。。。咕噜~咕噜~饥饿的肚子容不得小明多想，他必须奔向最近的餐厅来拯救他的肚子。学校的四个餐厅距离小明分别为a米、b米、c米、d米、小明的速度是1m/s。那么，小明最少花多长时间才能拯救他的肚子？

    **核心思路**：小明的午餐难题 找到a,b,c,d中的最小值，并将其输出。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：常数级或一次线性读入；以代码中的循环层数为准

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        int a, b, c, d;
        scanf("%d %d %d %d", &a, &b, &c, &d);
        int minnum = a;
        if (minnum > a)
            minnum = a;
        if (minnum > b)
            minnum = b;
        if (minnum > c)
            minnum = c;
        if (minnum > d)
            minnum = d;
        printf("%d", minnum);
        return 0;
    }
    ```
