??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：我们之间没有你插手的余地哦？

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1764>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给出一个长度为n的字符串，该字符串只有英文字母，数字字符以及空格组成，其中，字符'1'表示为一个人，空格表示为“空隙”。现在你要写出一个程序，判断是否有两个人之间存在且只存在空隙。

    **核心思路**：一对合法的“人”必须是两个字符 1，且它们中间至少有一个字符， 中间每个字符都必须是空格。枚举左端的 1，再向右越过连续空格； 若越过至少一个空格后正好遇到另一个 1，就找到了答案。读取整行前 要先处理上一行留下的换行。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：每组 O(n) 时间、O(1) 额外空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            cin.ignore(numeric_limits<streamsize>::max(), '\n');
            string s;
            getline(cin, s);
            bool found = false;
            for (int i = 0; i < n && !found; ++i) {
                if (s[i] != '1')
                    continue;
                int j = i + 1;
                while (j < n && s[j] == ' ')
                    ++j;
                if (j > i + 1 && j < n && s[j] == '1')
                    found = true;
            }
            cout << (found ? "Y" : "N") << '\n';
        }
        return 0;
    }
    ```
