??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：kx的压缩

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1209>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行，压缩码。

    **核心思路**：把 N×N 点阵按题面给出的行优先顺序视作一个长串，依次统计连续 0、连续 1、连续 0…的长度。编码规定第一项总表示 0 的段，因此若输入 一开始就是 1，要先输出长度 0。之后每次字符变化就输出上一段计数， 最后别忘了输出末段。N 本身不属于样例输出的压缩码。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(N²) 时间、O(段数) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        string bitmap;
        cin >> n >> bitmap;
        vector<int> runs;
        char expected = '0';
        int len = 0;
        for (char bit : bitmap) {
            if (bit == expected) {
                ++len;
            } else {
                runs.push_back(len);
                expected = bit;
                len = 1;
            }
        }
        runs.push_back(len);
        for (int i = 0; i < (int)runs.size(); ++i) {
            if (i)
                cout << ' ';
            cout << runs[i];
        }
        cout << '\n';
        return 0;
    }
    ```
