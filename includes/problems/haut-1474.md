    **题目**：cxk的数学难题

    **题意**：cxk的数学难题

    **核心思路**：按 Collatz 规则直接模拟：奇数变为 3n+1，偶数除以 2，每变化 一次计数，直到 n=1。使用 64 位无符号整数覆盖中间值。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(变换次数) 时间、O(1) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        unsigned long long n;
        cin >> n;
        long long steps = 0;
        while (n != 1) {
            if (n & 1ULL)
                n = 3 * n + 1;
            else
                n /= 2;
            ++steps;
        }
        cout << steps << '\n';
        return 0;
    }
    ```
