    **题目**：牛牛的素数判断

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1583>){ .problem-source target="_blank" rel="noopener" }

    **题意**：牛牛最近学会了素数判断，但牛牛的朋友不相信想考考他，便问他：给你两个数a,b，判断a×b是否是素数。

    **核心思路**：牛牛的素数判断//这题数据弱了，有些a×b的也过了(a×b会爆掉)；由于评测姬出了一些问题，时间复杂度也没卡到// 由素数定义可知若a×b为素数则必定其中一个数为1且另一个数必须为素数，因此本题只需判断不为1那个数是否为素数即可。 时间限制为1s的话，如果你在判断素数时从2挨个求余会超时，判断到sqrt(n)即可。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：通常为 O(n)；若循环嵌套或迭代范围不同，应按代码重新核算

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。；检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <math.h>
    int prime(long long x) {
        if (x == 1)
            return 0;
        for (int i = 2; i <= sqrt(x); i++)
            if (x % i == 0)
                return 0;
        return 1;
    }
    int main() {
        int T;
        scanf("%d", &T);
        while (T--) {
            long long a, b;
            scanf("%lld%lld", &a, &b);
            if (a == 1 && prime(b) == 1 || b == 1 && prime(a) == 1)
                printf("YES\n");
            else
                printf("NO\n");
        }
    }
    ```
