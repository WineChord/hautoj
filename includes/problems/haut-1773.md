    **题意**：根据给定输入，输出 c，使得 b 为 a 和 c 的等差中项。

    **核心思路**：由 b=(a+c)/2 移项，直接得到 c=2b-a。范围很小，普通 int 足够。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int a, b;
        cin >> a >> b;
        cout << 2 * b - a << '\n';
        return 0;
    }
    ```
