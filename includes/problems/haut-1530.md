??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：小青的传统艺能

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1530>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，%%%zcs

    **核心思路**：无输入，百分号在 cout 字符串中无需转义，按要求输出三个百分号 和 zcs。

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++17 编译通过；未提供成对公开样例

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << "%%%zcs\n";
        return 0;
    }
    ```
