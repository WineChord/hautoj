    **题目**：Displaced Plant

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1369>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出所有人下楼的最短时间

    **核心思路**：这就是“过桥与手电筒”模型：升降机下楼后必须有人把它送回楼上。 时间已排序。每次把当前最慢的两人送下去有两种最优候选： ①最快两人配合摆渡，代价 a0+2a1+a_last； ②最快者分别陪两名最慢者，代价 2a0+a_prev+a_last。 取较小者并删去最慢两人。剩 1、2、3 人时答案分别为 a0、a1、a0+a1+a2。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<long long> a(n);
        for (long long& x : a)
            cin >> x;
        long long ans = 0;
        int people = n;
        while (people > 3) {
            long long planOne = a[0] + 2 * a[1] + a[people - 1];
            long long planTwo = 2 * a[0] + a[people - 2] + a[people - 1];
            ans += min(planOne, planTwo);
            people -= 2;
        }
        if (people == 3)
            ans += a[0] + a[1] + a[2];
        else if (people == 2)
            ans += a[1];
        else if (people == 1)
            ans += a[0];
        cout << ans << '\n';
        return 0;
    }
    ```
