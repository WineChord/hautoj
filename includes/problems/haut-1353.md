??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：N！

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1353>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组案例占一行，输出n!的第一个非零数和最后一个非零数用空格隔开。

    **核心思路**：首位用对数求：log10(n!)=Σlog10(i)，其小数部分 f 满足首位为 floor(10^f)。末位非零数用缩减乘积：依次乘 i，每步把末尾的 0 全部 除掉，再只保留较低若干位，最后个位就是所求。n≤10000，可以预处理 1..10000 的两个答案，之后每个文件尾询问 O(1) 输出。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：预处理 O(10000)，每个询问 O(1)，空间 O(10000)

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        const int LIMIT = 10000;
        vector<int> firstDigit(LIMIT + 1), lastDigit(LIMIT + 1);
        long double logarithm = 0.0L;
        long long tail = 1;
        for (int n = 1; n <= LIMIT; ++n) {
            logarithm += log10((long double)n);
            long double fractional = logarithm - floor(logarithm);
            firstDigit[n] = (int)(pow((long double)10.0, fractional) + 1e-12L);
            tail *= n;
            while (tail % 10 == 0)
                tail /= 10;
            tail %= 100000000LL;
            lastDigit[n] = tail % 10;
        }
        int n;
        while (cin >> n)
            cout << firstDigit[n] << ' ' << lastDigit[n] << '\n';
        return 0;
    }
    ```
