    **题目**：数字钟

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1570>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出格式为 XX:XX:XX （分别表示时，分，秒）

    **核心思路**：电路刚接通时为 00:00:00。左键每次加一小时，右键每次加一分钟， 再加自然经过的 t 秒；把总秒数对 24·3600 取模，依次除出时、分、 秒，并用 setw(2) 与 setfill('0') 补前导零。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long hours, minutes, seconds;
        cin >> hours >> minutes >> seconds;
        long long total = (hours * 3600 + minutes * 60 + seconds) % 86400;
        int h = total / 3600;
        int m = total / 60 % 60;
        int s = total % 60;
        cout << setfill('0') << setw(2) << h << ':' << setw(2) << m << ':' << setw(2) << s
             << '\n';
        return 0;
    }
    ```
