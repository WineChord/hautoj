    **题目**：界面越花 编程越拉

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1717>){ .problem-source target="_blank" rel="noopener" }

    **题意**：现给出小m的初始华丽值n，请输出使华丽值变为0的方案数。由于方案数可能过多，所以请对最终答案取模1e9+7。

    **核心思路**：设 dp\[i\] 为华丽值 i 变为 0 的方案数。按题目允许的两种第一步，后续分别进入 i-1 与 floor(i/2)，因此 $dp_{i}=dp$\[i-1\]+dp\[floor(i/2)\]。从小到大预处理并对 $10^9$+7 取模，答案为 dp\[n\]。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(n) 时间、O(n) 空间

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；减法结果可能为负，必要时先加模数再取模。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    #define INF 0x3f3f3f3f
    #define ll long long
    #define endl "\n"
    const int max_n = 1e5 + 100;
    const int mod = 1e9 + 7;
    int ans = 0;
    int dp[max_n]; // dp[i]为初始值为i的方案数
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(0);
        cout.tie(0);
        int n;
        cin >> n;
        dp[1] = 2;
        for (int i = 2; i <= n; i++)
            dp[i] = (dp[i - 1] + dp[i / 2]) % mod;
        cout << dp[n] << endl;
        return 0;
    }
    ```
