    **题目**：界面越花 编程越拉

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1717>){ .problem-source target="_blank" rel="noopener" }

    **题意**：现给出小m的初始华丽值n，请输出使华丽值变为0的方案数。由于方案数可能过多，所以请对最终答案取模1e9+7。

    **核心思路**：界面越花 编程越拉 标签:动态规划 mid题目大意:给你一个数 ， n n n可以从 n n n的状态转移过来，也可以用 n − n-1 n−1的状态转移过来，问从0开始能有多少种方案。 n 2 \frac{n}{2} 2n​思路：如果能够把题意理解到上述意思，其实解法就很明确了，就是一个简单的递推，每个值由两个状态转移得到。 程序表达如下： dp&#91;i&#93; = dp&#91;i - 1&#93; + dp&#91;i / 2&#93;同样可以使用记忆化搜索来解决这个问题（不使用记忆化的话会因为数据量过大而T） DP的标程如下

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：o(false)

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；初值不能默认全部可达；0/1 背包必须倒序遍历容量。；检查 0/1 起下标、n = 1、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    #define INF 0x3f3f3f3f
    #define ll long long
    #define endl "\n"
    const int max_n = 1e5 + 100;
    const int mod = 1e9 + 7;
    int ans = 0;
    int dp[max_n]; // dp[i]为初始值为i的方案数
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(0);
        cout.tie(0);
        int n;
        cin >> n;
        dp[1] = 2;
        for (int i = 2; i <= n; i++)
            dp[i] = (dp[i - 1] + dp[i / 2]) % mod;
        cout << dp[n] << endl;
        return 0;
    }
    ```
