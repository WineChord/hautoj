    **题目**：圆的交点

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1201>){ .problem-source target="_blank" rel="noopener" }

    **题意**：输入两个圆的坐标和半径，判断它们是否有交点

    **核心思路**：设圆心距为 d。两圆相离时 d&gt;r1+r2，内含且不接触时 d&lt;|r1-r2|；其余情况都有交点，包括外切、内切以及完全重合。因此判断 `|r1-r2|≤d≤r1+r2`，浮点比较加入很小的 eps。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        double x1, y1, r1, x2, y2, r2;
        cin >> x1 >> y1 >> r1;
        cin >> x2 >> y2 >> r2;
        double distance = hypot(x1 - x2, y1 - y2);
        const double EPS = 1e-10;
        bool intersects = distance + EPS >= fabs(r1 - r2) && distance <= r1 + r2 + EPS;
        cout << (intersects ? "Yes" : "No") << '\n';
        return 0;
    }
    ```
