    **题目**：旅行者的抛弃

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1853>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个小数（保留3位小数）

    **核心思路**：旅行者的抛弃 签到题 根据重量比求出半径比 要注意重量比 是 M + 1 m1是可莉的重量，m2是要求的结果 m1 g1 / $2 = m2$ g2 根据万有引力公式 : $g = GM$ / (r \* r) 得出 g1 / g2 的值 最后带入 可得 m2 最后直接输出

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：o(false)

    **易错点**：核对中英文标点、尾随空格和末尾换行。；乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    void solve() {
        double m, M;
        cin >> m >> M;
        double r = pow(M + 1, 1.0 / 3);
        cout << fixed << setprecision(3) << r * r / (M + 1) * m / 2;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(0);
        cout.tie(0);
        int test = 1;
        // cin >> test;
        while (test--) {
            solve();
        }
        return 0;
    }
    ```
