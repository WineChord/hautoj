    **题目**：命运之夜

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1848>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，表示小A有多少种方案召唤出最强英灵。

    **核心思路**：命运之夜 与运算：如果两个数a，b的第i位都为1，那么与运算之后，答案的第i位也为1. 或运算：如果两个数a，b的第i为中存在1个1，那么或运算之后，答案的第i位为1； 考虑a,b第i位的四种情况 1 1：与运算结果第i位为1，或运算结果第i位为1. 1 0 :与运算结果第i位为0，或运算结果第i位为1. 0 1：与运算结果第i位为0，或运算结果第i位位1. 0 0：与运算结果第i位为0，或运算结果第i为为0. 不难发现，与运算和或运算的答案内1的个数和与运算前a，b两数的1的个数和相同， 那么，我们可以先预处理出来每个数的二进制位含多少1，cnt数组记录一下，然后枚举以它为i时，大于i的部分有多少下标满足条件（有多少数的二进制中1的个数大于等于k-cnt&#91;i&#93;）。让ans+=满足k-cnt&#91;i&#93;的个数即可。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：通常为 O(n)

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；检查 0/1 起下标、n = 1、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    long long arr[110000];
    int cnt[90];       // cnt[i]表示有多少数的二进制位中1的个数等于i。
    int crr[110000];   ////crr[i]表示第i个数的二进制位中有多少1。
    long long sum[90]; // sum[i]表示有多少数的二进制位中1的个数大于等于i。
    int main() {
        int n, k;
        scanf("%d %d", &n, &k);
        for (int i = 1; i <= n; ++i) {
            scanf("%lld", &arr[i]);
            int cnt1 = 0;
            for (int j = 0; j <= 30; ++j) // 计算每个数中有多少1
            {
                int c = (1 << j);
                if (c & arr[i]) {
                    cnt1++;
                }
            }
            crr[i] = cnt1;
            cnt[cnt1]++;
        }
        for (int i = 70; i >= 0; --i) {
            sum[i] = sum[i + 1] + cnt[i];
        }
        int c = 0;
        long long ans = 0;
        for (int i = 1; i <= n; ++i) {
            int t = k - crr[i];
            for (
                int j = crr[i]; j >= 0;
                --j) // 将自身减去。保证当前sum[i]表示的是大于i中有多少数的二进制位中1的个数大于等于i。避免重复。
            {
                sum[j]--;
            }
            if (t < 0)
                t = 0;
            // cout<<t<<endl;
            ans += sum[t];
        }
        printf("%lld\n", ans);
        return 0;
    }
    ```
