??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Choice的箱子

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1349>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出需要检查箱子的数目。

    **核心思路**：箱子最后打开，当且仅当它被 a、b、c 三组操作覆盖了奇数次。 设 A、B、C 为相应倍数集合。把单集合计数相加后，两集合交集中的元素 被算了两次但应为 0，故每个两两交集减 2 次；三重交集经历三次操作 应保留，而前三步合计给它系数 -3，所以再加 4 次。答案为 |A|+|B|+|C|-2(|AB|+|AC|+|BC|)+4|ABC|，交集用最小公倍数计数。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(log max(a,b,c)) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    template <class T>
    T gcdValue(T a, T b) {
        while (b != 0) {
            T r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    long long safeLcm(long long a, long long b, long long limit) {
        __int128 value = (__int128)(a / gcdValue(a, b)) * b;
        return value > limit ? limit + 1 : (long long)value;
    }
    long long multiples(long long n, long long divisor) {
        return divisor > n ? 0 : n / divisor;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long n, a, b, c;
            cin >> n >> a >> b >> c;
            long long ab = safeLcm(a, b, n);
            long long ac = safeLcm(a, c, n);
            long long bc = safeLcm(b, c, n);
            long long abc = safeLcm(ab, c, n);
            long long ans = multiples(n, a) + multiples(n, b) + multiples(n, c) -
                            2 * (multiples(n, ab) + multiples(n, ac) + multiples(n, bc)) +
                            4 * multiples(n, abc);
            cout << ans << '\n';
        }
        return 0;
    }
    ```
