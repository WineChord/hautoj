    **题目**：踱步

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1869>){ .problem-source target="_blank" rel="noopener" }

    **题意**：请统计他共走了多少米，并记录最后停在了哪个位置。

    **核心思路**：从 (0,0) 出发，方向 1/2/3/4 分别让 x 加、x 减、y 减、y 加 length；同时把每段 length 加入总路程。最后分两行输出坐标与路程。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, x = 0, y = 0, total = 0;
        cin >> n;
        while (n--) {
            int dir, len;
            cin >> dir >> len;
            total += len;
            if (dir == 1)
                x += len;
            else if (dir == 2)
                x -= len;
            else if (dir == 3)
                y -= len;
            else
                y += len;
        }
        cout << x << ' ' << y << '\n' << total << '\n';
        return 0;
    }
    ```
