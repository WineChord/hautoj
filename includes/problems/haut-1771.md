    **题目**：赶上世界崩坏的速度，将你拯救

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1771>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出至少多少次操作后存在一种排序使得剩下的数排序后，在数值上严格递增。

    **核心思路**：最后能严格递增等价于“剩余元素互不相同”。设 n 个数中有 u 个 不同值，则至少要删掉 d=n-u 个重复副本。一次恰好删两个数，所以 至少 ceil(d/2) 次；若 d 为奇数，最后一次顺带删掉一个目前唯一的数 也不会制造重复，因而这个下界总能达到。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n log n) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            set<int> distinct;
            for (int i = 0, x; i < n; ++i) {
                cin >> x;
                distinct.insert(x);
            }
            int duplicates = n - static_cast<int>(distinct.size());
            cout << (duplicates + 1) / 2 << '\n';
        }
        return 0;
    }
    ```
