    **题目**：村里有个姑娘叫小Jun

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1498>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数

    **核心思路**：先用并查集连好已有道路，并记录每个连通块内的最大编号。顺序 扫描一个区间 \[left,right\]：若扫到的点属于新连通块，为使整个编号 区间和谐就必须加一条边合并它，同时 right 可能扩展到该块的最大 编号。直到越过 right 后再开始下一个区间。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O((n+m)α(n)) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    struct DSU {
        vector<int> parent, mx;
        DSU(int n) : parent(n + 1), mx(n + 1) {
            iota(parent.begin(), parent.end(), 0);
            iota(mx.begin(), mx.end(), 0);
        }
        int find(int x) {
            return parent[x] == x ? x : parent[x] = find(parent[x]);
        }
        void unite(int a, int b) {
            a = find(a);
            b = find(b);
            if (a == b)
                return;
            parent[b] = a;
            mx[a] = max(mx[a], mx[b]);
        }
    };
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m;
        cin >> n >> m;
        DSU dsu(n);
        while (m--) {
            int a, b;
            cin >> a >> b;
            dsu.unite(a, b);
        }
        int ans = 0;
        for (int left = 1; left <= n;) {
            int root = dsu.find(left);
            int right = dsu.mx[root];
            for (int point = left + 1; point <= right; ++point) {
                int other = dsu.find(point);
                root = dsu.find(root);
                if (other != root) {
                    right = max(right, dsu.mx[other]);
                    dsu.unite(root, other);
                    root = dsu.find(root);
                    ++ans;
                }
            }
            left = right + 1;
        }
        cout << ans << '\n';
        return 0;
    }
    ```
