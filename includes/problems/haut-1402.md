??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：文物鉴定

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1402>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组输入对应一行输出，两个时间较早的年份在前，你只需要在年份数字后面加上AD或者BC即可。

    **核心思路**：把 AD 年记为正数、BC 年记为负数，按时间轴排序。最近的一对一定 在排序后相邻位置中；依次比较间隔，严格更小时更新，间隔相同保留 先遇到的更早一对。输出时取绝对值并还原 AD/BC，整数输出会自然 去掉输入中的前导零。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(k log k) 时间、O(k) 空间，k≤20

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int parseYear(const string& s) {
        int year = stoi(s.substr(0, 4));
        return s.substr(4) == "BC" ? -year : year;
    }
    string formatYear(int year) {
        return to_string(abs(year)) + (year < 0 ? "BC" : "AD");
    }
    int main() {
        int T;
        cin >> T;
        while (T--) {
            vector<int> years;
            string token;
            while (cin >> token && token != "/")
                years.push_back(parseYear(token));
            sort(years.begin(), years.end());
            int best = 0;
            for (int i = 1; i + 0 < (int)years.size(); ++i) {
                if (years[i] - years[i - 1] < years[best + 1] - years[best]) {
                    best = i - 1;
                }
            }
            cout << formatYear(years[best]) << ' ' << formatYear(years[best + 1]) << '\n';
        }
        return 0;
    }
    ```
