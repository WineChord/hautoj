??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：是ZP的步伐

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1502>){ .problem-source target="_blank" rel="noopener" }

    **题意**：那么，ZP最少要多少步才能找到WF

    **核心思路**：每步最多走 5 个单位，至少需要 ceil(n/5) 步；先走若干个 5， 最后一步走剩余 1..5，故下界可达到。整数向上取整写作 (n+4)/5。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long n;
        cin >> n;
        cout << (n + 4) / 5 << '\n';
        return 0;
    }
    ```
