    **题目**：欢迎来到实力至上主义的OJ

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1328>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一整数，走过的最短距离

    **核心思路**：默认已经在顶点 a，并把它算作经过的第 1 个顶点，所以还需走 n-1 条边。顶点只有三个，做小型动态规划：dp&#91;step&#93;&#91;v&#93; 表示共经过 step 个顶点且停在 v 的最短路程；从另外两个顶点转移并加相应边长。允许 重复经过顶点，但一次移动必须沿三角形的一条边。最后取三个终点最小值。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        long long ab, ac, bc;
        cin >> n >> ab >> ac >> bc;
        long long distance[3][3] = {{0, ab, ac}, {ab, 0, bc}, {ac, bc, 0}};
        const long long INF = (1LL << 60);
        array<long long, 3> dp{0, INF, INF};
        for (int visited = 2; visited <= n; ++visited) {
            array<long long, 3> next{INF, INF, INF};
            for (int from = 0; from < 3; ++from)
                for (int to = 0; to < 3; ++to)
                    if (from != to)
                        next[to] = min(next[to], dp[from] + distance[from][to]);
            dp = next;
        }
        cout << *min_element(dp.begin(), dp.end()) << '\n';
        return 0;
    }
    ```
