    **题目**：趣味游戏（五）：吃鸡

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1333>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组样例输出用一个空格隔开的两个整数,第一个整数表示玩家最多可以吃到多少只"鸡"，第二个整数表示玩家吃最多的”鸡”之后最多还能吃下多少单位的食物。

    **核心思路**：目标首先是让“鸡的只数”最大，其次才让剩余胃口最大。因此总应优先 吃转化食物单位更少的类型；若跳过一只小鸡去吃更大的，不会增加数量， 只会消耗更多容量。按 a&#91;i&#93; 升序，对每类可整只吃下 min(b&#91;i&#93;,剩余容量/a&#91;i&#93;) 只，更新数量和剩余容量。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(m log m) 时间、O(m) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；比较器必须满足严格弱序；相等时处理题目指定的次关键字。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long capacity;
            int types;
            cin >> capacity >> types;
            vector<int> food(types), count(types);
            for (int& x : food)
                cin >> x;
            for (int& x : count)
                cin >> x;
            vector<pair<int, int>> chicken(types);
            for (int i = 0; i < types; ++i)
                chicken[i] = {food[i], count[i]};
            sort(chicken.begin(), chicken.end());
            long long eaten = 0;
            for (auto [units, available] : chicken) {
                long long take = min<long long>(available, capacity / units);
                eaten += take;
                capacity -= take * units;
            }
            cout << eaten << ' ' << capacity << '\n';
        }
        return 0;
    }
    ```
