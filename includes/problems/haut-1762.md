??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：喂喂，你知道魔法少女的这个传闻吗？

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1762>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行，直接输出答案即可。

    **核心思路**：先算整数个数，再乘一个 int 占用的 4 字节。本题无输入，只需把 确定的答案 497120 原样输出；固定输出题最重要的是不要添加解释文字。

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++17 编译通过；公开样例不可机读，未执行

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << 497120 << '\n';
        return 0;
    }
    ```
