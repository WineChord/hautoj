    **题目**：偶数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1337>){ .problem-source target="_blank" rel="noopener" }

    **题意**：小智特别喜欢偶数，所以它希望一个数可以由两个偶数相加得来。小智给你一个数n，你来判断n是否可以由两个偶数(正整数)相加得来，如果可以

    **核心思路**：两个正偶数的最小值都是 2，所以它们的和至少为 4，且仍是偶数。 反过来，任何不小于 4 的偶数 n 都能写成 2+(n-2)，两项均为正偶数。 因此判断 `n&gt;=4 &amp;&amp; n%2==0`。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            cout << (n >= 4 && n % 2 == 0 ? "Happy QAQ" : "Sad TAT") << '\n';
        }
        return 0;
    }
    ```
