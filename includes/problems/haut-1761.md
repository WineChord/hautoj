??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：lycoris

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1761>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行，三个整数，以空格分隔，代表三位密码

    **核心思路**：分别维护三种左括号当前尚未匹配的数量，以及成功匹配的对数。遇到左括号就增加对应未匹配数；遇到右括号且仍有同类左括号时，消耗一个并增加匹配数。最后按题目要求的中括号、圆括号、花括号顺序输出。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n) 时间、O(1) 额外空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        char str[10010];
        scanf("%s", str);
        int s = 0, m = 0, l = 0;
        int ss = 0, mm = 0, ll = 0;
        for (int i = 0; str[i] != '\0'; i++) {
            if (str[i] == '(')
                s++;
            else if (str[i] == '[')
                m++;
            else if (str[i] == '{')
                l++;
            else if (str[i] == ')') {
                if (s != 0) {
                    s--;
                    ss++;
                }
            } else if (str[i] == ']') {
                if (m != 0) {
                    m--;
                    mm++;
                }
            } else if (str[i] == '}') {
                if (l != 0) {
                    l--;
                    ll++;
                }
            }
        }
        printf("%d %d %d", mm, ss, ll);
        return 0;
    }
    ```
