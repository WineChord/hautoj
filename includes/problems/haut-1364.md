    **题目**：Travel

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1364>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，Print "YES" if there is a path from DSB's house to his friend's house that uses only teleports, and "NO" otherwise.

    **核心思路**：从 0 出发，若当前能到达整个区间 \[0,reached\]，那么所有起点 $ai \le reached$ 的传送器都能使用，并可把右端扩展到 max(reached,bi)。 对传送器反复松弛，直到某一轮不再扩展。n 只有 100，直接做至多 n 轮 即可；最终 $reached \ge m$ 时仅靠传送器可到朋友家。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n²) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++14 编译通过；公开样例不可机读，未执行

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m;
        cin >> n >> m;
        vector<pair<int, int>> teleport(n);
        for (auto& [a, b] : teleport)
            cin >> a >> b;
        int reached = 0;
        for (int iteration = 0; iteration < n; ++iteration) {
            int old = reached;
            for (auto [a, b] : teleport)
                if (a <= reached)
                    reached = max(reached, b);
            if (reached == old)
                break;
        }
        cout << (reached >= m ? "YES" : "NO") << '\n';
        return 0;
    }
    ```
