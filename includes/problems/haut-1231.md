    **题目**：ykc买零食

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1231>){ .problem-source target="_blank" rel="noopener" }

    **题意**：ykc的班级准备举行班级聚会，而身为生活委员的ykc要为此准备好零食，这天，ykc来到了学校的新起点超市，在转了3个小时候，ykc决定买以下所有的n种零食，其中每种零食的价格可能不一样，而刚好超市有活动，每买m种零食，就可以任选一种不超过k元的零食并免费赠送，而ykc想尽可能的省钱，求ykc的最小花费

    **核心思路**：买 m 种送 1 种，若最终拿到 n 种，则最多有 floor(n/(m+1)) 种 可作为赠品；同时赠品价格必须不超过 k。统计所有合格价格，实际免费数 是它与该上限的较小值。为了最省钱，应让其中价格最高的若干种免费： 把合格价格降序排列，从总价中减去前 freeCount 个。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n log n) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；比较器必须满足严格弱序；相等时处理题目指定的次关键字。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m, k;
        while (cin >> n >> m >> k) {
            long long total = 0;
            vector<int> eligible;
            for (int i = 0; i < n; ++i) {
                int price;
                cin >> price;
                total += price;
                if (price <= k)
                    eligible.push_back(price);
            }
            sort(eligible.begin(), eligible.end(), greater<int>());
            int freeCount = min<int>(eligible.size(), n / (m + 1));
            for (int i = 0; i < freeCount; ++i)
                total -= eligible[i];
            cout << total << '\n';
        }
        return 0;
    }
    ```
