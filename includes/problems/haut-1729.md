    **题目**：爱情废柴

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1729>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果count不为0，输出count，否则输出"Thanks to LF's object!" 不带引号

    **核心思路**：爱情废柴模拟 按照要求模拟即可 C

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：通常为 O(n)；若循环嵌套或迭代范围不同，应按代码重新核算

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        int n;
        int a, b;
        int lack = 0, thank = 0;
        scanf("%d", &n);
        scanf("%d", &b);
        for (int i = 2; i <= n; i++) {
            scanf("%d", &a);
            if (a < b) {
                lack = b - a;
            } else if (lack != 0) {
                if (a - b > lack) {
                    lack = 0;
                    thank++;
                } else if (a - b == lack) {
                    lack = 0;
                } else if (a - b < lack) {
                    lack -= a - b;
                }
            } else if (a > b) {
                thank++;
            }
            b = a;
        }
        if (thank == 0) {
            printf("Thanks to LF's object!\n");
        } else {
            printf("%d\n", thank);
        }
    }
    ```
