    **题目**：欢迎来到LDX广场

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1503>){ .problem-source target="_blank" rel="noopener" }

    **题意**：欢迎来到LDX广场，广场大小n\*m,由于广场新建，需要用2\*1大小的方块去最大限度的填满这个广场。请问需要多少方块。

    **核心思路**：每块覆盖两个格子，所以任何方案至多使用 floor(nm/2) 块。 矩形网格可以沿任意偶数方向成对铺设；即使总格数为奇数，也只剩 一个格子，因此这个上界总能达到。

    **正确性**：构造只使用题目允许的元素与操作。；每一步都维持长度、取值、相邻关系或总和等约束。；结束时规模达到要求，因此输出是完整合法答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；样例只是一个合法答案；本地检查约束，不要逐字比对。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long n, m;
        cin >> n >> m;
        cout << n * m / 2 << '\n';
        return 0;
    }
    ```
