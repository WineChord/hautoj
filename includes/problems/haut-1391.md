??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：超超超超超越数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1391>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个数字，0或1，即刘维尔数小数点后第n位的数字

    **核心思路**：刘维尔数在小数点后 k! 位放 1，其余位为 0。n≤1e9，只需从 1! 开始不断乘下一个整数，若命中 n 输出 1，超过 n 则输出 0。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(log n) 级循环、O(1) 空间

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long n, factorial = 1;
        cin >> n;
        bool isOne = false;
        for (long long k = 1; factorial <= n; ++k) {
            if (factorial == n) {
                isOne = true;
                break;
            }
            if (factorial > n / (k + 1))
                break;
            factorial *= k + 1;
        }
        cout << (isOne ? 1 : 0) << '\n';
        return 0;
    }
    ```
