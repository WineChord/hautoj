    **题目**：Set

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1901>){ .problem-source target="_blank" rel="noopener" }

    **题意**：求可以进行的最大操作数。

    **核心思路**：Set 我们可以从小到大删除数字，因此，之前删除的数字并不会影响未来的选择(如果x&lt;y,那么x不可能是y的倍数)，因此，当且仅当k*x&lt;=r,即x&lt;=&#91;r/k&#93;时，整数x(1&lt;=x&lt;=r)可以被整除，答案是max(&#91;r/j&#93;-l+1,0); cin对应c语言中的scanf，cout对应printf。max是c++标准库中的取最大值函数

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：通常为 O(n)

    **易错点**：检查 0/1 起下标、n = 1、首尾元素和数组容量。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int T;
    void solve() {
        int l, r, k;
        cin >> l >> r >> k;
        cout << max(r / k - l + 1, 0) << endl;
        return;
    }
    int main() {
        cin >> T;
        while (T--) {
            solve();
        }
    }
    ```
