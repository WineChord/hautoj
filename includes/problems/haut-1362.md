??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：表面兄弟

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1362>){ .problem-source target="_blank" rel="noopener" }

    **题意**：现在他将考试座位表给你，想问你他是否有可能在考试中有充足时间作弊并拿到100分

    **核心思路**：左上角到右下角的曼哈顿距离恰好是 n+m-2。题目不允许多花一秒， 所以合法路线不能向上或向左，只能始终向右或向下。做一个布尔动态规划： 当前座位愿意传纸条且它的上方或左方可达时，当前格可达。最后检查右下角。 这比普通 BFS 更准确地利用了严格时间上限。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(nm) 时间、O(m) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；公开样例不可机读，未执行

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m;
        cin >> n >> m;
        vector<char> reachable(m, false);
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                int willing;
                cin >> willing;
                if (!willing) {
                    reachable[j] = false;
                } else if (i == 0 && j == 0) {
                    reachable[j] = true;
                } else {
                    bool fromUp = reachable[j];
                    bool fromLeft = j > 0 && reachable[j - 1];
                    reachable[j] = fromUp || fromLeft;
                }
            }
        }
        cout << (reachable[m - 1] ? "YES" : "LBWNB") << '\n';
        return 0;
    }
    ```
