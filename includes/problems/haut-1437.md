    **题目**：数字分组

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1437>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出有一行，为各组数字的数量。 若无结果，输出-1.

    **核心思路**：每组元素和必须等于 total/k，所以 total 不能整除 k 时直接失败。 用前缀和依次寻找 target、2target、…、(k-1)target 的边界，且每个 边界下标必须严格递增并早于 n；找到后输出相邻边界之差。这个写法 对负数和 $target=0$ 也成立。

    **正确性**：构造只使用题目允许的元素与操作。；每一步都维持长度、取值、相邻关系或总和等约束。；结束时规模达到要求，因此输出是完整合法答案。

    **复杂度**：O(n) 时间、O(n) 空间

    **易错点**：样例只是一个合法答案；本地检查约束，不要逐字比对。；检查 0/1 起下标、$n = 1$、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, k;
        cin >> n >> k;
        vector<long long> a(n);
        long long total = 0;
        for (long long& x : a) {
            cin >> x;
            total += x;
        }
        if (total % k != 0) {
            cout << -1 << '\n';
            return 0;
        }
        long long target = total / k, prefix = 0;
        vector<int> cuts;
        int needed = 1;
        for (int i = 1; i < n && needed < k; ++i) {
            prefix += a[i - 1];
            if (prefix == target * needed) {
                cuts.push_back(i);
                ++needed;
            }
        }
        if (needed != k) {
            cout << -1 << '\n';
            return 0;
        }
        int pre = 0;
        for (int cut : cuts) {
            cout << cut - pre << ' ';
            pre = cut;
        }
        cout << n - pre << '\n';
        return 0;
    }
    ```
