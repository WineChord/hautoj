    **题意**：根据给定输入，一行字符串

    **核心思路**：没有输入，原样输出包含双引号的字符串 `"a % b = c"`。在 C++ 字符串字面量中双引号要写成 `"`；百分号在 `cout` 中无需转义 （若使用 printf 才要写成 `%%`）。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；未提供成对公开样例

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << "\"a % b = c\"\n";
        return 0;
    }
    ```
