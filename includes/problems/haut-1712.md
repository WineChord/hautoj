    **题目**：lsjp和他的小伙伴们

    **题意**：经过百天的奋战，21年的高考算是圆满结束了，对于生活十分有仪式感的lsjp来说来一场说走就走的旅行最合适不过了，他和他的家人们率先来了场美妙的旅行。又过了不久就开学了，lsjp在haut结识了不少新的伙伴，其中的两个就是lwjq和lcby，因此他们三个也计划着在中秋节或者国庆节来一场说走就走的旅行，就在这个时候有个问题就出现了，三人都有不同的想去的地方，ls……

    **核心思路**：lsjp和他的小伙伴们题意理解：这道题目主要就是概率和最大公约数的相关知识点，只要找出大于等于前两位点数的情况再约分即可。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：常数级或一次线性读入；以代码中的循环层数为准

    **易错点**：核对中英文标点、尾随空格和末尾换行。；乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int gcd(int x, int y) // 最大公约数用于约分
    {
        if (x % y == 0)
            return y;
        else
            return gcd(y, x % y);
    }
    int main() {
        int a, b;
        scanf("%d %d", &a, &b);
        int maxx = a > b ? a : b; // 求a,b中的最大的那个
        int ans = 6 - maxx + 1;
        int x = gcd(ans, 6);
        printf("%d/%d\n", ans / x, 6 / x);
    }
    ```
