    **题目**：神奇的井

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1244>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出最终落到井内的盘子数量。

    **核心思路**：盘子下落时能否经过某层，取决于从井口到该层的最窄宽度。因此先把 井宽改为前缀最小值，使其单调不增。维护下一个可放置的最深层 position； 对每只盘子从该位置向上找首个宽度不小于盘宽的层，放下后 position 减一。若越过井口，后续盘子都无法进入，停止。指针总共只向上走 N 次。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(N+M) 时间、O(N) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int depth, plateCount;
        cin >> depth >> plateCount;
        vector<long long> width(depth);
        for (long long& x : width)
            cin >> x;
        for (int i = 1; i < depth; ++i)
            width[i] = min(width[i], width[i - 1]);
        int pos = depth - 1;
        int placed = 0;
        for (int i = 0; i < plateCount; ++i) {
            long long plate;
            cin >> plate;
            if (pos < 0)
                continue;
            while (pos >= 0 && width[pos] < plate)
                --pos;
            if (pos >= 0) {
                ++placed;
                --pos;
            }
        }
        cout << placed << '\n';
        return 0;
    }
    ```
