    **题目**：零钱问题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1225>){ .problem-source target="_blank" rel="noopener" }

    **题意**：假设老板那边有面值 50， 10，5，2，1无数张，请你帮zy算算老板应该找他多少钱，钱张数最少是多少张。

    **核心思路**：找零额为 100-t。面额 50、10、5、2、1 构成规范系统，从最大面额 起尽量使用：整除得到该面额张数，余数交给更小面额。若用若干小面额 能替代一张更大面额，张数不会更少，因此贪心最优。输出找零额和张数。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int spent;
        cin >> spent;
        int change = 100 - spent;
        int remaining = change;
        int notes = 0;
        const int coin[] = {50, 10, 5, 2, 1};
        for (int value : coin) {
            notes += remaining / value;
            remaining %= value;
        }
        cout << change << ' ' << notes << '\n';
        return 0;
    }
    ```
