    **题目**：最小的数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1344>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给你两个一维数组（都为大于等于1且小于等于9的数），从第一个数组中取至少一个数字，再从第二个数组中取至少一个数字，用你选取的数字组成一个整数，求能组成的最小整数。

    **核心思路**：若两个数组有公共数字 d，可以从两边都选 d 且只保留一个，最小答案 就是最小公共数字（一个一位数一定优于任何两位数）。若没有公共数字， 必须各选一个；显然应选两数组各自最小值，并把较小者放十位，组成 10·min(x,y)+max(x,y)。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n+m) 时间、O(n+m) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n, m;
            cin >> n >> m;
            vector<int> a(n), b(m);
            array<bool, 10> inA{}, inB{};
            for (int& x : a) {
                cin >> x;
                inA[x] = true;
            }
            for (int& x : b) {
                cin >> x;
                inB[x] = true;
            }
            int common = -1;
            for (int digit = 1; digit <= 9; ++digit)
                if (inA[digit] && inB[digit]) {
                    common = digit;
                    break;
                }
            if (common != -1) {
                cout << common << '\n';
            } else {
                int x = *min_element(a.begin(), a.end());
                int y = *min_element(b.begin(), b.end());
                cout << min(x, y) * 10 + max(x, y) << '\n';
            }
        }
        return 0;
    }
    ```
