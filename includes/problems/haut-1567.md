??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：石子游戏

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1567>){ .problem-source target="_blank" rel="noopener" }

    **题意**：现在请绝顶聪明的你判断一下其他玩家是否有可能挑战成功，若能输出 "YES"，否则输出 "NO";

    **核心思路**：第 i 次操作的位移是 2^i，且每个幂最多使用一次；移动较小石子 记正号、移动较大石子记负号，问题变成用最少个带符号的二进制幂 表示距离差。差为奇数时不可能，因为所有位移均为偶数。差除以 2 后用非相邻形式 NAF：奇数末两位为 01 时减 1，为 11 时加 1， 每次选择计一次，所得非零位数最少。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(log |a-b|) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long a, b, k;
        cin >> a >> b >> k;
        long long diff = llabs(a - b);
        if (diff % 2) {
            cout << "NO\n";
            return 0;
        }
        long long value = diff / 2;
        int needed = 0;
        while (value > 0) {
            if ((value & 1) == 0) {
                value >>= 1;
            } else {
                ++needed;
                if (value == 1 || value % 4 == 1)
                    --value;
                else
                    ++value;
            }
        }
        cout << (needed <= k ? "YES" : "NO") << '\n';
        return 0;
    }
    ```
