    **题目**：Balance

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1419>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于每一个测试数据，输出至少需要称量多少次，如果永远无法得到劣质小球是哪一个，输出-1

    **核心思路**：劣质球可能偏重也可能偏轻，但只需确定“是哪一只”。一次天平称量有 左重、平衡、右重三种结果。k 次称量能为球的身份提供的最大容量是 (3\^k-1)/2；逐步扩大 k，找到容量首次不少于 n 的值即可。 两个球是唯一例外：互相称只能知道一重一轻，却无法判断哪只才是异物， 又没有第三只已知正常球作参照，所以永远无法确定。一个球无需称量。 在本题 $n \le 25$ 内也可核对为：1→0，2→-1，3..4→2， 5..13→3，14..25→4。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(log n) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        while (cin >> n) {
            if (n == 1) {
                cout << 0 << '\n';
                continue;
            }
            if (n == 2) {
                cout << -1 << '\n';
                continue;
            }
            int weighings = 0;
            long long p3 = 1;
            while ((p3 - 1) / 2 < n) {
                p3 *= 3;
                ++weighings;
            }
            cout << weighings << '\n';
        }
        return 0;
    }
    ```
