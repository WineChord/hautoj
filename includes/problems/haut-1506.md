    **题目**：zp的新冒险

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1506>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行包含一个整数表示活动个数。

    **核心思路**：经典活动选择：按结束时间从小到大排序，每次选择开始时间不早于 上一个已选活动结束时间的活动。最早结束给后续留下的可用时间最多， 用交换论证可知不会劣于任何最优方案。区间是 \[s,f)，端点相等可 无缝衔接。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        vector<pair<int, int>> activity(n);
        for (auto& [finish, start] : activity)
            cin >> start >> finish;
        sort(activity.begin(), activity.end(), [](auto a, auto b) {
            if (a.first != b.first)
                return a.first < b.first;
            return a.second > b.second;
        });
        int ans = 0, last = -1;
        for (auto [finish, start] : activity) {
            if (start >= last) {
                ++ans;
                last = finish;
            }
        }
        cout << ans << '\n';
        return 0;
    }
    ```
