    **题目**：输出WAGD

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1843>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，在一行中按题目要求输出排序后的字符串。题目保证输出非空。

    **核心思路**：与 mtlf 型循环输出相同：不区分大小写统计 W、A、G、D，随后按 W→A→G→D 循环尝试输出，耗尽的字母跳过，直至一整轮无输出。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(|s|+答案长度) 时间、O(1) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        string s;
        cin >> s;
        const string order = "WAGD";
        array<int, 4> count{};
        for (unsigned char c : s) {
            char x = static_cast<char>(toupper(c));
            for (int i = 0; i < 4; ++i) {
                if (x == order[i])
                    ++count[i];
            }
        }
        while (true) {
            bool printed = false;
            for (int i = 0; i < 4; ++i) {
                if (count[i]) {
                    cout << order[i];
                    --count[i];
                    printed = true;
                }
            }
            if (!printed)
                break;
        }
        cout << '\n';
        return 0;
    }
    ```
