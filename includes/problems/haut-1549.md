??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：替换

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1549>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，q行，每行一个整数，表示每次操作后整个序列的和

    **核心思路**：维护每个值的出现次数 count 和当前总和 sum。把所有 a 换成 b 时， 总和改变量为 count&#91;a&#93;·(b-a)，随后把 count&#91;a&#93; 合并进 count&#91;b&#93;。 a=b 时序列不变，必须单独跳过，避免把计数错误清零。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n+q) 时间、O(值域) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, q;
        cin >> n >> q;
        const int LIMIT = 100000;
        vector<long long> count(LIMIT + 1, 0);
        long long sum = 0;
        for (int i = 0, x; i < n; ++i) {
            cin >> x;
            ++count[x];
            sum += x;
        }
        while (q--) {
            int a, b;
            cin >> a >> b;
            if (a != b) {
                sum += count[a] * (b - a);
                count[b] += count[a];
                count[a] = 0;
            }
            cout << sum << '\n';
        }
        return 0;
    }
    ```
