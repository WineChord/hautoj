    **题目**：Choice and Bramble

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1351>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果Choide赢输出“Choice”,如果Bramble赢输出“Bramble”。

    **核心思路**：每种糖果至多被操作一次，而且 n 种完全相同，因此游戏等价于有 n 个可取物品：若这一种能够合法等分，一次操作就取走一个。若可操作数 n 为偶数，后手赢；为奇数，先手赢。合法等分要求 m 存在一个满足 $k \le d < m$ 的因数 d（每堆 d 个且至少两堆）。最大的真因数是 m/最小质因数，找出它后与 k 比较即可。不能分时先手直接无步可走。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组最坏 O(√m) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    long long div(long long value) {
        for (long long divisor = 2; divisor * divisor <= value; ++divisor)
            if (value % divisor == 0)
                return value / divisor;
        return 1;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        long long n, m, k;
        while (cin >> n >> m >> k) {
            bool splittable = div(m) >= k;
            bool choiceWins = splittable && (n % 2 == 1);
            cout << (choiceWins ? "Choice" : "Bramble") << '\n';
        }
        return 0;
    }
    ```
