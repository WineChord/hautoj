    **题目**：点赞分能量

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1401>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出占一行，分别输出每个人分得的能量（向下取整），中间用空格隔开

    **核心思路**：点赞总数非零时，第 i 人得到 floor(n\*likes\[i\]/sumLikes)，乘法 先用 long long。若五人点赞全为 0，大家贡献相等，按均分规则每人 得到 floor(n/5)，这也是官方题解特别提醒的零分母边界。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long energy;
        cin >> energy;
        array<long long, 5> likes{};
        for (long long& x : likes)
            cin >> x;
        long long total = accumulate(likes.begin(), likes.end(), 0LL);
        for (int i = 0; i < 5; ++i) {
            if (i)
                cout << ' ';
            if (total == 0)
                cout << energy / 5;
            else
                cout << energy * likes[i] / total;
        }
        cout << '\n';
        return 0;
    }
    ```
