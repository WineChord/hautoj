??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：Starlight

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1942>){ .problem-source target="_blank" rel="noopener" }

    **题意**：现在小光和华恋各自随机选择一个整数x、y，对应直角坐标上的点（x，y）；再由隔壁班的奈奈同学确定尺寸参数a，请你帮她们确定这个点是否在a决定的星形线内。

    **核心思路**：星形线边界满足 |x|^(2/3)+|y|^(2/3)=a^(2/3)。计算左右两边 的差：绝对值小于 1e-6 判为边界，左边更小在内部，否则在外部。 对负坐标必须先取绝对值，否则分数幂会产生 NaN。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long double x, y, a;
        cin >> x >> y >> a;
        long double left = powl(fabsl(x), 2.0L / 3.0L) + powl(fabsl(y), 2.0L / 3.0L);
        long double right = powl(a, 2.0L / 3.0L);
        if (fabsl(left - right) < 1e-6L)
            cout << "Non Non Da Yo\n";
        else if (left < right)
            cout << "Position Zero!\n";
        else
            cout << "Fly Me to the Star\n";
        return 0;
    }
    ```
