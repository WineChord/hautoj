    **题目**：加密工作

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1312>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，四个整数，以空格隔开。

    **核心思路**：先把每个字母统一转成 1..26 的值。四个选项对应原下标排列分别为 \[0,1,2,3\]、\[3,2,1,0\]、\[2,3,0,1\]、\[1,0,3,2\]。选出相应排列后， 用单个空格连接四个整数，不在行尾额外输出空格。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int option;
        string s;
        while (cin >> option >> s) {
            const int order[4][4] = {{0, 1, 2, 3}, {3, 2, 1, 0}, {2, 3, 0, 1}, {1, 0, 3, 2}};
            for (int i = 0; i < 4; ++i) {
                if (i)
                    cout << ' ';
                char c = s[order[option - 1][i]];
                cout << tolower((unsigned char)c) - 'a' + 1;
            }
            cout << '\n';
        }
        return 0;
    }
    ```
