??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：突然之间

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1733>){ .problem-source target="_blank" rel="noopener" }

    **题意**：使得Xx达到或超过 n 位数字的最小正整数 x 是多少？

    **核心思路**：x\^x 的十进制位数是 floor(x·log10(x))+1。该值随正整数 x 单调增加，在 \[1,2e9\] 二分第一个位数不少于 n 的 x。使用 long double 减少边界处的浮点误差。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(log 2e9) 时间、O(1) 空间

    **易错点**：确认循环边界，以及最终返回第一个可行还是最后一个不可行。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        long long n;
        cin >> n;
        long long left = 1, right = 2000000000LL;
        auto enough = [&](long long x) {
            long double logarithm = x * log10((long double)x);
            return logarithm + 1e-12L >= (long double)(n - 1);
        };
        while (left < right) {
            long long middle = left + (right - left) / 2;
            if (enough(middle))
                right = middle;
            else
                left = middle + 1;
        }
        cout << left << '\n';
        return 0;
    }
    ```
