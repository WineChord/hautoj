    **题目**：AC之子

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1487>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个数，是前t项的总和

    **核心思路**：数列从第三项起为前两项之和。t 可达 1000，项和会远超 64 位， 因此用十进制字符串实现加法。分别维护前两项 current/next 与总和， 每生成一项便加入总和；t=1、2 单独由同一循环自然覆盖。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(tD) 时间、O(D) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    string add(string a, string b) {
        int i = (int)a.size() - 1, j = (int)b.size() - 1, carry = 0;
        string res;
        while (i >= 0 || j >= 0 || carry) {
            int x = i >= 0 ? a[i--] - '0' : 0;
            int y = j >= 0 ? b[j--] - '0' : 0;
            int sum = x + y + carry;
            res.push_back(char('0' + sum % 10));
            carry = sum / 10;
        }
        reverse(res.begin(), res.end());
        return res;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        string first, second;
        int t;
        cin >> first >> second >> t;
        string sum = "0";
        if (t >= 1)
            sum = add(sum, first);
        if (t >= 2)
            sum = add(sum, second);
        for (int index = 3; index <= t; ++index) {
            string next = add(first, second);
            sum = add(sum, next);
            first = second;
            second = next;
        }
        cout << sum << '\n';
        return 0;
    }
    ```
