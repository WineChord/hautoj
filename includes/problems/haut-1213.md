    **题目**：Meeting Friends

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1213>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，Print one integer — the minimum total distance the friends need to travel in order to meet together.

    **核心思路**：三人在数轴上一点会合时，绝对距离和在中位数处最小。把三个坐标 排序为 $x \le y \le z$，选 y 后总路程为 (y-x)+(z-y)=z-x；直接输出最大 坐标减最小坐标即可。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        array<int, 3> x{};
        cin >> x[0] >> x[1] >> x[2];
        sort(x.begin(), x.end());
        cout << x[2] - x[0] << '\n';
        return 0;
    }
    ```
