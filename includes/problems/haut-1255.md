    **题目**：Simple学长的数学题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1255>){ .problem-source target="_blank" rel="noopener" }

    **题意**：Simple学长在学数学的时候遇到了一个难题，根据点A(X1,Y1),点B(X2,Y2)的坐标求出直线AB的函数表达式，Simple学长半天也没做出来，希望你们帮他一下。

    **核心思路**：两点式给出斜率 k=(y2-y1)/(x2-x1) 和截距 b=(x2·y1-x1·y2)/(x2-x1)。竖线 dx=0 或水平线 dy=0 按题意输出 Error。其余把 k、b 的分子分母分别用 gcd 约成最简分数，统一让分母 为正；系数 1/-1 分别省写为 `x`/`-x`，截距为 0 时省略。坐标乘积 可能越过有符号 64 位，使用 __int128。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(log C) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    using i128 = __int128_t;
    i128 abs128(i128 x) {
        return x < 0 ? -x : x;
    }
    i128 gcd128(i128 a, i128 b) {
        a = abs128(a);
        b = abs128(b);
        while (b != 0) {
            i128 r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    string toStr(i128 x) {
        if (x == 0)
            return "0";
        bool neg = x < 0;
        x = abs128(x);
        string s;
        while (x > 0) {
            s.push_back(char('0' + x % 10));
            x /= 10;
        }
        if (neg)
            s.push_back('-');
        reverse(s.begin(), s.end());
        return s;
    }
    struct Frac {
        i128 p, q;
        Frac(i128 n, i128 d) {
            if (d < 0)
                n = -n, d = -d;
            i128 g = gcd128(n, d);
            p = n / g;
            q = d / g;
        }
        string str() const {
            i128 n = abs128(p);
            if (q == 1)
                return toStr(n);
            return toStr(n) + "/" + toStr(q);
        }
    };
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        long long xa, ya, xb, yb;
        while (cin >> xa >> ya >> xb >> yb) {
            i128 x1 = xa, y1 = ya, x2 = xb, y2 = yb;
            i128 dx = x2 - x1, dy = y2 - y1;
            if (dx == 0 || dy == 0) {
                cout << "Error\n";
                continue;
            }
            Frac k(dy, dx);
            Frac bias(x2 * y1 - x1 * y2, dx);
            cout << "y=";
            if (k.p < 0)
                cout << '-';
            if (abs128(k.p) != k.q)
                cout << k.str();
            cout << 'x';
            if (bias.p != 0) {
                cout << (bias.p > 0 ? '+' : '-');
                cout << bias.str();
            }
            cout << '\n';
        }
        return 0;
    }
    ```
