    **题目**：Crazy Computer

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1226>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，Print a single positive integer, the number of words that remain on the screen after all n words was typed, in other words, at the second tn.

    **核心思路**：若相邻两次输入单词的时间差大于延迟 c，之前屏幕上的所有单词都会 消失，当前可见数重置为 1；否则旧单词尚未清空，当前可见数加一。 从第一个单词的计数 1 开始扫描所有相邻时间差，最后的计数就是 tn 时刻屏幕上的单词数。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        long long delay;
        cin >> n >> delay;
        long long pre;
        cin >> pre;
        int visible = 1;
        for (int i = 1; i < n; ++i) {
            long long cur;
            cin >> cur;
            if (cur - pre > delay)
                visible = 1;
            else
                ++visible;
            pre = cur;
        }
        cout << visible << '\n';
        return 0;
    }
    ```
