    **题目**：趣味游戏（四）：蛮王

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1332>){ .problem-source target="_blank" rel="noopener" }

    **题意**：听说你们喜欢玩《英雄联盟》，但是你们有没有听说过伟大的蛮王泰达米尔？蛮王从他的父亲手中继承了大剑，而这把剑也是他父亲从泰达米尔祖父那里继承来的。多年来他一直铭记着父亲的教诲“熟练掌握它，就能拥有它。”他和寒冰射手艾希缔结了婚姻，并一起为守护联盟的子民们而战。有一天敌人入侵联盟，蛮王为了守护联盟和妻子，英勇地与敌人战斗。经过艰苦地战斗蛮王终于打退了敌人，战后妻……

    **核心思路**：每一刀基础伤害都必然计入；恰有 m 刀暴击，相当于再额外加上这 m 刀各自的一份基础伤害。因此最小总伤害选择最小的 m 个数额外加入， 最大总伤害选择最大的 m 个数额外加入。排序后用前缀/后缀求和即可。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n, crit;
            cin >> n >> crit;
            vector<long long> damage(n);
            long long baseTotal = 0;
            for (long long& x : damage) {
                cin >> x;
                baseTotal += x;
            }
            sort(damage.begin(), damage.end());
            long long mn = baseTotal;
            long long mx = baseTotal;
            for (int i = 0; i < crit; ++i) {
                mn += damage[i];
                mx += damage[n - 1 - i];
            }
            cout << mn << ' ' << mx << '\n';
        }
        return 0;
    }
    ```
