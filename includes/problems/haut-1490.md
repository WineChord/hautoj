    **题目**：成龙AC记

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1490>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个数字，表示此次成龙上学所用的时间。

    **核心思路**：记录已经是到达路口时的灯色和倒计时，不必再模拟此前路程造成的 相位变化。道路 k=0 加 t；红灯 k=1 等 t；黄灯 k=2 还要等完当前 黄灯及下一段红灯，即 t+r；绿灯 k=3 直接通过。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long red, yellow, green;
        int n;
        cin >> red >> yellow >> green >> n;
        long long ans = 0;
        while (n--) {
            int type;
            long long time;
            cin >> type >> time;
            if (type == 0 || type == 1)
                ans += time;
            else if (type == 2)
                ans += time + red;
        }
        cout << ans << '\n';
        return 0;
    }
    ```
