    **题目**：逻辑判断

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1399>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组数据输出最终的逻辑值，每组占一行

    **核心思路**：表达式只有两个逻辑值和一个运算符。首尾字符转为布尔值，中间 若含 &amp;&amp; 做与，若为 | 做或，否则做异或，最后转回 T/F。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        while (n--) {
            string expr;
            cin >> expr;
            bool a = expr.front() == 'T';
            bool b = expr.back() == 'T';
            bool res;
            if (expr.find("&&") != string::npos)
                res = a && b;
            else if (expr.find('|') != string::npos)
                res = a || b;
            else
                res = a ^ b;
            cout << (res ? 'T' : 'F') << '\n';
        }
        return 0;
    }
    ```
