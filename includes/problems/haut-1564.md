??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：获得自由？

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1564>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，若他能获得自由，则输出 “YES”，否则输出 “NO”。

    **核心思路**：网格图是黑白二分图，每走一步颜色必然改变。右下角与左上角颜色 相同；若 n 为偶数，n² 个格子的路径含奇数条边，两个端点应异色， 矛盾。若 n 为奇数，则可按蛇形路线遍历所有格子并从右下到左上， 所以答案恰为 n 是否为奇数。

    **正确性**：建图把每个合法对象或状态映射为点，把合法关系映射为边。；扩展操作覆盖所有且仅覆盖合法转移，访问标记避免重复处理。；遍历结束后的可达性、距离或累计值与原问题一一对应。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对有向/无向、重边、自环、不可达点和点编号范围。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        cout << (n % 2 ? "YES" : "NO") << '\n';
        return 0;
    }
    ```
