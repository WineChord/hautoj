    **题目**：进位

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1870>){ .problem-source target="_blank" rel="noopener" }

    **题意**：寻找一个最小的数 x，使 num+x 刚好比 num 的位数多一位。

    **核心思路**：目标是 x=10^n-num。直接把 10^n 写成“1 后跟 n 个 0”，再从 低位到高位执行带借位减法；这样即使 num 的末位是 0，也不会出现 把数值 10 错当成一个十进制字符的问题。最后删除前导 0。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(n) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<int> digit(n);
        for (int& value : digit)
            cin >> value;
        string minuend = "1" + string(n, '0');
        string ans(n + 1, '0');
        int borrow = 0;
        for (int i = n; i >= 0; --i) {
            int upper = minuend[i] - '0' - borrow;
            int lower = (i == 0 ? 0 : digit[i - 1]);
            if (upper < lower) {
                upper += 10;
                borrow = 1;
            } else {
                borrow = 0;
            }
            ans[i] = char('0' + upper - lower);
        }
        size_t first = ans.find_first_not_of('0');
        if (first == string::npos)
            cout << "0\n";
        else
            cout << ans.substr(first) << '\n';
        return 0;
    }
    ```
