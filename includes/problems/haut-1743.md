??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：小C刷跑

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1743>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出小C还需要跑的最短距离，结果保留两位小数

    **核心思路**：若 $R \ge y$，沿 x 轴直跑就进入 2 号点打卡圆，最后到距 3 号点 R 处停止，距离 2x-R。否则 2 号打卡点最优取 (x,y-R)，到起点和 3 号点的距离相等，跑程为两倍该距离，再减去最后无需进入 3 号圆心 的 R。平方使用 long double 防溢出。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long double x, y, radius;
        cin >> x >> y >> radius;
        long double ans;
        if (radius >= y) {
            ans = 2 * x - radius;
        } else {
            long double vertical = y - radius;
            ans = 2 * sqrt(x * x + vertical * vertical) - radius;
        }
        cout << fixed << setprecision(2) << (double)ans << '\n';
        return 0;
    }
    ```
