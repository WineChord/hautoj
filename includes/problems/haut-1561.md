??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：禁止复读

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1561>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，第一行一个k输出被禁言人的个数。 第二行由小到大输出k个整数，表示被禁言的人是谁。 如果k=0，则输出空行即可

    **核心思路**：“发起复读”只指一段相同消息中的第二条，而不是第三条、第四条。 因此当前消息等于上一条、且上一条不是其前一条的延续时，才把当前 发言者加入集合。set 同时完成去重和编号升序。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n log n) 时间、O(n) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<string> messages(n);
        set<int> banned;
        for (int i = 0; i < n; ++i) {
            int user;
            cin >> user >> messages[i];
            bool same = i >= 1 && messages[i] == messages[i - 1];
            bool prevDup = i >= 2 && messages[i - 1] == messages[i - 2];
            if (same && !prevDup)
                banned.insert(user);
        }
        cout << banned.size() << '\n';
        bool first = true;
        for (int user : banned) {
            if (!first)
                cout << ' ';
            cout << user;
            first = false;
        }
        cout << '\n';
        return 0;
    }
    ```
