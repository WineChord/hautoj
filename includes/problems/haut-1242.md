    **题目**：又是郊游

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1242>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出狗跑的路径，结果保留小数点后两位。

    **核心思路**：zy 出发时 cds 已领先 M·X 米。两人的相对速度是 Y-X，所以追上 所需时间为 `M·X/(Y-X)` 分钟。狗在这整个时间内始终以 Z 米/分钟 奔跑，往返细节不会改变总路程，故答案为 Z 乘追赶时间。用 double 并保留两位小数。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：按误差要求保留精度，不要只按样例字符数猜小数位。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            double minutes, slowSpeed, fastSpeed, dogSpeed;
            cin >> minutes >> slowSpeed >> fastSpeed >> dogSpeed;
            double catchTime = minutes * slowSpeed / (fastSpeed - slowSpeed);
            cout << fixed << setprecision(2) << catchTime * dogSpeed << '\n';
        }
        return 0;
    }
    ```
