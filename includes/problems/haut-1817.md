    **题目**：我爱编程，编程使我快乐。

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1817>){ .problem-source target="_blank" rel="noopener" }

    **题意**：刚刚接触编程的你发现编程能给你带来许多乐趣，为了表达自己的快乐，请输出 “我爱编程，编程使我快乐。” （只需要输出“”内的字符）。

    **核心思路**：无输入固定输出题，按题面要求输出指定句子即可。

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++17 编译通过；未提供成对公开样例

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << "我爱编程，编程使我快乐。" << '\n';
        return 0;
    }
    ```
