??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：约好了下午三点，在记忆博物馆

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1768>){ .problem-source target="_blank" rel="noopener" }

    **题意**：工作人员告诉你：记忆博物馆只能通过魔法列车（魔法列车一共有12个站点，每条运行的魔法列车只有起点和终点且为单向行驶，不会停靠在别的站点，随时都有车次）到达，你现在所处的位置为1号站点，而记忆博物馆在n号站点（2&lt;=n&lt;=12)，并且给了你目前开通的t（1&lt;=t&lt;=12）条魔法列车线路及其运行一次所用的时间。机智的你发现，对于每个站点，最多只能成为一次起点。现……

    **核心思路**：每个站点最多只有一条出边，因此从 1 号站出发不存在路线选择， 只需沿唯一后继一直走。用 visited 防止线路形成环；累加沿途耗时。 到达 n 后按 120 分钟判断 yes/No，遇到无出边或环则说明不能到达。

    **正确性**：建图把每个合法对象或状态映射为点，把合法关系映射为边。；扩展操作覆盖所有且仅覆盖合法转移，访问标记避免重复处理。；遍历结束后的可达性、距离或累计值与原问题一一对应。

    **复杂度**：O(t+n) 时间、O(n) 空间

    **易错点**：核对有向/无向、重边、自环、不可达点和点编号范围。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, t;
        cin >> n >> t;
        vector<int> nextStation(13, -1), cost(13, 0);
        for (int i = 0; i < t; ++i) {
            int a, b, x;
            cin >> a >> b >> x;
            nextStation[a] = b;
            cost[a] = x;
        }
        vector<bool> visited(13, false);
        int cur = 1, total = 0;
        while (cur != n && cur != -1 && !visited[cur]) {
            visited[cur] = true;
            if (nextStation[cur] == -1) {
                cur = -1;
                break;
            }
            total += cost[cur];
            cur = nextStation[cur];
        }
        if (cur == n) {
            cout << (total <= 120 ? "yes" : "No") << '\n' << total << '\n';
        } else {
            cout << "No\n0\n";
        }
        return 0;
    }
    ```
