    **题目**：小唐的工作

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1934>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个小数，保留18位小数。

    **核心思路**：小唐的工作 n天完成的任务量可以简化为1-pow(0.5,n+1)。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：常数级或一次线性读入；以代码中的循环层数为准

    **易错点**：核对中英文标点、尾随空格和末尾换行。；条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    signed main() {
        int n;
        cin >> n;
        double x = pow(0.5, n);
        printf("%.18lf", 1 - x);
        return 0;
    }
    ```
