    **题目**：Raging Loop

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1881>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，"Hai"或者"chi ga u"

    **核心思路**：把整数当作十进制字符串检查。公开题解给出的判定是：前两位必须 为“10”；第三位大于 1 时成立，第三位等于 1 时还必须存在第四位。 其余情况均输出 chi ga u。字符串写法避免了数值位数判断的边界错误。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(|x|) 时间、O(|x|) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        string number;
        cin >> number;
        bool raging = number.size() >= 3 && number[0] == '1' && number[1] == '0' &&
                      (number[2] > '1' || (number[2] == '1' && number.size() > 3));
        cout << (raging ? "Hai" : "chi ga u") << '\n';
        return 0;
    }
    ```
