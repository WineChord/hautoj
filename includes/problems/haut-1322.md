    **题目**：崩崩崩

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1322>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，Stone最早第几天得到自己心仪的女武神。

    **核心思路**：一天共有 86400 秒，第 i 天可用于收集的时间是 86400-a\[i\]。 从第一天开始累加空闲时间，第一次达到所需总时间 t 的下标就是最早 天数。也可以每读一天便从 t 中减去当天空闲时间，首次 $t \le 0$ 时输出。 题目数据按其设定会在给定天数内完成；代码仍为异常输入保留 -1。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        long long required;
        cin >> n >> required;
        int ans = -1;
        for (int day = 1; day <= n; ++day) {
            long long occupied;
            cin >> occupied;
            if (ans == -1) {
                required -= 86400 - occupied;
                if (required <= 0)
                    ans = day;
            }
        }
        cout << ans << '\n';
        return 0;
    }
    ```
