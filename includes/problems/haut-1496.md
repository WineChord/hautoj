    **题意**：给了两个大小相同的数组a,b。现判断是否能通过一次给a中某个区间的元素都加上相同值（该值大于等于0），从而使数组a,b相等。

    **核心思路**：令 $d_{i}=b_{i}$-a\[i\]。一次给连续区间加非负常数，意味着 d 必须 形如“若干 0、若干个相同的正数、若干 0”。扫描时记录首个正差值， 进入正段后若遇到不同正数或离开正段后又遇正数，就不可能；任意 $d < 0$ 也立即失败。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n) 时间、O(n) 空间

    **易错点**：检查 0/1 起下标、$n = 1$、首尾元素和数组容量。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        vector<long long> a(n);
        for (long long& x : a)
            cin >> x;
        long long value = -1;
        bool ended = false, possible = true;
        for (int i = 0; i < n; ++i) {
            long long b;
            cin >> b;
            long long diff = b - a[i];
            if (diff < 0)
                possible = false;
            else if (diff == 0) {
                if (value != -1)
                    ended = true;
            } else {
                if (ended)
                    possible = false;
                if (value == -1)
                    value = diff;
                else if (value != diff)
                    possible = false;
            }
        }
        cout << (possible ? "YES" : "NO") << '\n';
        return 0;
    }
    ```
