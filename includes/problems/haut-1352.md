??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Choice的字符串

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1352>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组输出一行，表示展开后的字符串。

    **核心思路**：从左到右扫描。遇到字母就原样加入结果，并把它记作最近字符；遇到 一位数字 d，就把最近字符额外追加 d 次。数字不会成为新的最近字符， 因而 `c22` 是原有一个 c 再追加 2+2 个，共五个 c。第一位保证是字母。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：每组 O(输入长度+输出长度) 时间与空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            string encoded, decoded;
            cin >> encoded;
            char latest = '\0';
            for (char c : encoded) {
                if (isdigit((unsigned char)c)) {
                    decoded.append(c - '0', latest);
                } else {
                    latest = c;
                    decoded.push_back(c);
                }
            }
            cout << decoded << '\n';
        }
        return 0;
    }
    ```
