    **题目**：二进制翻转

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1818>){ .problem-source target="_blank" rel="noopener" }

    **题意**：你每次可以选择连续的一些0翻转成1，请计算把数组中所有元素变成1所需的最小翻转次数。

    **核心思路**：二进制翻转 根据题意只需要计算数组中连续的0的段数即是答案，注意到每个连续的0的段前面必定有一个1（如果起始为0单独计算），所以记录前1后0的位置的数量即是连续的0的段的数量。 c c++

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：通常为 O(n)

    **易错点**：检查 0/1 起下标、n = 1、首尾元素和数组容量。；检查 gcd/lcm 的 0 值、负数和乘法溢出。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int n;
    int a[200005];
    int main() {
        scanf("%d", &n);
        for (int i = 0; i < n; i++)
            scanf("%d", &a[i]);
        int ans = 0;
        if (a[0] == 0)
            ans++;
        for (int i = 1; i < n; i++) {
            if (a[i] == 0 && a[i - 1] == 1)
                ans++;
        }
        printf("%d\n", ans);
        return 0;
    }
    ```
