    **题目**：小唐的运气

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1932>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，能够追上则输出yes 追不上时输出no

    **核心思路**：小唐的运气 (a-b)*t &gt; x 时能追上。 #include &lt;bits/stdc++.h&gt;

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：常数级或一次线性读入；以代码中的循环层数为准

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    signed main() {
        int x, a, b, t;
        cin >> x >> a >> b >> t;
        if ((a - b) * t >= x) {
            cout << "yes" << endl;
            return 0;
        } else
            cout << "no" << endl;
        return 0;
    }
    ```
