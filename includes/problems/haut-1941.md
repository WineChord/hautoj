??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：挂谷集

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1941>){ .problem-source target="_blank" rel="noopener" }

    **题意**：挂谷转针问题，询问在平面上是否有一个面积最小的区域 D，在其中针可以旋转 360 度。 挂谷宗一于 1917 年首次对于凸集提出此问题。

    **核心思路**：题面给出长为 1 的针所需最小凸集面积为 1/sqrt(3)。长度按 x 缩放时，所有线性尺度乘 x，面积因此乘 x²，所以答案为 x²/sqrt(3)。 用 fixed 与 setprecision(2) 完成四舍五入到两位小数。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按误差要求保留精度，不要只按样例字符数猜小数位。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long double x;
        cin >> x;
        long double area = x * x / sqrtl(3.0L);
        cout << fixed << setprecision(2) << area << '\n';
        return 0;
    }
    ```
