    **题目**：cxk的进制转换问题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1478>){ .problem-source target="_blank" rel="noopener" }

    **题意**：cxk的进制转换问题

    **核心思路**：反复取 n%m 得到从低位到高位的各位，把它们反转后输出。$n=0$ 时循环不会执行，需单独输出 0；$m \le 9$，所以每一位可直接用字符表示。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(log\_m n) 时间、O(log\_m n) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long n;
        int base;
        cin >> n >> base;
        if (n == 0) {
            cout << 0 << '\n';
            return 0;
        }
        string ans;
        while (n > 0) {
            ans += char('0' + n % base);
            n /= base;
        }
        reverse(ans.begin(), ans.end());
        cout << ans << '\n';
        return 0;
    }
    ```
