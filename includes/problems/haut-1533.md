    **题目**：小青的线性代数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1533>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，代表行列式的值

    **核心思路**：阶数只有 1、2、3，分别套用行列式公式。三阶采用第一行展开： a(ei−fh)−b(di−fg)+c(dh−eg)。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(n²) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        long long a[3][3] = {};
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j)
                cin >> a[i][j];
        }
        long long ans;
        if (n == 1)
            ans = a[0][0];
        else if (n == 2)
            ans = a[0][0] * a[1][1] - a[0][1] * a[1][0];
        else {
            ans = a[0][0] * (a[1][1] * a[2][2] - a[1][2] * a[2][1]) -
                  a[0][1] * (a[1][0] * a[2][2] - a[1][2] * a[2][0]) +
                  a[0][2] * (a[1][0] * a[2][1] - a[1][1] * a[2][0]);
        }
        cout << ans << '\n';
        return 0;
    }
    ```
