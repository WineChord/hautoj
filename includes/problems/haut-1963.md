??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：冥界的人员统计

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1963>){ .problem-source target="_blank" rel="noopener" }

    **题意**：新的逝者注册时，他将向系统发送一则内容为其名称的请求，如果该名称尚未存在于系统数据库内，则将该名称插入数据库，同时得到回应信息"OK"表示其已经成功登记。如果他请求的用户名已经存在于数据库内，那么系统将产生一个新的名称并将其加入数据库。新名称由逝者请求的名称与正整数i构成，i 为使 "名称i" 尚未存在于数据库内的最小的 i。

    **核心思路**：哈希表 count\[name\] 既表示名字已注册，也保存下次应尝试的后缀。 首次出现输出 OK 并把计数设为 1；再次出现输出 name+count，再把计数 加一。按该题的标准数据，系统生成名不会与未来原始名产生冲突；若要 做通用版，可把生成名也写入表中。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：期望 O(总字符数) 时间、O(n) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        unordered_map<string, int> count;
        while (n--) {
            string name;
            cin >> name;
            if (!count.count(name)) {
                cout << "OK\n";
                count[name] = 1;
            } else {
                string created = name + to_string(count[name]++);
                while (count.count(created)) {
                    created = name + to_string(count[name]++);
                }
                cout << created << '\n';
                count[created] = 1;
            }
        }
        return 0;
    }
    ```
