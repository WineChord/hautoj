    **题目**：将故事写成我们

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1776>){ .problem-source target="_blank" rel="noopener" }

    **题意**：只有最后两个烟花到达同一位置才视为相汇，即它们的轨迹拼成一个爱心。小坚书直实和一行琉璃正在欣赏烟花，所以他想请你判断烟花的轨迹是否有可能拼成一个爱心。

    **核心思路**：两个烟花可以分别选择是否执行每条指令。对任意一条水平方向指令， 它对两烟花横坐标差的改变量可为 -1、0、1；因此 H 条水平指令能把 横坐标差调整为 &#91;-H,H&#93; 内任意整数。纵坐标同理。两个方向相互独立， 所以只需同时满足初始横差不超过 H、纵差不超过 V。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(|S|) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int x1, y1, x2, y2;
        string commands;
        cin >> x1 >> y1 >> x2 >> y2 >> commands;
        int horizontal = 0, vertical = 0;
        for (char c : commands) {
            if (c == 'L' || c == 'R')
                ++horizontal;
            else
                ++vertical;
        }
        bool possible = abs(x1 - x2) <= horizontal && abs(y1 - y2) <= vertical;
        cout << (possible ? "Explosion" : "Safe") << '\n';
        return 0;
    }
    ```
