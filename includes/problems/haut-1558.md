    **题目**：我劝你们这些年轻人，不要轻易碰此题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1558>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于每轮游戏来说，每行输出一个结果。 如果阿正的数比Love_Jacques的数大，输出"AZNB" 如果Love_Jacques的数比阿正的数大，输出"YZNB" 如果阿正的数跟Love_Jacques的数一样大，输出"EASY GAME!" 输出不带引号

    **核心思路**：不能转成浮点数，因为小数可有 1000 位。把整数部分与小数部分 分开，先比较整数位；相同后把小数末尾无意义的 0 删除，再补齐到 相同长度按字典序比较。这样 1.2 与 1.20 会被判为相等。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(|x|+|y|) 时间、O(|x|+|y|) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    pair<string, string> splitNumber(string s) {
        size_t dot = s.find('.');
        string integer = dot == string::npos ? s : s.substr(0, dot);
        string fraction = dot == string::npos ? "" : s.substr(dot + 1);
        while (!fraction.empty() && fraction.back() == '0')
            fraction.pop_back();
        return {integer, fraction};
    }
    int cmp(const string& a, const string& b) {
        auto [ai, af] = splitNumber(a);
        auto [bi, bf] = splitNumber(b);
        if (ai != bi)
            return ai < bi ? -1 : 1;
        size_t len = max(af.size(), bf.size());
        af.resize(len, '0');
        bf.resize(len, '0');
        if (af == bf)
            return 0;
        return af < bf ? -1 : 1;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            string x, y;
            cin >> x >> y;
            int relation = cmp(x, y);
            if (relation > 0)
                cout << "AZNB\n";
            else if (relation < 0)
                cout << "YZNB\n";
            else
                cout << "EASY GAME!\n";
        }
        return 0;
    }
    ```
