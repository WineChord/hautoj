    **题目**：调查员三宝之旧印

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1782>){ .problem-source target="_blank" rel="noopener" }

    **题意**：打开旧印的密码是三个未知正整数x,y,z($x \le y \le z$)。旧印上的提示有七个正整数，是x，y，z，x+y，x+z，y+z，x+y+z这七个数的某种排列。请你帮调查员求出x，y，z分别是什么。

    **核心思路**：调查员三宝之旧印： 分析：$x \le y \le z$，显然七个数中，最小的是x，次小的是y，最大的是x+y+z 将7个数排序后，依次输出最小的，次小的，最大的减去最小的和次小的

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：通常为 O(n)

    **易错点**：检查 0/1 起下标、$n = 1$、首尾元素和数组容量。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        int a[10];
        for (int i = 1; i <= 7; i++) {
            scanf("%d", &a[i]);
        }
        for (int i = 1; i <= 7; i++) {
            for (int j = i + 1; j <= 7; j++) {
                if (a[i] > a[j]) {
                    int t = a[i];
                    a[i] = a[j];
                    a[j] = t;
                }
            }
        }
        printf("%d %d %d", a[1], a[2], a[7] - a[1] - a[2]);
        return 0;
    }
    ```
