    **题目**：新建 Microsoft PowerPoint 演示文稿.pptx

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1560>){ .problem-source target="_blank" rel="noopener" }

    **题意**：输入2：删除一个编号为 x 的文档，反馈文档是否删除成功

    **核心思路**：用布尔数组记录编号是否存在。新建时从 1 起寻找最小未占用编号； 编号 1 使用无括号的基础文件名，编号大于 1 才加 (x)。删除时按 当前占用状态分别反馈 Successful 或 Failed。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：最坏 O(n²) 时间、O(n) 空间；n&lt;1000

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<bool> used(n + 2, false);
        while (n--) {
            int type;
            cin >> type;
            if (type == 1) {
                int id = 1;
                while (used[id])
                    ++id;
                used[id] = true;
                cout << "新建 Microsoft PowerPoint 演示文稿";
                if (id > 1)
                    cout << '(' << id << ')';
                cout << ".pptx\n";
            } else {
                int id;
                cin >> id;
                if (id < (int)used.size() && used[id]) {
                    used[id] = false;
                    cout << "Successful\n";
                } else {
                    cout << "Failed\n";
                }
            }
        }
        return 0;
    }
    ```
