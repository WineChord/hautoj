    **题目**：移动坐标

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1340>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给你两个点A、B，和固定移动距离（x,y），问是否可以通过移动A点若干次最终到B点。

    **核心思路**：设横、纵方向分别需要净走 p=(x2-x1)/x、q=(y2-y1)/y 个单位步。 首先两个差必须能整除固定步长。走 k 次时，每一维都是 k 个 ±1 的和， 所以其绝对净步数不超过 k，且与 k 同奇偶。k 可以任意增大，因此只需 |p| 与 |q| 同奇偶：此时选足够大的同奇偶 k，两维都能安排出相应数量 的正负步。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long x1, y1, x2, y2, xStep, yStep;
            cin >> x1 >> y1 >> x2 >> y2;
            cin >> xStep >> yStep;
            long long dx = x2 - x1;
            long long dy = y2 - y1;
            bool possible = dx % xStep == 0 && dy % yStep == 0;
            if (possible) {
                long long horizontal = llabs(dx / xStep);
                long long vertical = llabs(dy / yStep);
                possible = horizontal % 2 == vertical % 2;
            }
            cout << (possible ? "YES" : "NO") << '\n';
        }
        return 0;
    }
    ```
