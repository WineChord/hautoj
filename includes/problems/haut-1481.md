??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：欢天喜地

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1481>){ .problem-source target="_blank" rel="noopener" }

    **题意**：【欢】想成为最大的熊，或者至少比他的朋友ZP更大。如果达成目的【欢】会非常开心。

    **核心思路**：每过一年，欢的体重乘 3，ZP 的体重乘 2。循环到 $a > b$ 为止， 循环次数就是完整年数；等于还不算“更重”，所以条件必须是 $a \le b$。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(答案年数) 时间、O(1) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int a, b, years = 0;
        cin >> a >> b;
        while (a <= b) {
            a *= 3;
            b *= 2;
            ++years;
        }
        cout << years << '\n';
        return 0;
    }
    ```
