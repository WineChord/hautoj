    **题目**：存储单位进率

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1396>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组输出一个数X，代表后一个单位是前一个单位的2的X次方倍,每组占一行。

    **核心思路**：把所有单位统一换成“相对 1 bit 的二进制指数”：b=0、B=3， K=13、M=23、G=33、T=43。后一个单位是前一个单位的 2^(exp2-exp1) 倍，直接做指数相减；读到 0 0 停止。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；EOF 题不要读取不存在的 T，也不要多输出内容。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int exponent(char unit) {
        if (unit == 'b')
            return 0;
        if (unit == 'B')
            return 3;
        string larger = "KMGT";
        return 13 + 10 * larger.find(unit);
    }
    int main() {
        char first, second;
        while (cin >> first >> second && !(first == '0' && second == '0')) {
            cout << exponent(second) - exponent(first) << '\n';
        }
        return 0;
    }
    ```
