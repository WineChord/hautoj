    **题目**：趣味游戏（一）：喝饮料

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1329>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组样例输出一个整数表示需要买的饮料数目

    **核心思路**：喝饮料的共有 n+1 人。买 x 瓶可得到 x·m 杯；既要每人分到相同 的正整数杯数，又不能剩余，就要求 x·m 是 n+1 的倍数。最小总杯数是 lcm(n+1,m)，所以最少瓶数为 lcm/m=(n+1)/gcd(n+1,m)。用这个化简 还能避免先求最小公倍数时的乘法溢出。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(log min(n,m)) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    long long gcdll(long long a, long long b) {
        while (b) {
            long long r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long friends, per;
            cin >> friends >> per;
            long long people = friends + 1;
            cout << people / gcdll(people, per) << '\n';
        }
        return 0;
    }
    ```
