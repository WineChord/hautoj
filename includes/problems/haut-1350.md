    **题目**：Choice发糖果

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1350>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出Choice能带走的糖果的最大总价值，保留1位小数。输出占一行。

    **核心思路**：同一种糖果每颗价值相同，为 pi/mi。问题就是按单位价值做“可拆分 背包”：把所有种类按单颗价值从高到低排序，依次拿 min(剩余容量,mi) 颗，容量用完即停止。交换论证：若方案中拿了较便宜 的一颗却漏掉较贵的一颗，交换后价值只会增加，所以该贪心最优。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n log n) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；比较器必须满足严格弱序；相等时处理题目指定的次关键字。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    struct Candy {
        double unitPrice;
        int count;
    };
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, capacity;
        while (cin >> n >> capacity) {
            vector<Candy> candy(n);
            for (Candy& item : candy) {
                int totalPrice, count;
                cin >> totalPrice >> count;
                item = {(double)totalPrice / count, count};
            }
            sort(candy.begin(), candy.end(), [](const Candy& a, const Candy& b) {
                return a.unitPrice > b.unitPrice;
            });
            double ans = 0.0;
            for (const Candy& item : candy) {
                int take = min(capacity, item.count);
                ans += take * item.unitPrice;
                capacity -= take;
                if (capacity == 0)
                    break;
            }
            cout << fixed << setprecision(1) << ans << '\n';
        }
        return 0;
    }
    ```
