??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Choice学姐的众数问题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1321>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出mi中出现最多的那个数，占一行。

    **核心思路**：多数元素出现次数严格大于 n/2。Boyer–Moore 投票法维护候选者和 票数：票数为 0 时换成当前数；相同则加一，不同则减一。每次抵消掉 一对不同元素后，多数元素仍比所有其他元素总数更多，所以最终候选必是 答案。无需保存百万个数，也无需哈希表。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        long long cand = 0;
        int votes = 0;
        for (int i = 0; i < n; ++i) {
            long long value;
            cin >> value;
            if (votes == 0) {
                cand = value;
                votes = 1;
            } else if (value == cand) {
                ++votes;
            } else {
                --votes;
            }
        }
        cout << cand << '\n';
        return 0;
    }
    ```
