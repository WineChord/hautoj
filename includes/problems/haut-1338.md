    **题目**：多米诺骨牌

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1338>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，表示放入的多米诺骨牌的最大数量。

    **核心思路**：每块多米诺覆盖两个单位格，所以数量不可能超过 floor(MN/2)。 沿行（或列）成对铺放即可达到这个上界：面积为偶数时铺满，面积为奇数 时只剩一个格。因此答案就是整数除法 M*N/2。乘积最大 10^18，要用 long long。

    **正确性**：构造只使用题目允许的元素与操作。；每一步都维持长度、取值、相邻关系或总和等约束。；结束时规模达到要求，因此输出是完整合法答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；样例只是一个合法答案；本地检查约束，不要逐字比对。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long m, n;
            cin >> m >> n;
            cout << m * n / 2 << '\n';
        }
        return 0;
    }
    ```
