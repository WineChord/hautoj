    **题目**：小青的高等数学

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1532>){ .problem-source target="_blank" rel="noopener" }

    **题意**：第一节高数课高数老师就给小青来了一个惊喜（xia），他给了小青一个长度为n的序列A，其中序列中每个元素的范围都是1~m，同时保证这m个整数都出现在了序列里。现在高数老师要求小青选取序列中的两个数，使得两个数的和最小，同时还需要保证这两个数的和为质数，你可以告诉小青这个最小的和是多少吗？

    **核心思路**：题目保证 1..m 每个数都出现，且 m≥2。因此若 1 至少出现两次， 可选 1+1=2；否则一定可以选 1 和 2，得到质数 3。不存在更小的正 质数，答案只可能是 2 或 3。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m, ones = 0;
        cin >> n >> m;
        for (int i = 0, x; i < n; ++i) {
            cin >> x;
            if (x == 1)
                ++ones;
        }
        cout << (ones >= 2 ? 2 : 3) << '\n';
        return 0;
    }
    ```
