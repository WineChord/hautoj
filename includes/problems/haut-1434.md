    **题目**：优化算法

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1434>){ .problem-source target="_blank" rel="noopener" }

    **题意**：速度为(v*10^18次/s)的计算机。用这个优化后的算法能在几秒内计算出最优解。

    **核心思路**：算法运算量为 (S·10⁹)(n·10⁹)=Sn·10¹⁸，计算机每秒完成 v·10¹⁸ 次，秒数就是 Sn/v 向上取整，即 (Sn+v-1)/v。题目给定 范围下 Sn 可用 long long。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int T;
        cin >> T;
        while (T--) {
            long long capacity, number, speed;
            cin >> capacity >> number >> speed;
            cout << (capacity * number + speed - 1) / speed << '\n';
        }
        return 0;
    }
    ```
