    **题目**：数组求和

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1978>){ .problem-source target="_blank" rel="noopener" }

    **题意**：输入一个二维数组M&#91;12&#93;&#91;12&#93;,根据输入要求，求出二维数组的左下部分元素的平均值或元素的和。

    **核心思路**：数组求和 遍历求和即可。 #include &lt;stdio.h&gt; #include &lt;string.h&gt;

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：通常为 O(n)

    **易错点**：检查 0/1 起下标、n = 1、首尾元素和数组容量。；检查 gcd/lcm 的 0 值、负数和乘法溢出。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <string.h>
    int main() {
        char s[2];
        double t, ans = 0.0;
        scanf("%s", s);
        for (int i = 0; i < 12; i++) {
            for (int j = 0; j < 12; j++) {
                scanf("%lf", &t);
                if (i > j) {
                    ans += t;
                }
            }
        }
        if (strcmp(s, "S") == 0) {
            printf("%.1f\n", ans);
        } else {
            printf("%.1f\n", ans / 66);
        }
        return 0;
    }
    ```
