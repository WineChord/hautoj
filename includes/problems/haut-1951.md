    **题目**：卡厄斯兰娜的33550336次轮回

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1951>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，请输出第n世承载火种的是第几世的卡厄斯兰娜。

    **核心思路**：承载者只会在“完成一个完美数轮回”之后更新，因此需要找严格小于 n 的最大完美数；在第 0 世或尚未经过第一个完美数时输出 0。1e10 内的偶完美数可由欧几里得—欧拉公式列出，逐个更新最近值即可。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        unsigned long long n;
        cin >> n;
        const vector<unsigned long long> perfect = {6ULL,    28ULL,       496ULL,
                                                    8128ULL, 33550336ULL, 8589869056ULL};
        unsigned long long ans = 0;
        for (auto x : perfect) {
            if (x < n)
                ans = x;
            else
                break;
        }
        cout << ans << '\n';
        return 0;
    }
    ```
