    **题目**：小唐的饼干

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1935>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出小唐原来有多少瓶汽水。 答案可能很大，对114取余。

    **核心思路**：小唐的饼干 从第n天，每往前一天需要先加二再乘二，注意每中间数可能会很大，每一步运算都需要对114取模。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：通常为 O(n)；若循环嵌套或迭代范围不同，应按代码重新核算

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int const mod = 114;
    signed main() {
        int n;
        cin >> n;
        n--;
        int re = 1;
        while (n--)
            re = ((re + 2) * 2) % mod;
        cout << re;
        return 0;
    }
    ```
