    **题目**：曼曼曼曼曼哈顿

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1389>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，即乌拉拉经过两个点所需的最短距离

    **核心思路**：所求距离为曼哈顿距离 如点（0，0）和点（3，4） 这两个点的直线距离（欧几里得距离）为5 这两个点的曼哈顿距离为 3+4 = 7

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：常数级或一次线性读入；以代码中的循环层数为准

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <math.h>
    int main() {
        int min1, min2;
        int xa, ya, xb, yb;
        scanf("%d %d\n%d %d", &xa, &ya, &xb, &yb);
        min1 = abs(xa) + abs(ya) + abs(xa - xb) + abs(ya - yb);
        min2 = abs(xb) + abs(yb) + abs(xa - xb) + abs(ya - yb);
        if (min1 < min2) {
            printf("%d", min1);
        } else {
            printf("%d", min2);
        }
    }
    ```
