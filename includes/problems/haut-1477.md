    **题目**：cxk的篮球数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1477>){ .problem-source target="_blank" rel="noopener" }

    **题意**：cxk的篮球数

    **核心思路**：区间 &#91;L,R&#93; 同加 W 可用差分数组：difference&#91;L&#93;+=W， difference&#91;R+1&#93;-=W。所有操作后做一次前缀和即可恢复每个位置的 总增量，再加到初值；虽然只询问一个 x，这种写法也便于迁移到多询问。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n+m) 时间、O(n) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n, m;
        cin >> n >> m;
        vector<long long> a(n + 1), diff(n + 2, 0);
        for (int i = 1; i <= n; ++i)
            cin >> a[i];
        while (m--) {
            int l, r;
            long long w;
            cin >> l >> r >> w;
            diff[l] += w;
            diff[r + 1] -= w;
        }
        int target;
        cin >> target;
        long long added = 0;
        for (int i = 1; i <= target; ++i)
            added += diff[i];
        cout << a[target] + added << '\n';
        return 0;
    }
    ```
