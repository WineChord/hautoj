    **题目**：四则运算

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1037>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给你一个简单的四则运算表达式，包含两个实数和一个运算符，请编程计算出结果

    **核心思路**：读取两个实数和运算符，分别处理加、减、乘、除。只有除法时才需要 检查除数是否接近 0；不能把“第二个操作数为 0”误判为所有运算都 非法。合法结果固定保留两位小数。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。；按误差要求保留精度，不要只按样例字符数猜小数位。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        double left, right;
        char op;
        cin >> left >> op >> right;
        cout << fixed << setprecision(2);
        if (op == '+')
            cout << left + right << '\n';
        else if (op == '-')
            cout << left - right << '\n';
        else if (op == '*')
            cout << left * right << '\n';
        else if (op == '/' && fabs(right) >= 1e-10) {
            cout << left / right << '\n';
        } else {
            cout << "Wrong input\n";
        }
        return 0;
    }
    ```
