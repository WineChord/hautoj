    **题目**：你能面对真正的内心吗

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1740>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，小圆做出了多少道题

    **核心思路**：你能面对真正的内心吗( 传送门)题目大意：小圆会按照顺序交题，那么用一个数来记录当前交到了第几题，那么进行一次循环即可。 时间复杂度: O(n)O(n)O(n)参考代码

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n)

    **易错点**：检查 0/1 起下标、$n = 1$、首尾元素和数组容量。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        int n, m;
        scanf("%d%d", &n, &m);
        int cnt = 0; // 记录当前做到第几题了
        for (int i = 1; i <= m; i++) {
            int x;
            scanf("%d", &x);
            if (x == cnt + 1)
                cnt++; // 判断x 是否是正确的题目号，当前做完的下一道
        }
        printf("%d\n", cnt);
        return 0;
    }
    ```
