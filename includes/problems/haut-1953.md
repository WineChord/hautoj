??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：幽蝶能留一缕芳

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1953>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个整数表示所有大阵的最大作用总和。

    **核心思路**：若一个阵旁有别的阵，它贡献 ai，否则贡献 bi。设有 k 个阵属于 至少含两阵的连续块，则 k 不能等于 1；它们至少占 k 个相邻点，其余 n-k 个孤立阵各需一个空点隔开，故需要 k+2(n-k) 个点。先把所有阵 按孤立贡献 bi 计入，再按 ai-bi 从大到小选择改为相邻状态，并枚举 所有几何上可行的 k。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        long long m;
        cin >> n >> m;
        vector<long long> diff(n);
        long long isolated = 0;
        for (int i = 0; i < n; ++i) {
            long long a, b;
            cin >> a >> b;
            isolated += b;
            diff[i] = a - b;
        }
        sort(diff.rbegin(), diff.rend());
        long long ans = LLONG_MIN;
        if (2LL * n - 1 <= m)
            ans = isolated;
        long long cur = isolated;
        for (int k = 1; k <= n; ++k) {
            cur += diff[k - 1];
            if (k >= 2 && k + 2LL * (n - k) <= m) {
                ans = max(ans, cur);
            }
        }
        cout << ans << '\n';
        return 0;
    }
    ```
