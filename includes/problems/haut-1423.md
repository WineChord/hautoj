    **题目**：Minecraft

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1423>){ .problem-source target="_blank" rel="noopener" }

    **题意**：求无限长的时间之后，是否整个n*m的区域都会被水布满

    **核心思路**：水只会增加不会消失，因此可以逐秒扫描：本轮把所有“当前至少有两个 四邻水格”的空地记下来，扫描完再统一变水，保证符合题目的同步更新。 如果某轮没有新增格子便达到稳定状态；此时检查是否还存在 0。格子最多 64 个，所以最多发生 64 轮有效变化。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组最坏 O((nm)²) 时间、O(nm) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        const int dx[4] = {-1, 1, 0, 0};
        const int dy[4] = {0, 0, -1, 1};
        while (T--) {
            int n, m;
            cin >> n >> m;
            vector<vector<int>> water(n, vector<int>(m));
            for (auto& row : water)
                for (int& cell : row)
                    cin >> cell;
            while (true) {
                vector<pair<int, int>> added;
                for (int i = 0; i < n; ++i) {
                    for (int j = 0; j < m; ++j) {
                        if (water[i][j])
                            continue;
                        int neighbors = 0;
                        for (int d = 0; d < 4; ++d) {
                            int x = i + dx[d], y = j + dy[d];
                            if (0 <= x && x < n && 0 <= y && y < m)
                                neighbors += water[x][y];
                        }
                        if (neighbors >= 2)
                            added.push_back({i, j});
                    }
                }
                if (added.empty())
                    break;
                for (auto [i, j] : added)
                    water[i][j] = 1;
            }
            bool full = true;
            for (const auto& row : water)
                for (int cell : row)
                    full &= (cell == 1);
            cout << (full ? "YES" : "NO") << '\n';
        }
        return 0;
    }
    ```
