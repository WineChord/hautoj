    **题目**：Run out of Prison

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1368>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个小数表示答案，精确到小数点后5位

    **核心思路**：两人可以事先约定：看到编号 i 就猜对方也是 i。两次独立摸球共有 n² 个等可能有序对，只有 (1,1),(2,2),…,(n,n) 这 n 对会使两人 同时猜中，所以成功率为 1/n。任何确定性策略都对应两张从编号到猜测的 映射；每个自己摸到的编号至多与一个对方编号组成双方同时正确的配对， 有利有序对不可能超过 n，因此 1/n 已是最优。

    **正确性**：构造只使用题目允许的元素与操作。；每一步都维持长度、取值、相邻关系或总和等约束。；结束时规模达到要求，因此输出是完整合法答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：样例只是一个合法答案；本地检查约束，不要逐字比对。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            double n;
            cin >> n;
            cout << fixed << setprecision(5) << 1.0 / n << '\n';
        }
        return 0;
    }
    ```
