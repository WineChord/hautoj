??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：蚂蚁

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1215>){ .problem-source target="_blank" rel="noopener" }

    **题意**：n只蚂蚁以每秒1cm的速度在长为Lcm的竿子上爬行。当蚂蚁爬到竿子的端点时就会掉落。由于竿子太细，两只蚂蚁相遇时，它们不能交错通过，只能各自反向爬回去。对于每只蚂蚁，我们知道它距离竿子左端的距离x，但不知道它当前的朝向。请计算所有蚂蚁落下竿子可能需要的最长时间。

    **核心思路**：两只蚂蚁相遇后同时反向，与它们保持方向、彼此穿过的几何轨迹完全 等价，只是交换了身份。因此可把每只蚂蚁独立看待。为了让全部掉落时间 尽量长，每只蚂蚁可朝更远端爬，位置 x 的最远距离是 max(x,L-x)； 所有蚂蚁中的最大值就是最终时间。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        long long len;
        int n;
        cin >> len >> n;
        long long ans = 0;
        for (int i = 0; i < n; ++i) {
            long long pos;
            cin >> pos;
            ans = max(ans, max(pos, len - pos));
        }
        cout << ans << '\n';
        return 0;
    }
    ```
