??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：Flowers

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1227>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出答案k，表示最多的花束数量。

    **核心思路**：一束花要么消耗同色 3 朵，要么三色各 1 朵。设先做 t 束混色花， 总数为 t+(a-t)/3+(b-t)/3+(c-t)/3。若 t 增加 3，混色束多 3， 三种单色束各少 1，总数不变，所以只需尝试 t=0,1,2（且不能超过 最少的颜色数），取最大值即可。这避免了对 int 级数量逐束枚举。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        long long a, b, c;
        cin >> a >> b >> c;
        long long ans = 0;
        for (long long mixed = 0; mixed <= min({2LL, a, b, c}); ++mixed) {
            ans = max(ans, mixed + (a - mixed) / 3 + (b - mixed) / 3 + (c - mixed) / 3);
        }
        cout << ans << '\n';
        return 0;
    }
    ```
