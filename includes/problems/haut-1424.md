??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：Greedy

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1424>){ .problem-source target="_blank" rel="noopener" }

    **题意**：问如何才能使得这个表达式的值最大

    **核心思路**：把输入中的正数看成前面的“+”，负数看成前面的“-”，括号只能改变 结合顺序。令 mx&#91;l&#93;&#91;r&#93;、mn&#91;l&#93;&#91;r&#93; 分别为子表达式能取得的最大、最小值。 枚举最后一次把区间切在 k：若连接符是加号，最大加最大、最小加最小； 若是减号，最大值用左最大减右最小，最小值用左最小减右最大。由短区间 向长区间计算，mx&#91;0&#93;&#91;n-1&#93; 即答案。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(n³) 时间、O(n²) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        while (cin >> n) {
            vector<long long> input(n), value(n);
            vector<char> op(n, '+');
            for (int i = 0; i < n; ++i) {
                cin >> input[i];
                value[i] = llabs(input[i]);
                if (i > 0 && input[i] < 0)
                    op[i] = '-';
            }
            value[0] = input[0];
            const long long INF = (1LL << 60);
            vector<vector<long long>> mn(n, vector<long long>(n, INF));
            vector<vector<long long>> mx(n, vector<long long>(n, -INF));
            for (int i = 0; i < n; ++i)
                mn[i][i] = mx[i][i] = value[i];
            for (int len = 2; len <= n; ++len) {
                for (int left = 0; left + len <= n; ++left) {
                    int right = left + len - 1;
                    for (int split = left; split < right; ++split) {
                        if (op[split + 1] == '+') {
                            mx[left][right] =
                                max(mx[left][right], mx[left][split] + mx[split + 1][right]);
                            mn[left][right] =
                                min(mn[left][right], mn[left][split] + mn[split + 1][right]);
                        } else {
                            mx[left][right] =
                                max(mx[left][right], mx[left][split] - mn[split + 1][right]);
                            mn[left][right] =
                                min(mn[left][right], mn[left][split] - mx[split + 1][right]);
                        }
                    }
                }
            }
            cout << mx[0][n - 1] << '\n';
        }
        return 0;
    }
    ```
