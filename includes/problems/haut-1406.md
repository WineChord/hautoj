??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：寻找遗迹

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1406>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，绘制后的示意图，字符占10行。 每行10个字符，字符之间用空格隔开。 其中，用减号“-”表示未划线的部分，用星号“*”来代表划线。

    **核心思路**：用 mark&#91;x&#93;&#91;y&#93; 表示坐标纸格点是否画线。每个矩形把上下两条横边 的所有 x、左右两条竖边的所有 y 标为星号。输出从 y=10 到 y=1， 每行 x=1..10，正好对应以左下角为原点的坐标系。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(N·10+100) 时间、O(100) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        bool mark[11][11] = {};
        while (n--) {
            int x1, y1, x2, y2;
            cin >> x1 >> y1 >> x2 >> y2;
            for (int x = x1; x <= x2; ++x)
                mark[x][y1] = mark[x][y2] = true;
            for (int y = y1; y <= y2; ++y)
                mark[x1][y] = mark[x2][y] = true;
        }
        for (int y = 10; y >= 1; --y) {
            for (int x = 1; x <= 10; ++x) {
                if (x > 1)
                    cout << ' ';
                cout << (mark[x][y] ? '*' : '-');
            }
            cout << '\n';
        }
        return 0;
    }
    ```
