    **题目**：Choice学姐买糖果 II

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1320>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出Choice学姐心里所想的，占一行(不要输出多余的空格)。

    **核心思路**：共输出 n 个短语，第 1、3、5…项是 `I love`，第 2、4、6…项是 `I hate`。相邻项之间输出 ` or `，最后一项后输出 ` it`。把分隔符放在 第 2 项及以后之前，可避免首尾多余空格。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        for (int i = 1; i <= n; ++i) {
            if (i > 1)
                cout << " or ";
            cout << (i % 2 == 1 ? "I love" : "I hate");
        }
        cout << " it\n";
        return 0;
    }
    ```
