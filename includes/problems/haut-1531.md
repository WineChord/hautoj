??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：小青的班委竞选

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1531>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于每组输入，输出答案占一行，代表该张卡片背面的英文

    **核心思路**：数字 1 到 7 与星期英文一一对应，建立下标从 1 开始的查表数组。 输入没有给组数，使用 while(cin&gt;&gt;n) 读到文件尾。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：EOF 题不要读取不存在的 T，也不要多输出内容。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        const string weekday[8] = {"",         "monday", "tuesday",  "wednesday",
                                   "thursday", "friday", "saturday", "sunday"};
        int n;
        while (cin >> n)
            cout << weekday[n] << '\n';
        return 0;
    }
    ```
