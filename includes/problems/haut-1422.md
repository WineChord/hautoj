    **题目**：Math

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1422>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给你一个小于1的非负有理数的小数形式，求出它的分数形式，当然这个小数可能是无限循环小数

    **核心思路**：设小数点后非循环部分有 k 位、循环节有 r 位。若不存在循环节， 分数就是 A/10^k；若存在，令 A 为非循环数字形成的整数、AB 为 “非循环+一遍循环节”形成的整数，则 x=(AB-A)/(10^(k+r)-10^k)。最后用最大公约数约分；分母约成 1 时只输出整数。这个公式来自把 x 分别乘 10^k 和 10^(k+r) 后相减， 循环尾部会完全抵消。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(|s|+log V) 时间、O(|s|) 空间

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    long long power10(int exponent) {
        long long value = 1;
        while (exponent--)
            value *= 10;
        return value;
    }
    long long digitsValue(const string& s) {
        long long value = 0;
        for (char c : s)
            value = value * 10 + (c - '0');
        return value;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            string s;
            cin >> s;
            size_t dot = s.find('.');
            size_t leftBracket = s.find('[');
            string nonRepeat;
            string repeat;
            if (dot != string::npos) {
                size_t end = leftBracket == string::npos ? s.size() : leftBracket;
                nonRepeat = s.substr(dot + 1, end - dot - 1);
            }
            if (leftBracket != string::npos) {
                size_t r = s.find(']', leftBracket);
                repeat = s.substr(leftBracket + 1, r - leftBracket - 1);
            }
            long long p, q;
            if (repeat.empty()) {
                p = digitsValue(nonRepeat);
                q = power10((int)nonRepeat.size());
            } else {
                long long A = digitsValue(nonRepeat);
                long long AB = digitsValue(nonRepeat + repeat);
                p = AB - A;
                q = power10((int)(nonRepeat.size() + repeat.size())) -
                    power10((int)nonRepeat.size());
            }
            long long g = gcd(p, q);
            p /= g;
            q /= g;
            if (q == 1)
                cout << p << '\n';
            else
                cout << p << '/' << q << '\n';
        }
        return 0;
    }
    ```
