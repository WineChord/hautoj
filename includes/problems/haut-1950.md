??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：梦应归于何处

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1950>){ .problem-source target="_blank" rel="noopener" }

    **题意**：已知dream到阿斯德纳星系的路径可视为一条长为L的轴，n个传送站分散在数轴上(可能有多个传送站在相同位置).dream的初始位置为0(可视为第0个传送站),请判断他最多能到达第几个传送站.

    **核心思路**：把当前位置记为 current。第 i 个站的有效范围是 \[ai-bi,ai+bi\]；若 $current \ge ai$-bi，由于站点位置不降且只能由前向后， 就能进入该站并把 current 更新为 ai。第一次不满足时，后续站也无法 跳过到达，直接结束。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；检查 0/1 起下标、$n = 1$、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<long long> pos(n), radius(n);
        for (long long& x : pos)
            cin >> x;
        for (long long& x : radius)
            cin >> x;
        long long cur = 0;
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            if (pos[i] - radius[i] > cur)
                break;
            cur = pos[i];
            ans = i + 1;
        }
        cout << ans << '\n';
        return 0;
    }
    ```
