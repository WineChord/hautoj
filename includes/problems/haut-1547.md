    **题目**：递归式

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1547>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，T行,每行一个实数,答案保留三位小数

    **核心思路**：按定义先算 f0=a、f1=b。把递推式连续展开可发现 f5=a、f6=b， 因而整个序列以 5 为周期；每组只需算 f0..f4，再取 n%5 对应项。 这也是 T 和 n 都可达 1e5 时不能逐项递推的关键。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        cout << fixed << setprecision(3);
        while (T--) {
            double a, b;
            long long n;
            cin >> a >> b >> n;
            double f[5];
            f[0] = a;
            f[1] = b;
            for (int i = 2; i < 5; ++i)
                f[i] = (1.0 + f[i - 1]) / f[i - 2];
            cout << f[n % 5] << '\n';
        }
        return 0;
    }
    ```
