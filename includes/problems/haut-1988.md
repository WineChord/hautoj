??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：进制转换

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1988>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个正整数，表示转换之后的 m 进制数。

    **核心思路**：先逐位把源进制串转成十进制整数：$value=value \times n$+digit；再反复 对目标进制 m 取余得到从低到高的数字，最后逆序输出。数值范围不超过 $10^9$，long long 足够；特别处理 $value=0$。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(|s|+log\_m value) 时间、O(log\_m value) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int digitValue(char character) {
        if (isdigit(static_cast<unsigned char>(character)))
            return character - '0';
        return toupper(static_cast<unsigned char>(character)) - 'A' + 10;
    }
    char ch(int value) {
        return value < 10 ? char('0' + value) : char('A' + value - 10);
    }
    int main() {
        int srcBase, dstBase;
        string number;
        cin >> srcBase >> number >> dstBase;
        long long value = 0;
        for (char character : number) {
            value = value * srcBase + digitValue(character);
        }
        if (value == 0) {
            cout << "0\n";
            return 0;
        }
        string ans;
        while (value > 0) {
            ans.push_back(ch(value % dstBase));
            value /= dstBase;
        }
        reverse(ans.begin(), ans.end());
        cout << ans << '\n';
        return 0;
    }
    ```
