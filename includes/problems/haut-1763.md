    **题目**：这就是绝交证明书

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1763>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，共t行，每行输出一个答案，即从第l级到第r级阶梯上共写有多少个名字。

    **核心思路**：建立前缀和 prefix&#91;i&#93;，表示第 1 级到第 i 级楼梯的名字总数。 区间 &#91;l,r&#93; 的和等于 prefix&#91;r&#93;-prefix&#91;l-1&#93;，这样每次询问只做 两次数组访问和一次减法。总和最大约 1e8，int 足够，使用 long long 也能避免以后改范围时溢出。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：预处理 O(n)，每次询问 O(1)，空间 O(n)

    **易错点**：检查 0/1 起下标、n = 1、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<long long> prefix(n + 1, 0);
        for (int i = 1; i <= n; ++i) {
            long long x;
            cin >> x;
            prefix[i] = prefix[i - 1] + x;
        }
        int q;
        cin >> q;
        while (q--) {
            int l, r;
            cin >> l >> r;
            cout << prefix[r] - prefix[l - 1] << '\n';
        }
        return 0;
    }
    ```
