    **题目**：容斥原理

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1398>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出1~n中能被a或b或c整除的数的个数，每组占一行

    **核心思路**：用容斥原理：三个单集计数相加，减去三个两两交集，再加三者交集。 能同时被若干数整除等价于被它们的最小公倍数整除。计算 lcm 时使用 __int128 并在超过 n 后截断，避免乘法溢出。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(log 值域) 时间、O(1) 空间

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    template <class T>
    T gcdValue(T a, T b) {
        while (b != 0) {
            T r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    using i128 = __int128_t;
    long long cappedLcm(long long a, long long b, long long cap) {
        i128 value = (i128)(a / gcdValue(a, b)) * b;
        return value > cap ? cap + 1 : (long long)value;
    }
    int main() {
        long long n, a, b, c;
        while (cin >> n >> a >> b >> c && (n || a || b || c)) {
            long long ab = cappedLcm(a, b, n);
            long long ac = cappedLcm(a, c, n);
            long long bc = cappedLcm(b, c, n);
            long long abc = cappedLcm(ab, c, n);
            auto divisible = [&](long long d) {
                return d > n ? 0LL : n / d;
            };
            long long ans = n / a + n / b + n / c - divisible(ab) - divisible(ac) -
                            divisible(bc) + divisible(abc);
            cout << ans << '\n';
        }
        return 0;
    }
    ```
