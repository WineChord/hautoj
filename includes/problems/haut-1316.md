??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Choice学姐买糖果III

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1316>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出至少要拿多少次，答案占一行。

    **核心思路**：一个纸袋容量 w 且一次只能装一种糖果，所以第 i 种至少需要 ceil(mi/w) 个“袋次”。这些袋次可以任意两两配成一次搬运，因为 Choice 有两个袋子；最后若总袋次数为奇数，再单独搬一次。因此先求 bags=Σceil(mi/w)，答案为 ceil(bags/2)。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        long long capacity;
        cin >> n >> capacity;
        long long bags = 0;
        for (int i = 0; i < n; ++i) {
            long long count;
            cin >> count;
            bags += (count + capacity - 1) / capacity;
        }
        cout << (bags + 1) / 2 << '\n';
        return 0;
    }
    ```
