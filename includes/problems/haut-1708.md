    **题目**：对称括号序列

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1708>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行一个正整数代表由n对括号可以构造出多少种不同的合法对称括号序列。

    **核心思路**：设 f\[i\] 为使用 i 对括号、按题目规则能够构造出的序列数。在已有序列外包一对括号会从 f\[i-1\] 转移；在左右各添加一对则从 f\[i-2\] 转移，因此 $f_{i}=f$\[i-1\]+f\[i-2\]。预处理到所有测试中的最大 n，并对 $10^9$+7 取模。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：预处理 O(max n) 时间、O(max n) 空间；每组查询 O(1)

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；减法结果可能为负，必要时先加模数再取模。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <stdlib.h>
    #include <string.h>
    #include <math.h>
    const int MOD = 1e9 + 7;
    int t, n;
    long long F[1000005];
    int main() {
        scanf("%d", &t);
        F[1] = 1, F[2] = 2;
        for (int i = 3; i <= 1000004; i++)
            F[i] = (F[i - 1] % MOD + F[i - 2] % MOD) % MOD;
        while (t--) {
            scanf("%d", &n);
            printf("%lld\n", F[n]);
        }
        return 0;
    }
    ```
