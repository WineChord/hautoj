??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：那年那题那些AC

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1486>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出： 输出答案矩阵，输出是x行，每行z个数据，数据之间用空格隔开。

    **核心思路**：矩阵 M 为 x×y，N 为 y×z，结果 C 的第 i 行第 j 列等于 Σ(k=0..y-1)M&#91;i&#93;&#91;k&#93;·N&#91;k&#93;&#91;j&#93;。三重循环按定义计算，并控制每行元素 之间有一个空格、行末无多余空格。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(xyz) 时间、O(xy+yz) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int x, y, z;
        cin >> x >> y >> z;
        vector<vector<long long>> a(x, vector<long long>(y));
        vector<vector<long long>> b(y, vector<long long>(z));
        for (auto& row : a)
            for (long long& value : row)
                cin >> value;
        for (auto& row : b)
            for (long long& value : row)
                cin >> value;
        for (int i = 0; i < x; ++i) {
            for (int j = 0; j < z; ++j) {
                long long value = 0;
                for (int k = 0; k < y; ++k)
                    value += a[i][k] * b[k][j];
                if (j)
                    cout << ' ';
                cout << value;
            }
            cout << '\n';
        }
        return 0;
    }
    ```
