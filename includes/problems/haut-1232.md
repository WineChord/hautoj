    **题目**：手机剩余电量

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1232>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于每组实例，输出手机剩余电量。

    **核心思路**：电池内部是 10×10 字符格，共表示 100% 电量。从最底行、每行从 右向左填充 `!`：对从上到下的第 row 行，其对应电量区间可直接用全局 单元编号判断。更直观的实现是先计算 fullRows=n/10 与 remainder=n%10：底部 fullRows 行填满，再上一行右侧填 remainder 个，其余为空。每个实例紧接输出，不插空行。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(100) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int battery;
        while (cin >> battery && battery != -1) {
            cout << "*----------*\n";
            int fullRows = battery / 10;
            int rem = battery % 10;
            for (int rowFromTop = 0; rowFromTop < 10; ++rowFromTop) {
                int row = 9 - rowFromTop;
                int filled = 0;
                if (row < fullRows)
                    filled = 10;
                else if (row == fullRows)
                    filled = rem;
                cout << '|' << string(10 - filled, ' ') << string(filled, '!') << "|\n";
            }
            cout << "*----------*\n";
        }
        return 0;
    }
    ```
