??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：AC小将

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1491>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出较大的那四个数的和或者是较大的四个数的积

    **核心思路**：第一行四个数按南宫问天的规则求乘积，第二行四个数按刁民的规则 求和，输出二者较大值。最大乘积 20⁴，int 也可容纳，使用 long long 更稳妥。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long product = 1, sum = 0, x;
        for (int i = 0; i < 4; ++i) {
            cin >> x;
            product *= x;
        }
        for (int i = 0; i < 4; ++i) {
            cin >> x;
            sum += x;
        }
        cout << max(product, sum) << '\n';
        return 0;
    }
    ```
