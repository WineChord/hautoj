    **题目**：大大大大大扫除

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1393>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，第一行 k 个整数，表示第 k 次操作移动的书的总数 第二行，如果能能把全部的书挪走，则输出yes， 反之输出 no

    **核心思路**：记录每本书在原排列中的位置 pos。由于每次都取当前目标及其之前 的全部书，已移走部分始终是一个原排列前缀。维护前缀终点 removed： 若 pos&#91;w&#93;&gt;removed，本次移动 pos&#91;w&#93;-removed 本并更新终点；否则为 0。最终 removed=n 就已全部移走。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n+k) 时间、O(n) 空间

    **易错点**：检查 0/1 起下标、n = 1、首尾元素和数组容量。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<int> pos(n + 1);
        for (int i = 1, book; i <= n; ++i) {
            cin >> book;
            pos[book] = i;
        }
        int k, removed = 0;
        cin >> k;
        for (int i = 0; i < k; ++i) {
            int book;
            cin >> book;
            int moved = max(0, pos[book] - removed);
            removed = max(removed, pos[book]);
            if (i)
                cout << ' ';
            cout << moved;
        }
        cout << '\n' << (removed == n ? "yes" : "no") << '\n';
        return 0;
    }
    ```
