    **题目**：体育课（二）

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1387>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对每行输入，从小到大输出其对应的一组正整数 M，如果没有对应的正整数M，输出“无”（不含引号），第 i 组输出前要加上“Testi: ”，具体样式见样例输出。 （M的各位之和要等于D，且要求从左面读和从右面读是一样的，10000 &lt;= M &lt; 1000000，例如M=10001，M的各位之和为 1+0+0+0+1 为2，从左面读M：10001，……

    **核心思路**：先一次性枚举 10000 到 999999，判断十进制正读、反读是否相同， 再按数位和把所有回文数分组。每次询问只需输出对应分组；组为空时 输出“无”。预处理保证数字天然按从小到大排列。

    **正确性**：枚举范围包含每个可能答案，没有候选被遗漏。；判断条件与题目约束等价，所以只接受合法候选。；按题意计数、取最优或输出这些候选即可得到答案。

    **复杂度**：O(10^6+答案总量) 时间、O(回文数总量) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    bool pal(int number) {
        int original = number, reversed = 0;
        while (number > 0) {
            reversed = reversed * 10 + number % 10;
            number /= 10;
        }
        return original == reversed;
    }
    int digitSum(int number) {
        int sum = 0;
        while (number > 0) {
            sum += number % 10;
            number /= 10;
        }
        return sum;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        vector<vector<int>> bySum(55);
        for (int number = 10000; number < 1000000; ++number) {
            if (pal(number))
                bySum[digitSum(number)].push_back(number);
        }
        int T;
        cin >> T;
        for (int testCase = 1; testCase <= T; ++testCase) {
            int targetSum;
            cin >> targetSum;
            cout << "Test" << testCase << ":\n";
            if (bySum[targetSum].empty()) {
                cout << "无\n";
            } else {
                for (int number : bySum[targetSum])
                    cout << number << '\n';
            }
        }
        return 0;
    }
    ```
