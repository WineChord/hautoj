    **题目**：ReLU 函数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1863>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个数字：x 经过 f(x) 计算后的结果。

    **核心思路**：ReLU 定义为 max(0,x)：$x \le 0$ 时输出 0，否则输出 x。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int x;
        cin >> x;
        cout << max(0, x) << '\n';
        return 0;
    }
    ```
