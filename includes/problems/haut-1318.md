??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：Choice学姐买糖果 V

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1318>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出至少拿了多少张纸币，答案占一行。

    **核心思路**：要让纸币张数最少，应尽量使用面额最大的纸币。依次对 100、50、20、10、5、1 做整除，商加入张数、余数继续处理。若某方案 使用多张小面额而能换成一张更大面额，张数会减少，所以该贪心最优。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long amount;
        cin >> amount;
        const int coin[] = {100, 50, 20, 10, 5, 1};
        long long notes = 0;
        for (int value : coin) {
            notes += amount / value;
            amount %= value;
        }
        cout << notes << '\n';
        return 0;
    }
    ```
