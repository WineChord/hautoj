??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：zp与宝可梦（题面已修改）

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1510>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出概率，如果绝对误差或相对误差小于或等于10e-9，则认为答案正确。

    **核心思路**：对任意一个精灵球，一名参与者不选它的概率是 1-1/n，m 人都 不选的概率为 (1-1/n)^m，因此它被拿走的概率为一减该值。利用期望 的线性性乘 n，得到 n·(1-(1-1/n)^m)。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(log m) 量级幂运算时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long double n, m;
        cin >> n >> m;
        long double ans = n * (1.0L - powl(1.0L - 1.0L / n, m));
        cout << fixed << setprecision(12) << ans << '\n';
        return 0;
    }
    ```
