??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：糖果之“战”

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1837>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，t行，每一行都包含输入的相应测试用例的答案。如果可以按计划拿糖果，输出“YES”，否则输出“NO”。

    **核心思路**：题目强制每次从“当前数量最多”的种类中拿一颗。若最大数量比第二 大数量多至少 2，第一次拿最大类后它仍严格最多，下一次只能拿同类， 立即违反要求；反之最大值至多比次大值多 1，可以始终在并列最大类 之间交替。把不存在的第二类视为数量 0。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(Σn) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            long long largest = 0, sec = 0;
            for (int i = 0; i < n; ++i) {
                long long count;
                cin >> count;
                if (count >= largest) {
                    sec = largest;
                    largest = count;
                } else if (count > sec) {
                    sec = count;
                }
            }
            cout << (largest <= sec + 1 ? "YES" : "NO") << '\n';
        }
        return 0;
    }
    ```
