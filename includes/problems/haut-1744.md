??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：小C爱编程

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1744>){ .problem-source target="_blank" rel="noopener" }

    **题意**：现在，小C手头一共还有n项作业没写完，他知道完成每项作业所需的时间，请问，他最少还需要多长时间才能去打代码（即写完这些作业所需的最短时间）？

    **核心思路**：把作业分给两只手，若其中一只手承担总时长 s，另一只就是 sum-s，完成时间为 max(s,sum-s)。用 0/1 背包记录每个可达的子集和；每项作业倒序更新，最后枚举可达 s，取上述最大值的最小值。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(n×sum) 时间、O(sum) 空间

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int n, sum = 0, ans = 0x3f3f3f3f, a[1005], dp[200005];
    int main() {
        scanf("%d", &n);
        for (int i = 1; i <= n; i++) {
            scanf("%d", &a[i]);
            sum += a[i];
        }
        dp[0] = 1;
        for (int i = 1; i <= n; i++)
            for (int j = sum; j >= a[i]; j--) {
                if (dp[j - a[i]])
                    dp[j] = 1;
            }
        for (int i = 1; i <= sum; i++) {
            if (dp[i]) {
                int l = i, r = sum - i, k; // 左右手当前情况写作业的时间
                if (l > r)
                    k = l; // k为写作业的时间，即左右手写作业时间的较大者
                else
                    k = r;
                if (ans > k)
                    ans = k; // 每种情况都对答案进行更新
            }
        }
        printf("%d", ans);
        return 0;
    }
    ```
