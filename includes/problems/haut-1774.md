    **题目**：我愿意为你跨越世界的尽头

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1774>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出总统计次数

    **核心思路**：每组先读题目给出的字符串长度，再读字符串。seen&#91;26&#93; 标记大写 字母是否出现过：第一次贡献 2，以后贡献 1；非大写字符不计入。 长度字段本身不能误当成字符串处理。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(Σ|S|) 时间、O(1) 额外空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int len;
            string text;
            cin >> len >> text;
            array<bool, 26> seen{};
            int ans = 0;
            for (char ch : text) {
                if (ch < 'A' || ch > 'Z')
                    continue;
                int id = ch - 'A';
                ans += seen[id] ? 1 : 2;
                seen[id] = true;
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
