??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：卷王之争

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1589>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果小H的学习时间多，输出"H is juanwang!" ; 如果小T的学习时间多，输出"T is juanwang!" ; 如果两人学习时间一样多，输出"We are juanwang!" ; (输出不带引号)

    **核心思路**：卷王之争 比较两个分数大小； 法一：直接通分时要注意数据范围。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：常数级或一次线性读入；以代码中的循环层数为准

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <iostream>
    int main() {
        long long a, b, x, y;
        scanf("%d%d%d%d", &a, &b, &x, &y);
        a *= y;
        x *= b;
        if (a > x)
            printf("H is juanwang!\n");
        else if (a < x)
            printf("T is juanwang!\n");
        else
            printf("We are juanwang!\n");
        return 0;
    }
    ```
