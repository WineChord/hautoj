??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：零食采购员小C

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1748>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个整数x，即小C给每个同学x份零食时，才能使得班里快乐的人数最多。 若出现多个x值能使得班里快乐的人数最多，请输出其中最小的x值

    **核心思路**：每名同学在整数区间 \[a,b\] 内都会快乐。用差分数组在 a 加一、 b+1 减一，做前缀和后 count\[x\] 就是统一发 x 份时的快乐人数。从小 到大扫描，只在人数严格增加时更新答案，自动保留并列时最小的 x。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n+$10^5$) 时间、O($10^5$) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        const int LIMIT = 100000;
        vector<int> diff(LIMIT + 2, 0);
        while (n--) {
            int left, right;
            cin >> left >> right;
            ++diff[left];
            --diff[right + 1];
        }
        int cur = 0, bestCount = -1, ans = 1;
        for (int value = 1; value <= LIMIT; ++value) {
            cur += diff[value];
            if (cur > bestCount) {
                bestCount = cur;
                ans = value;
            }
        }
        cout << ans << '\n';
        return 0;
    }
    ```
