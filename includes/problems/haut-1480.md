    **题目**：男欢女爱

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1480>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果检查为女性，请打印"CHAT WITH HER!"（不带引号），否则，打印“IGNORE HIM!”。 （不带引号）。

    **核心思路**：统计用户名中不同小写字母的数量；偶数按题意判为女性，奇数判为 男性。26 位布尔数组即可去重。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(|name|) 时间、O(1) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        string name;
        cin >> name;
        array<bool, 26> exists{};
        for (char c : name)
            exists[c - 'a'] = true;
        int distinct = count(exists.begin(), exists.end(), true);
        cout << (distinct % 2 == 0 ? "CHAT WITH HER!" : "IGNORE HIM!") << '\n';
        return 0;
    }
    ```
