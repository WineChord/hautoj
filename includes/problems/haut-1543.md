??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：阿正的英语阅读

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1543>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出出现次数最多的英语单词，若出现次数最多的单词不唯一，请输出出现最早的。

    **核心思路**：逐词读取并用哈希表计数。某个词的新计数严格大于当前最大值时才 更新答案；相等时不更新，便自然保留最早出现的那个词。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：期望 O(单词数) 时间、O(不同单词数) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        unordered_map<string, int> count;
        string word, ans;
        int best = 0;
        while (cin >> word) {
            int now = ++count[word];
            if (now > best) {
                best = now;
                ans = word;
            }
        }
        cout << ans << '\n';
        return 0;
    }
    ```
