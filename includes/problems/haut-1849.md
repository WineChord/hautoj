    **题意**：根据给定输入，一个整数，表示小A能在该局游戏中获得的最大收益。

    **核心思路**：大富翁！启动！ 影响最终收益的有当前所处的位置和当前已经获取的金币。 考虑动态规划，dp&#91;i&#93;表示到第i个点时小A可以获取多少收益。那么dp&#91;i&#93;的最大值会从dp&#91;i-1&#93;，dp&#91;i-2&#93;,dp&#91;i-3&#93;,dp&#91;i-4&#93;,dp&#91;i-5&#93;,dp&#91;i-6&#93;中的最大值+第i格获取的金币。dp&#91;n+1&#93;即为终点。 注意，由于获取的金币可以为负数，需要初始化dp&#91;i&#93;为最小值。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：由状态数 × 单状态转移数决定，需结合题目范围核算

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；检查 0/1 起下标、n = 1、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    long long arr[110000];
    long long dp[110000];
    int main() {
        int n;
        scanf("%d", &n);
        for (int i = 1; i <= n; ++i) {
            scanf("%lld", &arr[i]);
        }
        for (int i = 1; i <= n + 10; ++i) {
            dp[i] = -1e12;
        }
        for (int i = 1; i <= n + 1; ++i) {
            for (int j = i - 1; j >= 0 && j >= i - 6; --j) {
                if (dp[j] > dp[i])
                    dp[i] = dp[j];
            }
            dp[i] += arr[i];
        }
        printf("%lld\n", dp[n + 1]);
        return 0;
    }
    ```
