    **题意**：根据给定输入，卷卷赢输出"火锅！" 聚聚赢输出"牛排!" （输出不带引号）

    **核心思路**：每次操作一定恰好拿走一颗石子；游戏最终会拿完全部石子，所以总 步数就是石子总数。总数为奇数时先手拿最后一颗并获胜，否则后手获胜。 只累计奇偶性即可，避免大数求和。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, parity = 0;
        cin >> n;
        for (int i = 0; i < n; ++i) {
            long long stones;
            cin >> stones;
            parity ^= int(stones & 1LL);
        }
        cout << (parity ? "火锅！" : "牛排!") << '\n';
        return 0;
    }
    ```
