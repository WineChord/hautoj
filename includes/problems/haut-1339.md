    **题目**：排队

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1339>){ .problem-source target="_blank" rel="noopener" }

    **题意**：问是否排成这种队形，如果可以输出“YES”，否则输出“NO”

    **核心思路**：排序后，最合理的分法一定是最矮的 n 人在前排、最高的 n 人在后排。 条件“前排任意人都严格矮于后排任意人”等价于前排最大值 a&#91;n-1&#93; &lt; 后排最小值 a&#91;n&#93;。若这里都不成立，换任何更高的人到前排 只会更差。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            vector<int> height(2 * n);
            for (int& x : height)
                cin >> x;
            sort(height.begin(), height.end());
            cout << (height[n - 1] < height[n] ? "YES" : "NO") << '\n';
        }
        return 0;
    }
    ```
