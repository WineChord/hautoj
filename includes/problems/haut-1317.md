    **题目**：Choice学姐买糖果 IV

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1317>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出要买的糖果个数，答案占一行。

    **核心思路**：在尚未有任何一种达到 k 个的前提下，第 i 种最多能买 min(mi,k-1) 个。把各类这个上限相加，就是“仍可能不满足要求”的最大 总数；再多买一个，无论它属于哪一类，必有一类达到 k。数据保证至少 有一种 $mi \ge k$，所以答案是该和加 1。这是带库存上限的鸽巢原理。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        long long k;
        cin >> n >> k;
        long long safeMaximum = 0;
        for (int i = 0; i < n; ++i) {
            long long count;
            cin >> count;
            safeMaximum += min(count, k - 1);
        }
        cout << safeMaximum + 1 << '\n';
        return 0;
    }
    ```
