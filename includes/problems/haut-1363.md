    **题目**：Hearthstone

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1363>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个百分数表示QAQ获胜的概率，精确到小数点后1位

    **核心思路**：把血量换成“还要挨多少次 10 点伤害”：QAQ 需要 p=ceil(A/10) 次死亡，对手需要 q=ceil(B/10) 次死亡。令 dp&#91;i&#93;&#91;j&#93; 表示双方还分别能挨 i、j 次时 QAQ 最终获胜的概率。若 i=0 则已失败，概率 0；若 j=0 则已获胜，概率 1；其他状态下一发各有一半打中一方，因此 dp&#91;i&#93;&#91;j&#93;=(dp&#91;i-1&#93;&#91;j&#93;+dp&#91;i&#93;&#91;j-1&#93;)/2。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(pq) 时间、O(pq) 空间，其中 p,q≤10

    **易错点**：setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int A, B;
        while (cin >> A >> B) {
            int p = (A + 9) / 10;
            int q = (B + 9) / 10;
            vector<vector<double>> dp(p + 1, vector<double>(q + 1));
            for (int i = 1; i <= p; ++i)
                dp[i][0] = 1.0;
            for (int i = 1; i <= p; ++i)
                for (int j = 1; j <= q; ++j)
                    dp[i][j] = (dp[i - 1][j] + dp[i][j - 1]) / 2.0;
            cout << fixed << setprecision(1) << dp[p][q] * 100.0 << "%\n";
        }
        return 0;
    }
    ```
