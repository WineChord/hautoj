??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：卡萨的阻拦

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1856>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，元素能量和

    **核心思路**：卡萨的阻拦 中等题 直接计算约数的耗时较大，应该会超时，考虑到一个比较小的数会是多个数的约数，所以直接计算这个数会被计算多少次 。对于输入的n， 对于某个 i ， i &lt;= n, 一共有 n / i 个数 有 i 这个 约数， 其中包括 i 本身 所以要减去 1， 所以单个 i 的贡献为 i * (n / i - 1)， 循环求和即可 。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：o(false)

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    typedef long long ll;
    void solve() {
        int n;
        cin >> n;
        ll ans = 0;
        for (int i = 1; i <= n; ++i) {
            ans = ans + i * (n / i - 1);
        }
        cout << ans;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(0);
        cout.tie(0);
        int test = 1;
        // cin >> test;
        while (test--) {
            solve();
        }
        return 0;
    }
    ```
