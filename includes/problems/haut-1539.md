??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：阿正的忐忑不安

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1539>){ .problem-source target="_blank" rel="noopener" }

    **题意**：现在给出阿正同学语数英综合四科的成绩和阿正心仪院校的录取分数线，如果阿正的总分达到（大于等于）了院校录取分数线，请输出文本“Blessings for your college career!”；否则请输出文本“Blessings for your "fourth grade" in high school!”。

    **核心思路**：四科相加后与录取线比较。未达到时输出文本内部还含一对双引号， C++ 字符串中要写成转义的 \"。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int a, b, c, d, line;
        cin >> a >> b >> c >> d >> line;
        if (a + b + c + d >= line) {
            cout << "Blessings for your college career!\n";
        } else {
            cout << "Blessings for your \"fourth grade\" in high school!\n";
        }
        return 0;
    }
    ```
