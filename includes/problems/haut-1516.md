    **题目**：HJ病毒

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1516>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组测试数据输出一行，每行包含一个整数

    **核心思路**：HJ病毒快速幂基础题 由1+1=2我们可以知道： 答案是 n×2tn×2^tn×2t然后用快速幂算出 即可，不要忘记取模2t2^t2t C++版代码

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：通常为 O(n)；若循环嵌套或迭代范围不同，应按代码重新核算

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <iostream>
    #define mod 1000000007
    using namespace std;
    typedef long long LL;
    LL n, t;
    LL q_w(LL x, LL t) {
        LL ans = 1;
        while (t) {
            if (t & 1)
                ans *= x, ans %= mod;
            x *= x;
            x %= mod;
            t >>= 1;
        }
        return ans;
    }
    int main() {
        while (cin >> n >> t) {
            cout << n * q_w(2, t) % mod << "\n";
        }
        return 0;
    }
    ```
