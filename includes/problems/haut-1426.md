??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Poem

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1426>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果修改后可以成为回文字符串，输出"YES"，否则输出"NO!"

    **核心思路**：比较每一对对称字符，统计不相等的对数。超过一对不相等时，一次改动 不可能全部修好；恰有一对时，改其中一个字符即可。若原串已经回文， 题目还要求新名字与原名不同：奇数长度可以只改中间字符且仍然回文， 偶数长度改任何一个字符都会破坏对称，所以分别为 YES 与 NO。注意失败 文本是带感叹号的 `NO!`。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(|s|) 时间、O(1) 额外空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            string s;
            cin >> s;
            int mismatches = 0;
            for (int left = 0, right = (int)s.size() - 1; left < right; ++left, --right) {
                mismatches += (s[left] != s[right]);
            }
            bool possible = mismatches == 1 || (mismatches == 0 && s.size() % 2 == 1);
            cout << (possible ? "YES" : "NO!") << '\n';
        }
        return 0;
    }
    ```
