??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：吓得我赶紧出了个签到题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1562>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，两行，第一行四个选项（全为大写，无空格），第二行输出填空题答案

    **核心思路**：四道选择题依次为 A、C、D、A。把题面给出的程序原样编译运行， 其七个字符输出为 lcltql!；本题只要求输出结论，不应附加空格或 解释。

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++14 编译通过；未提供成对公开样例

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << "ACDA\n";
        cout << "lcltql!\n";
        return 0;
    }
    ```
