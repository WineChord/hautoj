    **题目**：数字躲猫猫

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1928>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个整数，代表数字之和。

    **核心思路**：数字躲猫猫 注意a,b大小不确定，所以要先判断谁在前，然后循环把不带3的数字相加，注意每次相加都要取模。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：通常为 O(n)；若循环嵌套或迭代范围不同，应按代码重新核算

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <stdlib.h>
    const int mod = 1e9 + 7;
    int main() {
        int a, b;
        scanf("%d %d", &a, &b);
        if (a >= b) {
            int t;
            t = a;
            a = b;
            b = t;
        }
        int ans = 0;
        for (int i = a; i <= b; i++) {
            int x = i, f = 1;
            while (x) {
                int y = x % 10;
                if (y == 3) {
                    f = 0;
                    break;
                }
                x /= 10;
            }
            if (f)
                ans = (ans + i) % mod;
        }
        printf("%d", ans);
        return 0;
    }
    ```
