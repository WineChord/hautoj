    **题目**：最大公约数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1217>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给出两个数a和b，输出它们的最大公约数。

    **核心思路**：欧几里得算法利用 gcd(a,b)=gcd(b,a mod b)。不断把较大问题替换为余数问题，直到 b=0，此时 a 就是最大公约数。为兼容 C++14，参考实现直接手写这一迭代。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(log min(a,b)) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long a, b;
        cin >> a >> b;
        while (b != 0) {
            long long rem = a % b;
            a = b;
            b = rem;
        }
        cout << a << '\n';
        return 0;
    }
    ```
