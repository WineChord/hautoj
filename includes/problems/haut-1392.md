??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：玩玩玩玩玩石子

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1392>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果乌拉拉获胜，输出 wulala 如果挖哈哈获胜，输出 wahaha

    **核心思路**：从已取出的 a、b 通过加减能生成的编号恰为 gcd(a,b) 的倍数。 1..n 中共有 floor(n/g) 个；开局已移走的两颗不改变剩余数量的奇偶 性，所以该值为奇数时先手拿到最后一步获胜，偶数时后手获胜。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(log min(a,b)) 时间、O(1) 空间

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    template <class T>
    T gcdValue(T a, T b) {
        while (b != 0) {
            T r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    int main() {
        long long n, a, b;
        cin >> n >> a >> b;
        long long movesParity = (n / gcdValue(a, b)) % 2;
        cout << (movesParity ? "wulala" : "wahaha") << '\n';
        return 0;
    }
    ```
