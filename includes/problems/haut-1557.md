    **题目**：ACM脱单大法

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1557>){ .problem-source target="_blank" rel="noopener" }

    **题意**：可能会存在多个符合题目要求的下标x，请输出最小的x。（下标从1-n）

    **核心思路**：预处理 prefixMin/Max 与 suffixMin/Max。切点 x 合法，当且仅当 &#91;1,x&#93; 与 &#91;x+1,n&#93; 的最小值相同且最大值相同。按 x 从小到大检查， 首个合法值就是题目要求的最短第一部分。

    **正确性**：枚举范围包含每个可能答案，没有候选被遗漏。；判断条件与题目约束等价，所以只接受合法候选。；按题意计数、取最优或输出这些候选即可得到答案。

    **复杂度**：每组 O(n) 时间、O(n) 空间

    **易错点**：检查 0/1 起下标、n = 1、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            vector<long long> a(n), preMin(n), preMax(n), sufMin(n), sufMax(n);
            for (long long& x : a)
                cin >> x;
            preMin[0] = preMax[0] = a[0];
            for (int i = 1; i < n; ++i) {
                preMin[i] = min(preMin[i - 1], a[i]);
                preMax[i] = max(preMax[i - 1], a[i]);
            }
            sufMin[n - 1] = sufMax[n - 1] = a[n - 1];
            for (int i = n - 2; i >= 0; --i) {
                sufMin[i] = min(sufMin[i + 1], a[i]);
                sufMax[i] = max(sufMax[i + 1], a[i]);
            }
            int ans = -1;
            for (int i = 0; i + 1 < n; ++i) {
                if (preMin[i] == sufMin[i + 1] && preMax[i] == sufMax[i + 1]) {
                    ans = i + 1;
                    break;
                }
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
