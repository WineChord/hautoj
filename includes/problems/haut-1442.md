    **题目**：最大的最小区间

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1442>){ .problem-source target="_blank" rel="noopener" }

    **题意**：坐标轴上有n个点，选取k个点，使这k个点相邻的区间长度最小值最大

    **核心思路**：排序坐标。给定最小间距 d，从最左点开始，每次贪心选第一个距离 上一已选点至少 d 的点，这会为后面留下最大空间；若能选满 k 个则 d 可行。可行性对 d 单调，因此二分最大的可行 d。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n log 坐标差+n log n) 时间、O(n) 空间

    **易错点**：确认循环边界，以及最终返回第一个可行还是最后一个不可行。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；比较器必须满足严格弱序；相等时处理题目指定的次关键字。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, k;
        cin >> n >> k;
        vector<long long> point(n);
        for (long long& x : point)
            cin >> x;
        sort(point.begin(), point.end());
        auto possible = [&](long long distance) {
            int selected = 1;
            long long last = point[0];
            for (int i = 1; i < n && selected < k; ++i) {
                if (point[i] - last >= distance) {
                    last = point[i];
                    ++selected;
                }
            }
            return selected >= k;
        };
        long long low = 0, high = point.back() - point.front();
        while (low < high) {
            long long middle = low + (high - low + 1) / 2;
            if (possible(middle))
                low = middle;
            else
                high = middle - 1;
        }
        cout << low << '\n';
        return 0;
    }
    ```
