??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：阿正的换位排序

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1546>){ .problem-source target="_blank" rel="noopener" }

    **题意**：阿正随机写下了若干个序列，你的任务是判断这若干个序列能否在 &#91;n*(n-1)&#93;/2 -1 步内完成排序。

    **核心思路**：相邻交换排成非递减序的最少次数等于逆序对数。其理论最大值 n(n-1)/2 只在序列严格递减时出现；题目上限恰比该最大值少 1， 所以只有严格递减序列输出 No，其余全部输出 Yes。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(n) 时间、O(n) 空间

    **易错点**：EOF 题不要读取不存在的 T，也不要多输出内容。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        while (cin >> n) {
            vector<long long> a(n);
            for (long long& x : a)
                cin >> x;
            bool dec = true;
            for (int i = 1; i < n; ++i) {
                if (a[i - 1] <= a[i])
                    dec = false;
            }
            cout << (dec ? "No" : "Yes") << '\n';
        }
        return 0;
    }
    ```
