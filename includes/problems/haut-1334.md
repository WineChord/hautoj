    **题目**：趣味游戏（六）：爬楼梯

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1334>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，每组样例输出一个整数 表示走到第 n 层楼可以有多少种不同的走法。

    **核心思路**：到达一段连续 m 阶楼梯的最后位置，每一步可走 1、2、3 阶。设 ways&#91;i&#93; 为恰好走完 i 阶的方案数，最后一步分别来自 i-1、i-2、i-3， 所以 ways&#91;i&#93;=三者之和，ways&#91;0&#93;=1，负下标视为 0。楼层编号 n 只提供背景，实际方案只由台阶数 m 决定。结果每步取模。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：每组 O(m) 时间、O(m) 空间

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；减法结果可能为负，必要时先加模数再取模。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        const long long MOD = 1000000007LL;
        int T;
        cin >> T;
        while (T--) {
            int floorNumber, stairs;
            cin >> floorNumber >> stairs;
            vector<long long> ways(stairs + 1, 0);
            ways[0] = 1;
            for (int i = 1; i <= stairs; ++i) {
                for (int step = 1; step <= 3; ++step)
                    if (i >= step)
                        ways[i] = (ways[i] + ways[i - step]) % MOD;
            }
            cout << ways[stairs] << '\n';
        }
        return 0;
    }
    ```
