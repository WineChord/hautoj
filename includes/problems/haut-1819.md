    **题目**：二进制扩列

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1819>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，最初的字符串可能的最短长度。

    **核心思路**：二进制扩列 由题意知原先的字符串经过扩展后必定是一边一个0另一边一个1，所以使用两个变量标记左右边界，如果符和一边是0另一边是1则符和条件，可以继续收缩。由于你要得到最短的最初的字符串，所以你只要找到不符合的位置，然后输出此时字符串的长度即可。 c c++

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：通常为 O(n)

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；检查 gcd/lcm 的 0 值、负数和乘法溢出。；检查 0/1 起下标、n = 1、首尾元素和数组容量。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    char s[100005];
    int main() {
        int n;
        scanf("%d%s", &n, s);
        int l = 0, r = n - 1, ans = 0;
        while (s[l] != s[r] && l < r) {
            l++, r--, ans++;
        }
        printf("%d\n", n - ans * 2);
        return 0;
    }
    ```
