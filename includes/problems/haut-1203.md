??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：取石子游戏

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1203>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果A获胜输出A，如果B获胜输出B

    **核心思路**：2 的幂模 3 只会在 1、2 间交替。若石子数是 3 的倍数，无论当前 玩家取哪个合法幂，都会把非 3 倍数局面留给对手；若不是 3 的倍数， 当前玩家可按余数取 1 或 2，把 3 的倍数留给对手。于是 3 的倍数为 必败态，先手 A 在其他局面必胜。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        cout << (n % 3 == 0 ? "B" : "A") << '\n';
        return 0;
    }
    ```
