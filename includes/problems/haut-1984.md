    **题目**：这是啥杯？

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1984>){ .problem-source target="_blank" rel="noopener" }

    **题意**：在昨日圆车中，我们一般用杯子的级别来形容干员的强度，比如中杯，大杯，超大杯，而干员强度又与许多方面有关，我们不考虑那么多，现在认为干员的强度只与dps，破甲线，总伤三个属性有关。而每一个属性现认为只有高或低之分。现在以dps，破甲线，总伤的顺序输入属性的高低，用1来代表高，用零来代表低。现在我们规定只有一个高属性为中杯干员，有两个高属性为大杯干员，有三个高属……

    **核心思路**：三个 0/1 分别表示三个属性是否高，只需统计 1 的个数。0、1、2、 3 个高属性分别对应题目规定的四个字符串；标点、空格和波浪线都必须 原样输出。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int a, b, c;
        cin >> a >> b >> c;
        int highCount = a + b + c;
        if (highCount == 0)
            cout << "zheshishabei?\n";
        else if (highCount == 1)
            cout << "medium cup\n";
        else if (highCount == 2)
            cout << "big cup\n";
        else
            cout << "super~ big~ cup~\n";
        return 0;
    }
    ```
