    **题目**：这年头难道有人不喜欢签到吗？

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1711>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个正整数表示1-n的十进制二进制数字的个数。

    **核心思路**：这年头难道有人不喜欢签到吗题意分析：这道题相当于是数字组合的问题，数字范围是1e9，那么我们可以先把该范围的所有符合的数字先提前预处理存一下，方便程序的实现。 具体分析：接下来的实现就是得到一个正整数n，首先先加上比n的位数少的符合的数字的个数，然后再对n所在的位数符合的数字进行判断，判断该问题时，我们可以从头往后处理，模拟处理。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：o(false)

    **易错点**：核对中英文标点、尾随空格和末尾换行。；检查 gcd/lcm 的 0 值、负数和乘法溢出。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        long long n;
        cin >> n;
        queue<long long> q;
        q.push(1);
        int ans = 0;
        while (!q.empty()) {
            long long x = q.front();
            q.pop();
            if (x > n)
                continue;
            ans++;
            if (x <= n / 10) {
                q.push(x * 10);
                q.push(x * 10 + 1);
            }
        }
        cout << ans << '\n';
        return 0;
    }
    ```
