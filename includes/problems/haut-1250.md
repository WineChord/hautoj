    **题目**：Simple学长玩游戏

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1250>){ .problem-source target="_blank" rel="noopener" }

    **题意**：你的任务是在每次换防之后，计算出若此时勇者要击杀某一支护卫队恶魔并见到大魔王，至少需要多少点初始防御力。

    **核心思路**：若勇者以初始防御 D 攻打一队，第 i 只恶魔（从 0 计）出现前已经 击杀 i 只，当前防御为 D+i。要存活需 D+i≥attack&#91;i&#93;，所以该队最低 初防是 max(attack&#91;i&#93;-i)。每次换防把两队指定长度的前缀取出并交换， 各自剩余后缀顺序不变；随后扫描所有非空队伍，取其最低初防的最小值。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：每次换防 O(总恶魔数) 时间、O(总恶魔数) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int need(const vector<int>& team) {
        int required = 0;
        for (int i = 0; i < (int)team.size(); ++i)
            required = max(required, team[i] - i);
        return required;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<vector<int>> team(n);
        for (auto& monsters : team) {
            int count;
            cin >> count;
            monsters.resize(count);
            for (int& attack : monsters)
                cin >> attack;
        }
        int q;
        cin >> q;
        while (q--) {
            int x, prefixX, y, prefixY;
            cin >> x >> prefixX >> y >> prefixY;
            --x;
            --y;
            vector<int> oldX = team[x];
            vector<int> oldY = team[y];
            vector<int> newX, newY;
            newX.insert(newX.end(), oldY.begin(), oldY.begin() + prefixY);
            newX.insert(newX.end(), oldX.begin() + prefixX, oldX.end());
            newY.insert(newY.end(), oldX.begin(), oldX.begin() + prefixX);
            newY.insert(newY.end(), oldY.begin() + prefixY, oldY.end());
            team[x] = move(newX);
            team[y] = move(newY);
            int ans = INT_MAX;
            for (const auto& monsters : team)
                if (!monsters.empty())
                    ans = min(ans, need(monsters));
            cout << ans << '\n';
        }
        return 0;
    }
    ```
