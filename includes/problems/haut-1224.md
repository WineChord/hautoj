    **题目**：Beru-taxi

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1224>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，Print a single real value — the minimum time Vasiliy needs to get in any of the Beru-taxi cars. You answer will be considered correct if its absolute or relative error does……

    **核心思路**：第 i 辆车直线驶向家，路程由欧氏距离公式 `sqrt((xi-a)²+(yi-b)²)` 给出，时间是路程除以速度 vi。遍历所有车 取最小时间，输出足够多的小数位以满足 1e-6 误差要求。使用 hypot 可直接、稳定地计算二维距离。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        double homeX, homeY;
        int n;
        cin >> homeX >> homeY >> n;
        double ans = numeric_limits<double>::infinity();
        for (int i = 0; i < n; ++i) {
            double x, y, speed;
            cin >> x >> y >> speed;
            ans = min(ans, hypot(x - homeX, y - homeY) / speed);
        }
        cout << fixed << setprecision(10) << ans << '\n';
        return 0;
    }
    ```
