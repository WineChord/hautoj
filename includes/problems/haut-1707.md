    **题意**：由于结果可能过大，请输出结果对1e9+7取模后的值。

    **核心思路**：子序列和枚举子序列计算总和的方式显然不现实，考虑枚举每位a&#91;i&#93;最总和造成的贡献。 假设包含a&#91;i&#93;的子序列共有k个，那么a&#91;i&#93;的贡献值便为a&#91;i&#93;*k； 假设对于当前子序列，a&#91;i&#93;已经选了，那么其他所有元素都有选和不选两种情况，最后包含的a&#91;i&#93;的子序列便有 个，n为序列总长度。2^{n-1}2n−12n−1举例如 ，求包含 a1,a2,a3,a4a1,a2,a3,a4a1,a2,a3,a4 的子序列共有多少个，那么 a1a1a1 选不选会分出来两种情况为a2a2a2 和 \{a1\}{a1}{a1}，\{a1,a2\}{a1,a2}{a1,a2} 选不选又分出来更多的情况，为a3a3a3，\{a1\},\{a1,a3\}\{a1,a2\},\{a1,a2,a3\}{a1},{a1,a3}{a1,a2},{a1,a2,a3}{a1},{a1,a3}{a1,a2},{a1,a2,a3} 同理，所以除了a4a4a4 以外其他元素要考虑n-1次，最后包含ai的子序列共有aiaiai 个。2^{n-1}2n−12n−1另一方面，计算 次方本题中可以在算每一位的贡献之前预处理出来，即开个for循环n次用一个数组2^{n-1}2n−12n−1，p&#91;\ &#93;p&#91; &#93;p&#91; &#93;存 pipipi 的值，或者可以直接用快速幂计算，不了解快速幂的可以学一下。2^i2i2i 此处为了照顾大多数人就不用快速幂了。ps：ps：ps

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：通常为 O(n)

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <stdlib.h>
    #include <string.h>
    #include <math.h>
    const int MOD = 1e9 + 7, maxn = 1e6 + 5;
    int n, a[1000005];
    long long BS[1000005];
    void init() {
        BS[0] = 1;
        for (int i = 1; i <= maxn - 1; i++) {
            BS[i] = (BS[i - 1] % MOD * 2) % MOD;
        }
    }
    int main() {
        init();
        scanf("%d", &n);
        long long res = 0;
        for (int i = 1; i <= n; i++) {
            scanf("%d", &a[i]);
            res = res % MOD + (a[i] % MOD * BS[n - 1] % MOD) % MOD;
        }
        printf("%lld\n", res);
        return 0;
    }
    ```
