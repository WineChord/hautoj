??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：迷宫探险

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1404>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，若可以走通，输出yes；否则输出no。

    **核心思路**：在固定 5×5 网格上从左下角做 BFS，只扩展上下左右且值为 1 的 未访问格子。最终查看右上角是否访问到，并按题目小写格式输出。

    **正确性**：建图把每个合法对象或状态映射为点，把合法关系映射为边。；扩展操作覆盖所有且仅覆盖合法转移，访问标记避免重复处理。；遍历结束后的可达性、距离或累计值与原问题一一对应。

    **复杂度**：O(25) 时间、O(25) 空间

    **易错点**：入队或递归时及时标记访问，避免重复状态和死循环。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int grid[5][5];
        for (auto& row : grid)
            for (int& x : row)
                cin >> x;
        bool visited[5][5] = {};
        queue<pair<int, int>> q;
        q.push({4, 0});
        visited[4][0] = true;
        const int dx[4] = {1, -1, 0, 0};
        const int dy[4] = {0, 0, 1, -1};
        while (!q.empty()) {
            auto [x, y] = q.front();
            q.pop();
            for (int d = 0; d < 4; ++d) {
                int nx = x + dx[d], ny = y + dy[d];
                if (nx >= 0 && nx < 5 && ny >= 0 && ny < 5 && grid[nx][ny] &&
                    !visited[nx][ny]) {
                    visited[nx][ny] = true;
                    q.push({nx, ny});
                }
            }
        }
        cout << (visited[0][4] ? "yes" : "no") << '\n';
        return 0;
    }
    ```
