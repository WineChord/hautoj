    **题目**：神奇的谕示裁定枢机

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1841>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于每组数据，输出保证一定能找到较重物品的最少称量次数。

    **核心思路**：一次称量最多产生 m+1 种结果：m 份中某份最重，或 m 份一样重 从而重物在未上秤的一份。做 k 次最多区分 (m+1)\^k 个候选，因此 答案是最小的 k 使该值不少于 n。循环乘 m+1，并用除法式上界避免 64 位溢出。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(log\_{m+1} n) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        unsigned long long n, m;
        cin >> n >> m;
        unsigned long long capacity = 1;
        int ans = 0;
        while (capacity < n) {
            ++ans;
            if (capacity > n / (m + 1))
                capacity = n;
            else
                capacity *= m + 1;
        }
        cout << ans << '\n';
        return 0;
    }
    ```
