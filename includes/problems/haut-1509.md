??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：zp与朋友

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1509>){ .problem-source target="_blank" rel="noopener" }

    **题意**：zp的朋友找到了他并且提出了宝可梦对战！对战的时候zp和他的朋友都必须喊出技能的名字，但是技能的名字在神秘力量的作用下成为了被打乱了顺序的字符串，zp必须在经过交换后得到从左往右读和从右往左读是一样的字符串才能释放技能，否则技能会无法释放。请你计算技能能否成功释放，如果能请计算最少的交换次数！交换的定义是：交换两个相邻的字符

    **核心思路**：先检查字符频次，奇数长度最多一个奇频字符、偶数长度不能有奇频， 否则 Impossible。用左右指针：从右端向左找与 s&#91;left&#93; 相同的字符， 找到后用相邻交换把它移到 right；若直到 left 都找不到，说明当前 字符是唯一中间字符，把它向右交换一格后重试。该贪心每步的移动量 都是不可避免的最小值。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n²) 时间、O(1) 额外空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        string s;
        cin >> n >> s;
        array<int, 26> count{};
        for (char c : s)
            ++count[c - 'a'];
        int odd = 0;
        for (int x : count)
            odd += x % 2;
        if (odd > n % 2) {
            cout << "Impossible\n";
            return 0;
        }
        long long swaps = 0;
        int left = 0, right = n - 1;
        while (left < right) {
            int match = right;
            while (match > left && s[match] != s[left])
                --match;
            if (match == left) {
                swap(s[left], s[left + 1]);
                ++swaps;
            } else {
                while (match < right) {
                    swap(s[match], s[match + 1]);
                    ++match;
                    ++swaps;
                }
                ++left;
                --right;
            }
        }
        cout << swaps << '\n';
        return 0;
    }
    ```
