??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：旅行

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1548>){ .problem-source target="_blank" rel="noopener" }

    **题意**：lcl从城市1出发，他的目标是除了出发的城市外，每个城市都到达并且只到达一次，在最后回到出发的城市，并且恰好用完预算，求一共有多少种不同的旅行方案

    **核心思路**：起点固定为城市 1，枚举其余 n-1 个城市的所有排列。对每个排列 累加 1→排列各点→1 的完整环路费用，恰等于 W 就计数。方向相反但 访问顺序不同的路线按题目算不同方案，会由排列自然分别统计。

    **正确性**：枚举范围包含每个可能答案，没有候选被遗漏。；判断条件与题目约束等价，所以只接受合法候选。；按题意计数、取最优或输出这些候选即可得到答案。

    **复杂度**：O((n-1)!·n) 时间、O(n²) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        long long budget;
        cin >> n >> budget;
        vector<vector<long long>> cost(n, vector<long long>(n));
        for (auto& row : cost)
            for (long long& x : row)
                cin >> x;
        vector<int> order;
        for (int city = 1; city < n; ++city)
            order.push_back(city);
        long long ans = 0;
        do {
            long long total = 0;
            int pre = 0;
            for (int city : order) {
                total += cost[pre][city];
                pre = city;
            }
            total += cost[pre][0];
            if (total == budget)
                ++ans;
        } while (next_permutation(order.begin(), order.end()));
        cout << ans << '\n';
        return 0;
    }
    ```
