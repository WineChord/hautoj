??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：求和

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1553>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，T行，每行一个整数，表示结果

    **核心思路**：题图定义 f(n)=Σ(i=0..n)x·i。提出常数 x，再用等差数列求和 0+1+…+n=n(n+1)/2，得到 f(n)=x·n(n+1)/2。乘法使用 long long。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long x, n;
            cin >> x >> n;
            cout << x * n * (n + 1) / 2 << '\n';
        }
        return 0;
    }
    ```
