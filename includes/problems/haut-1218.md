    **题目**：最大连续子段和

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1218>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给出n个数，求出n个数中最大连续子段和。

    **核心思路**：Kadane 算法维护“以当前位置结尾、值得继续保留的最大和” current。 加入 x 后若 current&lt;0，就把它重置为 0，因为负前缀只会拖累以后任意 子段；每步用 current 更新 answer。answer 初始为 0，恰好满足全负数 时输出 0 的特殊要求。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        long long cur = 0, ans = 0;
        for (int i = 0; i < n; ++i) {
            long long value;
            cin >> value;
            cur = max(0LL, cur + value);
            ans = max(ans, cur);
        }
        cout << ans << '\n';
        return 0;
    }
    ```
