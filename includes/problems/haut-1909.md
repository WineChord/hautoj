    **题目**：建房子

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1909>){ .problem-source target="_blank" rel="noopener" }

    **题意**：判断LY能把房子建好吗？如果能，判断LY还剩下的最大体力。

    **核心思路**：把“已消耗体力”当作 0/1 背包容量，dp&#91;j&#93; 表示恰好在不超过 j 体力限制下可搬到的最大体积。每块石头倒序更新，之后找到使体积至少 为 v 的最小消耗 j，最大剩余体力就是 c-j；找不到则输出 Impossible。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(nc) 时间、O(c) 空间

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int need, n, stamina;
        cin >> need >> n >> stamina;
        vector<int> mx(stamina + 1, 0);
        for (int i = 0; i < n; ++i) {
            int volume, cost;
            cin >> volume >> cost;
            for (int used = stamina; used >= cost; --used) {
                mx[used] = max(mx[used], mx[used - cost] + volume);
            }
        }
        for (int used = 0; used <= stamina; ++used) {
            if (mx[used] >= need) {
                cout << stamina - used << '\n';
                return 0;
            }
        }
        cout << "Impossible\n";
        return 0;
    }
    ```
