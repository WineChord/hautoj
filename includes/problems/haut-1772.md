??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Stay with you

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1772>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出最长单词链的长度

    **核心思路**：把单词按长度从短到长排序后，任何可能的前驱都已出现在当前词 之前。令 dp&#91;i&#93; 为以第 i 个词结尾的最长链；枚举所有更短或等长的 旧词 j，若 word&#91;j&#93; 是 word&#91;i&#93; 的前缀，则可用 dp&#91;j&#93;+1 更新。 相同单词也允许相邻，题面示例明确给出了重复 staywith。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(n²L) 时间，L≤20；O(n) 额外空间

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。；比较器必须满足严格弱序；相等时处理题目指定的次关键字。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<string> word(n);
        for (string& s : word)
            cin >> s;
        stable_sort(word.begin(), word.end(), [](const string& a, const string& b) {
            return a.size() < b.size();
        });
        vector<int> dp(n, 1);
        int ans = 1;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < i; ++j) {
                if (word[j].size() <= word[i].size() &&
                    word[i].compare(0, word[j].size(), word[j]) == 0) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            ans = max(ans, dp[i]);
        }
        cout << ans << '\n';
        return 0;
    }
    ```
