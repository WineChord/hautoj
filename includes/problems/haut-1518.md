    **题目**：最小的整数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1518>){ .problem-source target="_blank" rel="noopener" }

    **题意**：那么通过若干次类似的交换（或者不交换），我们能得到的大小最小的数字是什么呢？

    **核心思路**：奇数只能与相邻偶数交换，因此所有奇数内部的相对顺序不能改变， 所有偶数内部也不能改变；奇偶两条子序列则可以任意穿插。分别提取 两条子序列，每次选择当前队首较小的数字，就得到字典序最小合并。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(|s|) 时间、O(|s|) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        string number;
        while (cin >> number) {
            string evenDigits, oddDigits;
            for (char digit : number) {
                if ((digit - '0') % 2 == 0)
                    evenDigits.push_back(digit);
                else
                    oddDigits.push_back(digit);
            }
            size_t evenIndex = 0, oddIndex = 0;
            string ans;
            while (evenIndex < evenDigits.size() || oddIndex < oddDigits.size()) {
                if (oddIndex == oddDigits.size() ||
                    (evenIndex < evenDigits.size() &&
                     evenDigits[evenIndex] < oddDigits[oddIndex])) {
                    ans.push_back(evenDigits[evenIndex++]);
                } else {
                    ans.push_back(oddDigits[oddIndex++]);
                }
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
