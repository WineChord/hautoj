    **题目**：卷卷签到成功

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1573>){ .problem-source target="_blank" rel="noopener" }

    **题意**：卷卷的目标是AK这场比赛，卷卷首先要完成最简单的题（签到题）：请输出“&gt;&gt;签到成功&lt;&lt;”（不含引号）。

    **核心思路**：卷卷签到成功直接输出即可

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++14 编译通过；未提供成对公开样例

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        printf(">>签到成功<<");
        return 0;
    }
    ```
