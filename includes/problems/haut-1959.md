    **题目**：直播间红包雨抢券赛

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1959>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一行，若能观众获得这张 50 元券，输出 “Got it!”；否则输出 “Miss.”。

    **核心思路**：把编号 k 转成从 0 开始的位置 k-1。根据题目给出的抢券循环，每 4 个位置重复一次，只有余数为 0 的位置能够获得优惠券；判断 (k-1) mod 4 是否为 0 即可。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：减法结果可能为负，必要时先加模数再取模。；条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <stdlib.h>
    int main() {
        int n, k;
        scanf("%d %d", &n, &k);
        k--;
        if (k % 4 == 0)
            printf("Got it!");
        else
            printf("Miss.");
        return 0;
    }
    ```
