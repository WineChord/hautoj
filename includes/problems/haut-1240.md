    **题目**：Simple学长发咖啡

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1240>){ .problem-source target="_blank" rel="noopener" }

    **题意**：大家都知道，Simple学长是一位非常慷慨大方的人，他总喜欢给他身边的人发福利。喏~，Simple学长准备了很多咖啡，要请他的朋友们喝（其实大家都知道，因为Simple学长只喝特定编号的咖啡，所以才把咖啡分给大家）。每一瓶咖啡都有他的编号，每一个人都有一个名字（这不是废话吗），然而Simple学长规定了按自己名字的字典序先后，依次选择一个最小编号的咖啡。

    **核心思路**：规则是按名字字典序依次取当前最小编号的咖啡。把所有名字升序排序， 所有编号也升序排序，然后同一下标一一配对输出即可。名字和编号之间用 一个空格，每人一行。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            vector<string> name(n);
            vector<int> coffee(n);
            for (string& s : name)
                cin >> s;
            for (int& number : coffee)
                cin >> number;
            sort(name.begin(), name.end());
            sort(coffee.begin(), coffee.end());
            for (int i = 0; i < n; ++i)
                cout << name[i] << ' ' << coffee[i] << '\n';
        }
        return 0;
    }
    ```
