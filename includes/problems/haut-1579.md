    **题目**：牛牛的签到题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1579>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，This is an output question. Please output it"%%%\n\n\n".

    **核心思路**：牛牛的签到题格式控制符里输入%%即可输出一个%;输出\\即可输出一个\；printf("\"\"")即可输出双引号。

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++14 编译通过；未提供成对公开样例

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        printf("This is an output question. Please output it\"%%%%%%\\n\\n\\n\".");
    }
    ```
