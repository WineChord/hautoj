    **题目**：Nineteen

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1425>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给你一个数字n，求出≤n最大的一个象征绝望的数字

    **核心思路**：数据上限只有 138888，但询问超过十万，所以先一次性筛出所有“绝望 数字”。对每个候选 x，反复除以 10 检查所有普通前缀；再把十进制数字 反转，对反转数同样反复除以 10，就检查了题面定义的全部“翻转后前缀”。 每个值必须是 1 或质数。保存全部合格数并排序，每次询问用 upper_bound 找第一个大于 n 的位置，向前一格就是答案。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：预处理 O(U log log U+U·位数)，每次询问 O(log K)

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int rev(int x) {
        int res = 0;
        while (x > 0) {
            res = res * 10 + x % 10;
            x /= 10;
        }
        return res;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        const int LIMIT = 138888;
        vector<bool> prime(LIMIT + 1, true);
        prime[0] = prime[1] = false;
        for (int i = 2; i * i <= LIMIT; ++i)
            if (prime[i])
                for (int j = i * i; j <= LIMIT; j += i)
                    prime[j] = false;
        auto validPrefix = [&](int x) {
            while (x > 0) {
                if (x != 1 && !prime[x])
                    return false;
                x /= 10;
            }
            return true;
        };
        vector<int> despair;
        for (int x = 1; x <= LIMIT; ++x) {
            if (validPrefix(x) && validPrefix(rev(x)))
                despair.push_back(x);
        }
        int n;
        while (cin >> n) {
            auto it = upper_bound(despair.begin(), despair.end(), n);
            --it;
            cout << *it << '\n';
        }
        return 0;
    }
    ```
