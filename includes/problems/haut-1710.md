    **题目**：图书馆信息管理系统

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1710>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，若要判断的书的代号是所属类别的书，则输出YES,否则输出NO。

    **核心思路**：图书馆信息管理系统思路：这道题目的意思是要判断第一行的字符串能不能通过删除一些子串得到第二个字符串，本质理论是判断第二个字符串的所有元素是否可以按顺序出现在第一个串中即可。 具体实现：循环＋双指针维持即可。参考代码如下

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：通常为 O(n)

    **易错点**：核对中英文标点、尾随空格和末尾换行。；条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。；检查 0/1 起下标、n = 1、首尾元素和数组容量。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <string.h>
    char a[30], b[30];
    int main() {
        gets(a);
        gets(b);
        if (strlen(b) > strlen(a)) // b的长度比a的长直接输出NO
        {
            puts("NO");
            return 0;
        } else {
            int j = 0;
            for (int i = 0; i < strlen(a); i++) // 判断b字符串中的字符是否按顺序出现在a中
            {
                if (a[i] == b[j]) {
                    j++;
                }
            }
            if (j == strlen(b)) // 符合
            {
                puts("YES");
            } else // 不符合
            {
                puts("NO");
            }
        }
    }
    ```
