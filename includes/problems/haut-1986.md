    **题目**：身份证校验

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1986>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，18位的完整身份证号。

    **核心思路**：前 17 位分别乘固定权重并求和，对 11 取模。用字符串 "10X98765432" 直接按余数下标查校验码，再接到原 17 位之后输出。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(17) 时间、O(1) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。；按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        string id;
        cin >> id;
        const int weight[17] = {7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2};
        const string check = "10X98765432";
        int sum = 0;
        for (int i = 0; i < 17; ++i)
            sum += (id[i] - '0') * weight[i];
        cout << id << check[sum % 11] << '\n';
        return 0;
    }
    ```
