??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Haut校草

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1883>){ .problem-source target="_blank" rel="noopener" }

    **题意**：给定数组 a，求它任意重新排序后能够取得的最大得分。

    **核心思路**：最终全体达到同一身高时，最矮与最高之间每增加 1 个单位，需要让 n-1 个人发生一次相对变化，因此答案为 (max-min)×(n-1)。扫描数组 只保留最大值和最小值即可。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(1) 额外空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        long long mn = LLONG_MAX, mx = LLONG_MIN;
        for (int i = 0; i < n; ++i) {
            long long height;
            cin >> height;
            mn = min(mn, height);
            mx = max(mx, height);
        }
        cout << (mx - mn) * (n - 1LL) << '\n';
        return 0;
    }
    ```
