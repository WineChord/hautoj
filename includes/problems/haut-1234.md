??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Simple学长取咖啡

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1234>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个数字表示有多少种方法可以取到咖啡。（最后的数字有可能很大哦）

    **核心思路**：到第 n 阶的最后一步只能从 n-1、n-2 或 n-3 阶跳来，因此 ways&#91;n&#93;=ways&#91;n-1&#93;+ways&#91;n-2&#93;+ways&#91;n-3&#93;。设 ways&#91;0&#93;=1 表示站在起点 的一种空方案，负下标为 0，就得到 ways&#91;1&#93;=1、ways&#91;2&#93;=2、 ways&#91;3&#93;=4。预处理到 40 后逐询问输出。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：预处理 O(40)，每次询问 O(1)，空间 O(40)

    **易错点**：初值不能默认全部可达；0/1 背包必须倒序遍历容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        array<unsigned long long, 41> ways{};
        ways[0] = 1;
        for (int stair = 1; stair <= 40; ++stair)
            for (int jump = 1; jump <= 3; ++jump)
                if (stair >= jump)
                    ways[stair] += ways[stair - jump];
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            cout << ways[n] << '\n';
        }
        return 0;
    }
    ```
