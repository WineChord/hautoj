??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Lighting

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1367>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果能把灯全部关掉输出YES 否则输出QAQ

    **核心思路**：同一个按钮按两次会抵消，所以每个按钮只需考虑按或不按，共 2\^n 种方案。枚举一个二进制掩码，复制初始灯态；若第 i 位为 1，就翻转 i-1、i、i+1 三个仍在范围内的灯。只要某个方案得到全 0 就输出 YES。 $n \le 16$，最多约一百万次翻转，足够快，也很适合作为位枚举入门。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(n·2\^n) 时间、O(n) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<int> initial(n);
        for (int i = 0; i < n; ++i) {
            char bit;
            cin >> bit;
            initial[i] = bit - '0';
        }
        for (int mask = 0; mask < (1 << n); ++mask) {
            vector<int> light = initial;
            for (int i = 0; i < n; ++i) {
                if (!(mask >> i & 1))
                    continue;
                for (int j = max(0, i - 1); j <= min(n - 1, i + 1); ++j)
                    light[j] ^= 1;
            }
            if (all_of(light.begin(), light.end(), [](int x) {
                    return x == 0;
                })) {
                cout << "YES\n";
                return 0;
            }
        }
        cout << "QAQ\n";
        return 0;
    }
    ```
