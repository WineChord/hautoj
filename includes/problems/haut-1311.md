??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：午饭问题

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1311>){ .problem-source target="_blank" rel="noopener" }

    **题意**：W：“给你一些数字，问你出现次数最多的数字，如果出现次数最多的数字有多个请输出最小的一个，不过最多可以有1000000个数字, 这些数字都是整数，保证每个数字 大于等于 -5，小于等于5。”

    **核心思路**：数据值只可能是 -5..5，用长度 11 的计数数组即可，值 x 存在下标 x+5。读完后从 -5 到 5 递增扫描，只在次数严格更大时更新答案；次数 相同则保留先扫描到的更小数字。这样既节省内存又自然处理并列规则。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        array<int, 11> freq{};
        for (int i = 0; i < n; ++i) {
            int value;
            cin >> value;
            ++freq[value + 5];
        }
        int ans = -5;
        for (int value = -4; value <= 5; ++value)
            if (freq[value + 5] > freq[ans + 5])
                ans = value;
        cout << ans << '\n';
        return 0;
    }
    ```
