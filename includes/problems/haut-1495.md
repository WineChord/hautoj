    **题目**：你的AC。

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1495>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于每一个测试数据，输出最小的组队数量，每组数据之间用换行符隔开

    **核心思路**：如果不存在技能值相差 1 的两名学生，所有人可放一组。否则一组 不可能，但按技能值奇偶分成两组一定可行：同奇偶数的差不可能为 1。 因此答案只需判断是否同时出现某个 v 和 v+1。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(n+值域) 时间、O(值域) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int q;
        cin >> q;
        while (q--) {
            int n;
            cin >> n;
            array<bool, 102> exists{};
            for (int i = 0, x; i < n; ++i) {
                cin >> x;
                exists[x] = true;
            }
            int ans = 1;
            for (int value = 1; value < 100; ++value) {
                if (exists[value] && exists[value + 1])
                    ans = 2;
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
