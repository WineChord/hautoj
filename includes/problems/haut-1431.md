    **题目**：愉快序列

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1431>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于一个序列，输出它最长的"愉快序列"的长度。

    **核心思路**：滑动窗口维护区间内元素互不重复。记录每个值上次出现位置；读到 a\[right\] 时，把 left 推到 max(left,last\[a\]+1)，于是窗口重新合法， 再用 right-left+1 更新答案。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(n+值域初始化) 时间、O(值域) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n, left = 0, ans = 0;
            cin >> n;
            vector<int> last(100001, -1);
            for (int right = 0; right < n; ++right) {
                int value;
                cin >> value;
                left = max(left, last[value] + 1);
                last[value] = right;
                ans = max(ans, right - left + 1);
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
