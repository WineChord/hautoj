    **题目**：幂幂幂

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1903>){ .problem-source target="_blank" rel="noopener" }

    **题意**：wf是一个特别中二的人，他非常喜欢2这个数字以及2的k次方，现在给你一个正整数n，求这个数最少能被多少个2的幂次方组成。

    **核心思路**：幂幂幂 本题运用了一点点贪心的策略，尽量使用较大的2的幂次方，但是当n%2==1时，表示必须使用当前这个2，因为如果%2==0，则表示可以别的2的幂次方所表示，%2==1，表示不能再被别的2的幂次方表示了。 的幂次方，比如5%2==1，就必须使用1，5/2=2，此时此时总和为1，2%2==0，所以当前这个2的1次方不选，2/2==1，1%2==1，所以要使用4，总共用了两个2的幂次方数。

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    void solve() {
        int n, count = 0;
        scanf("%d", &n);
        while (n) {
            count += n % 2;
            n /= 2;
        }
        printf("%d\n", count);
    }
    int main() {
        int t;
        scanf("%d", &t);
        while (t--) {
            solve();
        }
        return 0;
    }
    ```
