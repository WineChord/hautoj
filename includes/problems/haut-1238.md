    **题目**：Simple学长买咖啡

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1238>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，Print the minimum number of steps that Simple needs to make to get from point 0 to point x.

    **核心思路**：每步最多走 5 个单位，为减少步数应尽量每步走满 5。到距离 x 至少 需要 ceil(x/5) 步，而用若干个 5 加上最后一个 1..4 的余量可以达到， 所以下界可实现。整数公式为 `(x+4)/5`。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long x;
            cin >> x;
            cout << (x + 4) / 5 << '\n';
        }
        return 0;
    }
    ```
