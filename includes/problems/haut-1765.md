??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：我什么都愿意做

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1765>){ .problem-source target="_blank" rel="noopener" }

    **题意**：喝完幸运药水之后，你获得了n点幸运值，现在你想要消耗掉这n点幸运值并使其收益最大化。你有n个活动可以同时参加（每项活动只能参加一次），参加不同的活动会获得不同数量的收益，且每个活动会消耗一点幸运值，你该如何安排你的活动使得到的收益最大呢？

    **核心思路**：每个活动消耗完全相同的一点幸运值，且最多参加 n 个，因此应优先 选择收益最大的 n 个活动。把全部收益降序排序，累加前 min(n,t) 个； 收益总和可能达到 1e10，必须用 long long。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(t log t) 时间、O(t) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；检查 0/1 起下标、n = 1、首尾元素和数组容量。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, t;
        cin >> n >> t;
        vector<long long> gain(t);
        for (long long& x : gain)
            cin >> x;
        sort(gain.rbegin(), gain.rend());
        long long ans = 0;
        for (int i = 0; i < min(n, t); ++i)
            ans += gain[i];
        cout << ans << '\n';
        return 0;
    }
    ```
