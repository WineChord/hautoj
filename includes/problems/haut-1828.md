    **题目**：小明的数字

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1828>){ .problem-source target="_blank" rel="noopener" }

    **题意**：小明有一个长度为n(1&lt;=n&lt;=100)的正整数a和一个正整数b(0&lt;=b&lt;=9)，现在小明需要将b插入到a中，使得变化后的a最大。请你输出变化后的a。

    **核心思路**：小明的数字 先用char数组读入字符串s，再遍历判断s中的每一个字符，从第一个字符开始，当第i个字符比m小时，将m插入到第i个字符前面，就可以保证最后得到的值是最大值。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：通常为 O(n)

    **易错点**：检查 0/1 起下标、n = 1、首尾元素和数组容量。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    char s[105];
    int main() {
        int n;
        char m;
        scanf("%d", &n);
        scanf("%s %c", s, &m);
        int f = 0;
        for (int i = 0; i < n; i++) {
            if (m > s[i] && f == 0) {
                printf("%c", m);
                f = 1;
            }
            printf("%c", s[i]);
        }
        if (f == 0)
            printf("%c", m);
        return 0;
    }
    ```
