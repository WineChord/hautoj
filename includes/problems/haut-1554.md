??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：选择

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1554>){ .problem-source target="_blank" rel="noopener" }

    **题意**：你的目标是使得这s个元素的和的绝对值最小。

    **核心思路**：n≤20，可以枚举除空集外的全部 2^n-1 个子集。用 lowbit 找到 新增的最低位，并由去掉该位后的子集和递推当前和，可把总复杂度从 O(n2^n) 降为 O(2^n)。

    **正确性**：状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。；转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。；处理完全部输入后，目标状态正好对应题目要求。

    **复杂度**：O(2^n) 时间、O(2^n) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        int n;
        cin >> n;
        vector<long long> a(n);
        for (long long& x : a)
            cin >> x;
        int total = 1 << n;
        vector<long long> subsetSum(total, 0);
        long long ans = LLONG_MAX;
        for (int mask = 1; mask < total; ++mask) {
            int bit = __builtin_ctz(mask);
            int pre = mask & (mask - 1);
            subsetSum[mask] = subsetSum[pre] + a[bit];
            ans = min(ans, llabs(subsetSum[mask]));
        }
        cout << ans << '\n';
        return 0;
    }
    ```
