    **题目**：第一个程序

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1308>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，#include &lt;stdio.h&gt; int main() { printf("Hello world\n"); return 0; }

    **核心思路**：程序没有输入，要求输出的内容本身是一段 C 源代码。关键在两层转义： 要输出双引号，需要在当前 C++ 字符串里写 `"`；目标代码中的 `\n` 两个字符，需要在当前字符串里写 `\\n`。为让零基础读者看清每一行， 这里逐行输出目标文本。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；公开样例不可机读，未执行

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << "#include <stdio.h>\n";
        cout << "int main()\n";
        cout << "{\n";
        cout << "printf(\"Hello world\\n\");\n";
        cout << "return 0;\n";
        cout << "}\n";
        return 0;
    }
    ```
