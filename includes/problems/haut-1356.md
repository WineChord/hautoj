    **题目**：数学（一）

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1356>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出 A（N， M）， 结果对 1000000007 取余。 第 i 组数据输出前加上，“Test : ”，不含引号。

    **核心思路**：排列数 A(N,M)=N·(N-1)·…·(N-M+1)。因为只要求模 1000000007，不必先求可能溢出的阶乘；直接把这 M 个因子逐个乘入， 每一步都取模即可。M=0 时空乘积为 1。注意样例规定的编号格式为 `Test1 : 120`。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(M) 时间、O(1) 空间

    **易错点**：减法结果可能为负，必要时先加模数再取模。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        const long long MOD = 1000000007LL;
        int T;
        cin >> T;
        for (int test = 1; test <= T; ++test) {
            int n, m;
            cin >> n >> m;
            long long ans = 1;
            for (int value = n - m + 1; value <= n; ++value)
                ans = ans * value % MOD;
            cout << "Test" << test << " : " << ans << '\n';
        }
        return 0;
    }
    ```
