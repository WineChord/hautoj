    **题目**：看医生

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1343>){ .problem-source target="_blank" rel="noopener" }

    **题意**：请你帮小A计算他拜访完所有医生最少需要到第几天（是从第一天开始计算，而不是从拜访第一个医生开始）。

    **核心思路**：医生必须按编号拜访且一天至多一位，所以第 i 位医生要选择严格晚于 上一次拜访日的最早工作日。其工作日为 si+k·di：若 si 已大于当前日， 直接选 si；否则把它增加最小个 di，使其严格大于当前日。逐个贪心即可， 因为把某次拜访推迟只会压缩后续选择，不会带来好处。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n) 时间、O(1) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            long long day = 0;
            for (int i = 0; i < n; ++i) {
                long long start, period;
                cin >> start >> period;
                if (start <= day) {
                    long long steps = (day - start) / period + 1;
                    start += steps * period;
                }
                day = start;
            }
            cout << day << '\n';
        }
        return 0;
    }
    ```
