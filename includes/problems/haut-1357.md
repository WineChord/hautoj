??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：午饭问题（一）

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1357>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，多实例测试，输出 A*B 的结果。

    **核心思路**：两个整数最多 1000 位，内置整数装不下。按小学竖式建立长度 n+m 的数组：从最低位开始枚举 A&#91;i&#93;、B&#91;j&#93;，把乘积累加到对应位； 再从低位向高位统一进位。去掉最高端多余的 0 后反向输出。输入按 两行一对一直读到文件尾，任何一个因数为 0 时自然得到 0。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(|A|·|B|) 时间、O(|A|+|B|) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    string multiply(const string& a, const string& b) {
        vector<int> digit(a.size() + b.size(), 0);
        for (int i = (int)a.size() - 1; i >= 0; --i) {
            for (int j = (int)b.size() - 1; j >= 0; --j) {
                int pos = (int)a.size() - 1 - i + (int)b.size() - 1 - j;
                digit[pos] += (a[i] - '0') * (b[j] - '0');
            }
        }
        for (int i = 0; i + 1 < (int)digit.size(); ++i) {
            digit[i + 1] += digit[i] / 10;
            digit[i] %= 10;
        }
        while (digit.size() > 1 && digit.back() == 0)
            digit.pop_back();
        string res;
        for (auto it = digit.rbegin(); it != digit.rend(); ++it)
            res.push_back(char('0' + *it));
        return res;
    }
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        string A, B;
        while (cin >> A >> B)
            cout << multiply(A, B) << '\n';
        return 0;
    }
    ```
