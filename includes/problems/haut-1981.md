    **题目**：编程霸总强制爱

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1981>){ .problem-source target="_blank" rel="noopener" }

    **题意**：如果你不喜欢编程，请输出“I love coding”。(输出不带引号)

    **核心思路**：编程霸总强制爱 按题意输出即可 #include&lt;bits/stdc++.h&gt; using namespace std; int main() { cout&lt;&lt;"I love coding"; return 0; } D

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++14 编译通过；公开样例不可机读，未执行

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << "I love coding";
        return 0;
    }
    ```
