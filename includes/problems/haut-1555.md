??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：会写脚本的月月鸟

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1555>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出m行 每行一个数代表a&#91;l&#93;&amp;a&#91;l+1&#93;&amp;a&#91;l+2&#93;.......a&#91;r-1&#93;&amp;a&#91;r&#93;的值

    **核心思路**：区间按位与满足结合律，可用迭代线段树维护。叶子存原数组， 父节点存两个子区间的按位与；查询时把被覆盖的节点逐个与到答案。 按位与的单位元可取所有位均为 1 的 ~0。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：建树 O(n)，每次询问 O(log n)，空间 O(n)

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m;
        cin >> n >> m;
        int size = 1;
        while (size < n)
            size <<= 1;
        vector<int> tree(2 * size, ~0);
        for (int i = 0; i < n; ++i)
            cin >> tree[size + i];
        for (int i = size - 1; i; --i)
            tree[i] = tree[i << 1] & tree[i << 1 | 1];
        while (m--) {
            int l, r;
            cin >> l >> r;
            --l;
            int ans = ~0;
            for (l += size, r += size; l < r; l >>= 1, r >>= 1) {
                if (l & 1)
                    ans &= tree[l++];
                if (r & 1)
                    ans &= tree[--r];
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
