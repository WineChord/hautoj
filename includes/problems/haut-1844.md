??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：纵向排版

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1844>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，按纵向排版格式排版给定的字符串，每列N个字符（除了最后一列可能不足N个）。

    **核心思路**：原串按“每列 N 个字符”切成若干列，输出时外层枚举行号 0..N-1， 内层枚举列号。原串下标为 column*N+row；越界说明最后一列不足， 应输出空格占位。第一行数字后的换行用 ignore 清除，再 getline。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(N·列数) 时间、O(|s|) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        cin.ignore(numeric_limits<streamsize>::max(), '\n');
        string s;
        getline(cin, s);
        int columns = (s.size() + n - 1) / n;
        for (int row = 0; row < n; ++row) {
            for (int column = 0; column < columns; ++column) {
                int index = column * n + row;
                cout << (index < (int)s.size() ? s[index] : ' ');
            }
            cout << '\n';
        }
        return 0;
    }
    ```
