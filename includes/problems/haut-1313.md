??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：体育课

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1313>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个浮点数，保留两位小数。

    **核心思路**：将身高排序，去掉最小两个和最大两个后，对中间 n-4 人求平均数。 题目说“前两个最高、后两个最低”均按人数去除，即便最高值相同也仍只 去掉两个元素。使用 long long 求和、double 做除法，保留两位小数。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；按误差要求保留精度，不要只按样例字符数猜小数位。；按上界估算中间量，相关变量不要退回 int。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<int> height(n);
        for (int& x : height)
            cin >> x;
        sort(height.begin(), height.end());
        long long sum = 0;
        for (int i = 2; i + 2 < n; ++i)
            sum += height[i];
        cout << fixed << setprecision(2) << (double)sum / (n - 4) << '\n';
        return 0;
    }
    ```
