    **题目**：Simple学长翻硬币

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1253>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出正面朝上硬币的编号（编号从1开始），每两个编号用空格隔开。

    **核心思路**：编号 i 的硬币会在 i 的每个正因数轮被翻一次，因此总翻转次数等于 i 的因数个数。因数通常成对出现 d 与 i/d，只有完全平方数的平方根 会落单，所以恰好完全平方数被翻奇数次、最终正面朝上。直接输出 1²,2²,…≤n；用标志控制空格，避免行尾多余分隔。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(√n) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            long long n;
            cin >> n;
            bool first = true;
            for (long long root = 1; root * root <= n; ++root) {
                if (!first)
                    cout << ' ';
                cout << root * root;
                first = false;
            }
            cout << '\n';
        }
        return 0;
    }
    ```
