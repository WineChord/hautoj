    **题目**：等式判断

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1229>){ .problem-source target="_blank" rel="noopener" }

    **题意**：请判断等式是否正确。如果正确，输出YES，否则输出NO。

    **核心思路**：用字符串流按 `左操作数 运算符 右操作数 = 结果` 读取。针对 +、-、*、/ 计算左侧；除法时若除数为 0，等式直接错误。题目使用整数， 所以 `/` 按 C/C++ 整数除法判断。最后比较计算值与等号右侧。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(|s|) 时间、O(|s|) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            string equation;
            cin >> equation;
            stringstream input(equation);
            long long a, b, expected;
            char op, equalSign;
            input >> a >> op >> b >> equalSign >> expected;
            bool valid = true;
            long long actual = 0;
            if (op == '+')
                actual = a + b;
            else if (op == '-')
                actual = a - b;
            else if (op == '*')
                actual = a * b;
            else if (op == '/') {
                if (b == 0)
                    valid = false;
                else
                    actual = a / b;
            } else {
                valid = false;
            }
            cout << (valid && actual == expected ? "YES" : "NO") << '\n';
        }
        return 0;
    }
    ```
