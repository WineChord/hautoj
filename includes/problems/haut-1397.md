    **题目**：外卖距离

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1397>){ .problem-source target="_blank" rel="noopener" }

    **题意**：最近CS很喜欢点外卖。但是CS发现选择不同的收货地址，最后下单的配送费不一样。CS研究了一下，觉得部分外卖机构的配送费是与店家到收货地址之间的距离有关。店家在平面上可以看成一个点，如果选择的收货地址在空间概念上可看作一个点，则店家到收货地址之间的距离就是这两点之间的直线。但如果收货地址可看成一个面，则店家到收货地址之间的距离为店家到这个面上所有点的距离的最小……

    **核心思路**：矩形横坐标范围为 &#91;left,left+length&#93;、纵坐标范围为 &#91;bottom,bottom+width&#93;。点在某一维区间内时该维距离为 0，否则为 到最近端点的差；二维直线距离用 hypot(dx,dy) 合成。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：按误差要求保留精度，不要只按样例字符数猜小数位。；setprecision 单独使用表示有效数字；固定小数位时必须配合 fixed。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        double x, y, left, bottom, len, width;
        cin >> x >> y >> left >> bottom >> len >> width;
        double right = left + len, top = bottom + width;
        double dx = max({left - x, 0.0, x - right});
        double dy = max({bottom - y, 0.0, y - top});
        cout << fixed << setprecision(2) << hypot(dx, dy) << '\n';
        return 0;
    }
    ```
