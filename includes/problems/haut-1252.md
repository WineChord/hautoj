??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：Simple学长的数字游戏

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1252>){ .problem-source target="_blank" rel="noopener" }

    **题意**：比如n = 3时，123，23，312组成的最大编号就是31223123.

    **核心思路**：决定两个字符串 a、b 谁在前面时，不能只比首位或数值，而要比较 拼接 `a+b` 与 `b+a`：若前者更大，就让 a 在前。按这个比较器排序后 依次连接，任意相邻对都选择了更优顺序，因此整体字典序（也就是同长度 十进制数值）最大。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(n log n·L) 时间、O(nL) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            vector<string> number(n);
            for (string& s : number)
                cin >> s;
            sort(number.begin(), number.end(), [](const string& a, const string& b) {
                return a + b > b + a;
            });
            for (const string& s : number)
                cout << s;
            cout << '\n';
        }
        return 0;
    }
    ```
