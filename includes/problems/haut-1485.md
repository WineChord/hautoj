    **题意**：根据给定输入，如果【欢】获胜输出“wula”，如果WX获胜输出“waha”。（输出只有字母不带引号）

    **核心思路**：n 为偶数时，欢第一步可以直接取走 n（合法偶数）并获胜；n 为 奇数时，无论欢减去哪个偶数，都会留下奇数，WX 可在下一步取走全部 剩余数。因此答案只由 n 的奇偶决定。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long n;
        cin >> n;
        cout << (n % 2 == 0 ? "wula" : "waha") << '\n';
        return 0;
    }
    ```
