    **题目**：连续五天早八

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1866>){ .problem-source target="_blank" rel="noopener" }

    **题意**：大学生连续上 5 天早八会精神焕发，输入某位大学生接下来 n 天是否需要上早八，判断他会不会精神焕发。

    **核心思路**：扫描 0/1 序列，1 使连续计数加一，0 使其清零；计数达到 5 即存在 连续五天早八。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, consecutive = 0;
        bool found = false;
        cin >> n;
        while (n--) {
            int value;
            cin >> value;
            consecutive = value ? consecutive + 1 : 0;
            found |= consecutive >= 5;
        }
        cout << (found ? "Yes" : "No") << '\n';
        return 0;
    }
    ```
