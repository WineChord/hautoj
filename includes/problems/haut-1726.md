    **题目**：想象之中

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1726>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，判断每一关是否可以成功通过，如果可以通过输出"YES"，否则输出"No"

    **核心思路**：想象之中注意读题，如果无法击败怪物，怪物会逃跑，所以一定能到终点，直接输出YES即可 C

    **正确性**：建图把每个合法对象或状态映射为点，把合法关系映射为边。；扩展操作覆盖所有且仅覆盖合法转移，访问标记避免重复处理。；遍历结束后的可达性、距离或累计值与原问题一一对应。

    **复杂度**：按一次完整遍历估算，通常为 O(n+m)

    **易错点**：条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。；入队或递归时及时标记访问，避免重复状态和死循环。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int main() {
        int n;
        scanf("%d", &n);
        while (n--)
            printf("YES\n");
    }
    ```
