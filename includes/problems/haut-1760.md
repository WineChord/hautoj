??? problem "展开：题意、思路、证明、复杂度与 C++14 代码"
    **题目**：好数

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1760>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行 如果摆摆可以继续开摆，输出 "YES \^\_\^" 否则，输出 "no!!! X\_X" 输出均不含引号

    **核心思路**：从最高位向最低位比较相邻字符：后一位较大记一次递增，较小记一次 递减，相等不计。概率大于 70% 等价于 10×递增数&gt;7×有效比较数， 用整数比较避免浮点误差；没有有效比较时条件不成立。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(|n|) 时间、O(|n|) 空间

    **易错点**：避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        string number;
        cin >> number;
        int increasing = 0, decreasing = 0;
        for (size_t i = 1; i < number.size(); ++i) {
            if (number[i] > number[i - 1])
                ++increasing;
            else if (number[i] < number[i - 1])
                ++decreasing;
        }
        int comparisons = increasing + decreasing;
        bool canRest = comparisons > 0 && 10 * increasing > 7 * comparisons;
        cout << (canRest ? "YES ^_^" : "no!!! X_X") << '\n';
        return 0;
    }
    ```
