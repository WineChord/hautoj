??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：Invictus

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1421>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，作为答案

    **核心思路**：先把题面中的十进制 ASCII 逐个转成字符，会得到一张代码图片的网址。 图片里的 C 程序在区间 &#91;1,10000&#93; 上二分第一个满足 m-A≥B 的整数。 因而答案就是把 A+B 限制在 &#91;1,10000&#93;：小于 1 得 1，大于 10000 得 10000。题目为文件尾多组输入。手册同时展示解码链，避免把它误当 成普通 A+B。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：确认循环边界，以及最终返回第一个可行还是最后一个不可行。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        long long A, B;
        while (cin >> A >> B) {
            cout << min(10000LL, max(1LL, A + B)) << '\n';
        }
        return 0;
    }
    ```
