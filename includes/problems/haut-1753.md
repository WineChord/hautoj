??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：比赛模拟

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1753>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，对于每组数据需你输出一个整数，代表这场比赛的总用时。 不同组数据之间用回车"\n"来进行分割。

    **核心思路**：每道最终通过的题贡献首次通过时间 ti；此前每次错误提交再贡献 20 分钟。逐组读入 n，累加 ti+20*cnti 即可。题目没有给数据组数， 所以必须把 cin&gt;&gt;n 直接放在 while 条件里，读到文件尾自然停止。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(n) 时间、O(1) 额外空间

    **易错点**：EOF 题不要读取不存在的 T，也不要多输出内容。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        while (cin >> n) {
            long long ans = 0;
            for (int i = 0; i < n; ++i) {
                long long time, wrong;
                cin >> time >> wrong;
                ans += time + 20 * wrong;
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
