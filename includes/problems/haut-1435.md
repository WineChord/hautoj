    **题目**：文件

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1435>){ .problem-source target="_blank" rel="noopener" }

    **题意**：自己想要文件需要移动其他文件的最小数量。如果想拿的文件不存在或者之前已经拿过了

    **核心思路**：两个 vector 按从下到上存成栈。查询文件时先在线性范围内定位； 若在 A 的位置 p，就把 A 中 p 上方的文件逐个 pop 并 push 到 B， 移动数为上方数量，随后删除目标；在 B 中同理。找不到（含已取走） 输出 -1。

    **正确性**：初始变量与题面初始状态相同。；若某一步前状态正确，本步按相同顺序和规则更新后仍保持一致。；由归纳法，全部步骤结束时程序状态与答案都正确。

    **复杂度**：每次 O(n+m)，总空间 O(n+m)

    **易错点**：按规定顺序更新，避免本轮新状态在同一轮被重复使用。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n, m, q;
            cin >> n >> m >> q;
            vector<int> a(n), b(m);
            for (int& x : a)
                cin >> x;
            for (int& x : b)
                cin >> x;
            while (q--) {
                int target;
                cin >> target;
                auto ia = find(a.begin(), a.end(), target);
                auto ib = find(b.begin(), b.end(), target);
                if (ia == a.end() && ib == b.end()) {
                    cout << -1 << '\n';
                } else if (ia != a.end()) {
                    int moves = a.end() - ia - 1;
                    while (a.back() != target) {
                        b.push_back(a.back());
                        a.pop_back();
                    }
                    a.pop_back();
                    cout << moves << '\n';
                } else {
                    int moves = b.end() - ib - 1;
                    while (b.back() != target) {
                        a.push_back(b.back());
                        b.pop_back();
                    }
                    b.pop_back();
                    cout << moves << '\n';
                }
            }
        }
        return 0;
    }
    ```
