??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：放烟花

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1571>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，最小花费时间

    **核心思路**：使用 k 根引线可把 k 箱烟花并入其他箱所在连通块，从而少手动点燃 k 箱；显然应省下点燃时间最大的 k 项。第 1..k 根引线总安装时间为 11·k(k+1)/2。排序后枚举 0..min(m,n-1) 根，取 总点燃时间−前 k 大之和+引线时间的最小值。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m;
        cin >> n >> m;
        vector<long long> time(n);
        long long total = 0;
        for (long long& x : time) {
            cin >> x;
            total += x;
        }
        sort(time.rbegin(), time.rend());
        long long ans = total, saved = 0;
        for (int k = 1; k <= min(m, n - 1); ++k) {
            saved += time[k - 1];
            long long fuse = 11LL * k * (k + 1) / 2;
            ans = min(ans, total - saved + fuse);
        }
        cout << ans << '\n';
        return 0;
    }
    ```
