    **题目**：排队

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1823>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，n个正整数，用空格分隔。

    **核心思路**：排队 单向链表的简单模拟，反向记录一下每个人后面的人即可，可以标记一下前面有人的人的编号没有标记的就是队首，另外有n可能为1赛时很多人wa这个点了。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：通常为 O(n)

    **易错点**：检查 0/1 起下标、$n = 1$、首尾元素和数组容量。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    int a[5005], st[5005];
    int main() {
        int n, h;
        scanf("%d", &n);
        for (int i = 1; i < n; i++) {
            int x, y;
            scanf("%d%d", &x, &y);
            a[y] = x;
            st[x] = 1;
        }
        for (int i = 1; i <= n; i++)
            if (!st[i]) {
                h = i;
                break;
            }
        while (h) {
            printf("%d ", h);
            h = a[h];
        }
        return 0;
    }
    ```
