??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：选数字

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1441>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，按字典序输出所有可能的排列。 若无法选取，则输出-1.

    **核心思路**：样例表明题目所说的“排列”实际要求从 n 个数中选 m 个、每组内部 保持升序的组合。先排序，再用递归从 last+1 开始选择下一个下标， 生成顺序天然是字典序；m&gt;n 时输出 -1。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(C(n,m)·m) 输出时间、O(n) 递归空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int n, m;
    vector<long long> number, chosen;
    void search(int start) {
        if ((int)chosen.size() == m) {
            for (int i = 0; i < m; ++i) {
                if (i)
                    cout << ' ';
                cout << chosen[i];
            }
            cout << '\n';
            return;
        }
        int stillNeeded = m - chosen.size();
        for (int i = start; i + stillNeeded <= n; ++i) {
            chosen.push_back(number[i]);
            search(i + 1);
            chosen.pop_back();
        }
    }
    int main() {
        cin >> n >> m;
        number.resize(n);
        for (long long& x : number)
            cin >> x;
        if (m > n) {
            cout << -1 << '\n';
            return 0;
        }
        sort(number.begin(), number.end());
        search(0);
        return 0;
    }
    ```
