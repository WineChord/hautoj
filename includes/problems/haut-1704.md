??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：博学的学长

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1704>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一行字符串。

    **核心思路**：博学的学长典型签到题，直接输出。 当然，你也可以去查ASCII码表。

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。；避免下标越界；getline 前要处理上一次格式化读入留下的换行。

    - 核验状态：C++17 编译通过；公开样例不可机读，未执行

    **C++17 实现**

    ```cpp linenums="1"
    #include <stdio.h>
    #include <stdlib.h>
    #include <string.h>
    #include <math.h>
    int main() {
        printf("%c%c%c%c%c%c%c", 67, 72, 70, 89, 89, 68, 83);
        return 0;
    }
    ```
