??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：疲惫的一天

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1221>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，一个整数，占一行，表示cds需要步行的最短路程

    **核心思路**：cds 从点 0 步行，学校在 1000。每辆车只能在起点 x 上车、终点 y 下车，且中途不能下。最优方案只可能是：都不坐、只坐 1、只坐 2、 先 1 后 2、先 2 后 1。分别把各段步行距离的绝对值相加，取五个候选 的最小值；坐车路段不计步行。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        long long ans = 1000;
        ans = min(ans, llabs(x1) + llabs(1000 - y1));
        ans = min(ans, llabs(x2) + llabs(1000 - y2));
        ans = min(ans, llabs(x1) + llabs(y1 - x2) + llabs(1000 - y2));
        ans = min(ans, llabs(x2) + llabs(y2 - x1) + llabs(1000 - y1));
        cout << ans << '\n';
        return 0;
    }
    ```
