    **题目**：周长之和

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1864>){ .problem-source target="_blank" rel="noopener" }

    **题意**：求所有图形周长之和的最小值。

    **核心思路**：所有矩形允许重叠时，把它们左下角对齐可让并集落在宽为最大 w、高为 最大 h 的外接矩形内，并达到最小周长 2(maxW+maxH)。扫描两个最大值。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, maxWidth = 0, maxHeight = 0;
        cin >> n;
        while (n--) {
            int width, height;
            cin >> width >> height;
            maxWidth = max(maxWidth, width);
            maxHeight = max(maxHeight, height);
        }
        cout << 2 * (maxWidth + maxHeight) << '\n';
        return 0;
    }
    ```
