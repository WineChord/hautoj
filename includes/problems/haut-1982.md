??? problem "展开：题意、思路、证明、复杂度与 C++17 代码"
    **题目**：一觉醒来成为算法高手

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1982>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，输出一个整数，表示最多能参加的活动个数。

    **核心思路**：这是区间调度：按结束时间从小到大排序，每次选择开始时间不早于 上一个已选区间结束时间的区间。结束越早，留给后续课程的时间越多， 这一局部选择可通过交换论证得到最优解。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(n log n) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；比较器必须满足严格弱序；相等时处理题目指定的次关键字。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n;
        cin >> n;
        vector<pair<long long, long long>> seg(n);
        for (auto& interval : seg) {
            long long start, finish;
            cin >> start >> finish;
            interval = {finish, start};
        }
        sort(seg.begin(), seg.end());
        long long last = LLONG_MIN;
        int ans = 0;
        for (auto [finish, start] : seg) {
            if (start >= last) {
                ++ans;
                last = finish;
            }
        }
        cout << ans << '\n';
        return 0;
    }
    ```
