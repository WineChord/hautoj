    **题目**：数学家

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1433>){ .problem-source target="_blank" rel="noopener" }

    **题意**：他希望你能帮他找到满足条件的最小正整数b，并且用c/b来表示这个小数0.a。

    **核心思路**：把输入当字符串，取小数点后的数字作为分子 a，分母是 10\^(小数位数)。用 gcd(a,denominator) 同除，所得分母最小；字符串 方式还能准确保留小数位数而不受浮点误差影响。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：每组 O(小数位数+log 值域) 时间、O(小数位数) 空间

    **易错点**：检查 gcd/lcm 的 0 值、负数和乘法溢出。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    long long gcdll(long long a, long long b) {
        while (b) {
            long long r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    int main() {
        int T;
        cin >> T;
        while (T--) {
            string decimal;
            cin >> decimal;
            string digits = decimal.substr(decimal.find('.') + 1);
            unsigned long long p = stoull(digits);
            unsigned long long q = 1;
            for (char ignored : digits)
                q *= 10;
            unsigned long long divisor = gcdll(p, q);
            cout << p / divisor << '/' << q / divisor << '\n';
        }
        return 0;
    }
    ```
