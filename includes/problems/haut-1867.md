    **题目**：找坐标

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1867>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，整数 k 所在的行和列，这两个数字用空格分隔。

    **核心思路**：按 1 起行列遍历 n×n 矩阵，读到唯一的 k 时记录并输出其坐标。 即使已经找到仍可继续完成输入，写法更稳健。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：O(n²) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, target, answerRow = -1, col = -1;
        cin >> n >> target;
        for (int row = 1; row <= n; ++row) {
            for (int column = 1; column <= n; ++column) {
                int value;
                cin >> value;
                if (value == target) {
                    answerRow = row;
                    col = column;
                }
            }
        }
        cout << answerRow << ' ' << col << '\n';
        return 0;
    }
    ```
