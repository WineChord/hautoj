    **题目**：星空列车与白的旅行

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1885>){ .problem-source target="_blank" rel="noopener" }

    **题意**：诺瓦是个很可爱的女孩，有着猫尾猫耳，而且总是呆呆的样子。诺瓦有一个可爱值的属性，在时间t秒的时候，诺瓦的可爱值会增加t^t，而这一秒增加的可爱值会持续k秒。如果在时间等于n秒的时候，诺瓦总的可爱值为奇数，那么你将不受控制，会被诺瓦吸引导致你被其他乘客当成hentai。你不想被当成hentai，所以请你判断，在时间为n秒的时候，诺瓦的可爱值是否为奇数。如果可爱……

    **核心思路**：t^t 的奇偶性只由 t 决定：t 为奇数时 t^t 为奇数，否则为偶数。 因而只需数区间 &#91;n-k+1,n&#93; 中有多少奇数；奇数项个数为偶数时总和 为偶数，输出 YES，否则输出 NO。

    **正确性**：推导把原过程转换为等价的公式或不变量。；算法直接计算该等价量，并使用足够宽的数据类型处理边界。；因此计算结果就是题目定义的答案。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。；按上界估算中间量，相关变量不要退回 int。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        long long n, k;
        cin >> n >> k;
        long long left = n - k + 1;
        long long oddCount = (n + 1) / 2 - left / 2;
        cout << (oddCount % 2 == 0 ? "YES" : "NO") << '\n';
        return 0;
    }
    ```
