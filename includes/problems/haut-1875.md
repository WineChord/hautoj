    **题目**：/\

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1875>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，/\

    **核心思路**：反斜杠在 C++ 字符串中要写成转义形式 \\，最终输出才是一个 反斜杠。

    **正确性**：题目没有输入，所有合法运行面对同一个固定任务。；程序输出的常量与题目要求逐字一致。；因此程序在所有运行中都得到正确结果。

    **复杂度**：O(1) 时间、O(1) 空间

    **易错点**：核对中英文标点、尾随空格和末尾换行。

    - 核验状态：C++14 编译通过；公开样例不可机读，未执行

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        cout << "/\\\n";
        return 0;
    }
    ```
