    **题目**：小青的大学英语

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1538>){ .problem-source target="_blank" rel="noopener" }

    **题意**：众所周知，大学英语的划水率特别高，大部分同学都是在下面玩手机，小青在经历了两周的认真学习之后也加入了玩手机大军。这天，小青突然想起昨晚停电了，手机电量只剩百分之五。教室内有k个可以使用的充电插口，本来小青可以快乐的独占一个插口，但由于昨晚停电，班里还有m-1名同学手机也没电了，显然有可能无法完成插口的按需分配。于是小青从他的神奇背包里拿出了n个插排，现在小青……

    **核心思路**：一个有 x 个插口的插排自身要占用一个现有插口，所以净增加 x-1 个可用口。初始有 k 个墙上插口；把净增量从大到小使用，首次 令总容量达到 m 台手机时就是最少插排数。多组数据读到文件尾。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：每组 O(n log n) 时间、O(n) 空间

    **易错点**：比较器必须满足严格弱序；相等时处理题目指定的次关键字。；先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。；EOF 题不要读取不存在的 T，也不要多输出内容。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int n, m, k;
        while (cin >> n >> m >> k) {
            vector<int> gain(n);
            for (int& x : gain) {
                cin >> x;
                --x;
            }
            sort(gain.rbegin(), gain.rend());
            int capacity = k, ans = 0;
            while (ans < n && capacity < m)
                capacity += gain[ans++];
            cout << (capacity >= m ? ans : -1) << '\n';
        }
        return 0;
    }
    ```
