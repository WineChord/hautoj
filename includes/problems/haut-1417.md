    **题目**：Chomp

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1417>){ .problem-source target="_blank" rel="noopener" }

    **题意**：根据给定输入，如果最后先手会吃掉那块有毒的巧克力输出First 否则输出Second

    **核心思路**：题目输出的是最终吃到毒巧克力的人，而不是“获胜者”的名字。 对 1×1 棋盘，先手只能立即吃毒块，所以输出 First。 对任何至少有两个格子的矩形 Chomp，经典的策略窃取论证说明先手一定 能把“避免吃毒块”的获胜策略掌握在自己手中：假设先手没有获胜策略， 他先吃右下角这一块后，本可属于后手的策略就能被先手照搬；额外少掉 的右下角不会让某个合法操作变得非法，产生矛盾。因此最终吃毒块的是 后手，输出 Second。

    **正确性**：扫描前保存的信息与已经处理的输入完全对应。；每读入一个元素，分支覆盖其全部情况并正确更新累计状态。；扫描结束时所有输入恰好处理一次，累计状态即为所求。

    **复杂度**：每组 O(1) 时间、O(1) 空间

    **易错点**：核对读入顺序、变量类型和输出格式。；自测最小规模、最大边界和一般样例。

    - 核验状态：C++17 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++17 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n, m;
            cin >> n >> m;
            cout << (n == 1 && m == 1 ? "First" : "Second") << '\n';
        }
        return 0;
    }
    ```
