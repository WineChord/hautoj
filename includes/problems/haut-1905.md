    **题目**：Two movies影评

    [打开 HAUTOJ 原题 ↗](<https://acm.haut.edu.cn/problem.php?id=1905>){ .problem-source target="_blank" rel="noopener" }

    **题意**：公司的评分是两部电影评分的最小值。您的任务是计算公司可能获得的最高评分。

    **核心思路**：先处理两部电影评价不同的位置：把评价为 1 的那一部对应得分加一； 此时得到基础分 x、y。评价都为 -1 的位置有 neg 个，都为 1 的位置 有 pos 个。枚举把多少个这类“共同评价”分给第一部电影，第二部得到 剩余部分，取 min(x,y) 的最大值。0 对答案没有影响。

    **正确性**：每一步选择不占用额外未来资源，并达到当前可证明的最优边界。；任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。；反复交换即可得到与算法相同的最优解，所以算法全局最优。

    **复杂度**：O(Σn) 时间、O(n) 空间

    **易错点**：先尝试找反例；无法给出交换论证或下界时，不要把直觉当证明。

    - 核验状态：C++14 编译通过；1 个可机读公开样例/合法构造校验通过

    **C++14 实现**

    ```cpp linenums="1"
    #include <bits/stdc++.h>
    using namespace std;
    int main() {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        int T;
        cin >> T;
        while (T--) {
            int n;
            cin >> n;
            vector<int> first(n), second(n);
            for (int& value : first)
                cin >> value;
            for (int& value : second)
                cin >> value;
            int x = 0, y = 0, positive = 0, negative = 0;
            for (int i = 0; i < n; ++i) {
                if (first[i] > second[i])
                    x += first[i];
                else if (second[i] > first[i])
                    y += second[i];
                else if (first[i] == 1)
                    ++positive;
                else if (first[i] == -1)
                    ++negative;
            }
            int ans = INT_MIN;
            for (int assigned = -negative; assigned <= positive; ++assigned) {
                int other = positive - negative - assigned;
                ans = max(ans, min(x + assigned, y + other));
            }
            cout << ans << '\n';
        }
        return 0;
    }
    ```
