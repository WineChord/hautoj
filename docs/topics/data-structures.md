# 数据结构

当普通数组无法高效维护动态信息时，再选择栈、队列、集合、哈希、堆、链表或线段树，并明确每个结构保存什么。

本模块共 **30** 道唯一题：入门 2 道、基础提高 5 道、进阶 23 道。

题目按难度、PID 排列。先进入完整题解独立阅读；需要快速复习时再展开摘要与代码。
