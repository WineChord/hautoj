## 题意与输入输出

**题意摘要**：某天，商城中有n种商品出售，每种商品可购买一次。已知每种商品的价格以及卡上的余额，问最少可使卡上的余额为多少。

**输入要点**：有多组数据。对于每组数据： 第一行只有一个正整数n，表示商品的数量。n&lt;=1000。 然后第二行包括n个正整数，表示每种商品的价格。价格不超过50。 最后一行只有一个正整数m，表示卡上的余额。m&lt;=1000。 n=0表示数据结束。

**输出要点**：对于每组输入,输出一行,包含一个整数，表示卡上可能的最小余额。

## 零基础先修

- if/else 按互斥条件选择处理路径；先覆盖特殊边界，再处理一般情况。
- 排序后应利用相邻性、前缀性质或单调性；并列时按题意添加次关键字。
- 用一句话定义 dp 状态，再写转移来源、初值、遍历顺序和最终答案。
- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 按主关键字排序；若存在并列规则，再加入次关键字。
3. 核心处理：买东西 n道菜，选出最贵的，放到最后买，然后在保留5元的情况下，用n-5元买剩下的才转化为背包问题。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。
- 转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。
- 处理完全部输入后，目标状态正好对应题目要求。

## 复杂度

通常为 O(n log n)，主要来自排序

## 易错点

- 条件应互斥并覆盖所有边界，尤其确认等号属于哪一侧。
- 比较器必须满足严格弱序；相等时处理题目指定的次关键字。
- 初值不能默认全部可达；0/1 背包必须倒序遍历容量。
