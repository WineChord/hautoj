## 题意与输入输出

**题意摘要**：根据给定输入，如果乌拉拉获胜，输出 wulala 如果挖哈哈获胜，输出 wahaha

**输入要点**：一行，三个整数n , a, b 。n 分别表示石子的数量，开局随机取出的两个石子编号。(1 &lt; n &lt;= 20000), (1 &lt;= a, b &lt;=n) 数据保证a, b 不相等

**输出要点**：如果乌拉拉获胜，输出 wulala 如果挖哈哈获胜，输出 wahaha

**题面提示**：“万事万物皆有规律” ———— 欧几里得

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。
- std::gcd(a, b) 使用欧几里得算法；同时检查 0 值、符号和 lcm 乘法溢出。
- 先找终止态和每步改变的量，再判断奇偶、不变量或必胜/必败状态。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：从已取出的 a、b 通过加减能生成的编号恰为 gcd(a,b) 的倍数。 1..n 中共有 floor(n/g) 个；开局已移走的两颗不改变剩余数量的奇偶 性，所以该值为奇数时先手拿到最后一步获胜，偶数时后手获胜。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

O(log min(a,b)) 时间、O(1) 空间

## 易错点

- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
- 按上界估算中间量，相关变量不要退回 int。
