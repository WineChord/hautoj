## 题意与输入输出

**题意摘要**：根据给定输入，两个整数 x，y，代表最终坐标。

**输入要点**：一行长度为n的字符串（仅含 U/D/L/R），0≤n≤20。

**输出要点**：两个整数 x，y，代表最终坐标。

## 零基础先修

- 输出也是答案的一部分：大小写、空格、换行、标点和小数位数都必须符合题意。
- string 可按下标访问字符；注意空串、大小写、标点和 getline 与 cin 的衔接。
- 把过程转成公式前，先在小数据上验证，再证明公式覆盖所有合法情况。

## 思路推导

1. 确认题目没有输入，程序无需声明或读取测试数据。
2. 按题面关系完成常数处理：机器人的寻宝路径 注意连续两次移动方向相同，第二次移动距离翻倍。
3. 原样输出结果，逐字核对字符、标点和末尾换行。
4. 程序不依赖输入规模，不需要循环或额外数据结构。

## 正确性说明

- 题目没有输入，所有合法运行面对同一个固定任务。
- 程序输出的常量与题目要求逐字一致。
- 因此程序在所有运行中都得到正确结果。

## 复杂度

通常为 O(n)

## 易错点

- 核对中英文标点、尾随空格和末尾换行。
- 避免下标越界；getline 前要处理上一次格式化读入留下的换行。
- 乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。
