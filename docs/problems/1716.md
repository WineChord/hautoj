## 题意与输入输出

**题意摘要**：这天，cgg学长来到了一个金库迷宫中，他在这个迷宫里面发现了m个小金库，每个小金库里面有ai个装有bi块金子的袋子，幸运的是这些袋子大小都是一样的，不考虑袋子变形的因素，而cgg学长的背包只能装下n个袋子，因此本题需要你帮他求出一个最优的致富方案。

**输入要点**：输入的第一行包含整数n(1≤n≤2·10^8)和整数m(1≤m≤20)。第i + 1行包含一对数字ai和bi(1≤ai≤10^8,1≤bi≤10)。所有输入的数字都是整数。

**输出要点**：输出一个整数代表最优致富方案的大小。

**题面提示**：7个袋子选第一个金库的五个袋子和第三个金库的两个袋子可以获得最大财富值5*10+6*2==62；cgg学长绝对聪明哦。

## 零基础先修

- 搜索必须有终止条件和访问标记；先估算状态数，避免指数爆炸。
- 用一句话定义 dp 状态，再写转移来源、初值、遍历顺序和最终答案。
- 排序后应利用相邻性、前缀性质或单调性；并列时按题意添加次关键字。
- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 按主关键字排序；若存在并列规则，再加入次关键字。
3. 核心处理：cgg学长的致富之路思路：这道题的要求已经比较明确了，就是找最优的财富方案所得到的财富的总数，需要特殊注意的一点就是袋子都是相同的，那么我们只需要用现有的袋子优先去装金钱多的袋子即可。 具体分析：对金库每个袋子里面金币数量进行一个降序排序再去判断就可以了。参考代码如下： 写法1 暴力模拟
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

- 状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。
