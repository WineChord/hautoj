## 题意与输入输出

### 题意摘要

一个n\*n的棋盘，一开始的时候棋子在一个角落的格子里，每次可以移动棋子到上下左右的相邻格子中（不能超过边界，而且不能走走过的格子）；当其中一人不能走时输，现在问你先手必胜还是后手必胜？如果先手胜请输出“FF”,后手胜请输出“AA”.

### 输入要点

多组数据，每行一个整数 N（$N \le 10^9$）；当 $N=0$ 时结束，0 不参与计算。

### 输出要点

对于每个输入的非零数字N输出一行答案。详见样例：

### 题面提示

$$
N \le 1000000000
$$

## 零基础先修

- 先找终止态和每步改变的量，再判断奇偶、不变量或必胜/必败状态。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：棋盘按黑白二染色，每一步必在两种颜色间交替。起点在角落。n 为 奇数时起点颜色比另一色多一个，后手可用配对策略应对，使路径最终停在 起点同色、轮到先手无路，故后手 AA 胜；n 为偶数时两色数量相同， 相同配对思想由先手取得最后一次移动，输出 FF。结论只取决于 n 的 奇偶，支持 $10^9$。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。
