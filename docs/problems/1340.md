## 题意与输入输出

**题意摘要**：给你两个点A、B，和固定移动距离（x,y），问是否可以通过移动A点若干次最终到B点。

**输入要点**：第一行：T，测试实例个数： 第二行：四个整数。x1,y1,x2,y2。分别是A点的坐标和B点的坐标。 - 10^5 ≤ x1, y1, x2, y2 ≤ 10^5 第三行：两个整数。x,y是固定移动距离 (1 ≤ x, y ≤ 105)

**输出要点**：“YES”或者“NO”。

## 零基础先修

- 把过程转成公式前，先在小数据上验证，再证明公式覆盖所有合法情况。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：设横、纵方向分别需要净走 p=(x2-x1)/x、q=(y2-y1)/y 个单位步。 首先两个差必须能整除固定步长。走 k 次时，每一维都是 k 个 ±1 的和， 所以其绝对净步数不超过 k，且与 k 同奇偶。k 可以任意增大，因此只需 |p| 与 |q| 同奇偶：此时选足够大的同奇偶 k，两维都能安排出相应数量 的正负步。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

## 易错点

- 乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。
- 按上界估算中间量，相关变量不要退回 int。
