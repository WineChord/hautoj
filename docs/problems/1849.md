## 题意与输入输出

### 题意摘要

根据给定输入，一个整数，表示小A能在该局游戏中获得的最大收益。

### 输入要点

第一行一个整数，代表一共n个格子（$0 < n \le 100000$）。

第二行n个整数a1 a2 a3 a4......an,第i个数代表第i个格子的收益（$-1000000 \le ai \le 1000000$)。

### 输出要点

一个整数，表示小A能在该局游戏中获得的最大收益。

### 题面提示

获得的金币可以为负

## 零基础先修

- 用一句话定义 dp 状态，再写转移来源、初值、遍历顺序和最终答案。
- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 定义 dp 状态、初值和遍历顺序，只从合法状态转移。
3. 核心处理：大富翁！启动！ 影响最终收益的有当前所处的位置和当前已经获取的金币。 考虑动态规划，dp\[i\]表示到第i个点时小A可以获取多少收益。那么dp\[i\]的最大值会从dp\[i-1\]，dp\[i-2\],dp\[i-3\],dp\[i-4\],dp\[i-5\],dp\[i-6\]中的最大值+第i格获取的金币。dp\[n+1\]即为终点。 注意，由于获取的金币可以为负数，需要初始化dp\[i\]为最小值。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。
- 转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。
- 处理完全部输入后，目标状态正好对应题目要求。

## 复杂度

由状态数 × 单状态转移数决定，需结合题目范围核算

## 易错点

- 初值不能默认全部可达；0/1 背包必须倒序遍历容量。
- 检查 0/1 起下标、$n = 1$、首尾元素和数组容量。
- 按上界估算中间量，相关变量不要退回 int。
