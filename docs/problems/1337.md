## 题意与输入输出

### 题意摘要

小智特别喜欢偶数，所以它希望一个数可以由两个偶数相加得来。小智给你一个数n，你来判断n是否可以由两个偶数(正整数)相加得来，如果可以

### 输入要点

第一行：测试实例个数T。

第二行：一个整数n （$1 \le n \le 1000$）

### 输出要点

输出“Happy QAQ”或者输出“Sad TAT”。

## 零基础先修

- 把过程转成公式前，先在小数据上验证，再证明公式覆盖所有合法情况。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：两个正偶数的最小值都是 2，所以它们的和至少为 4，且仍是偶数。 反过来，任何不小于 4 的偶数 n 都能写成 2+(n-2)，两项均为正偶数。 因此判断 `n&gt;=4 &amp;&amp; n%2==0`。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。
