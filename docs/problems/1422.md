## 题意与输入输出

### 题意摘要

给你一个小于1的非负有理数的小数形式，求出它的分数形式，当然这个小数可能是无限循环小数

### 输入要点

先输入一个T表示T组测试数据（$T \le 15$）

接下来每行输入一个字符串表示一个大于等于0小于1的有理数，长度不会超过10

### 输出要点

每一个样例输出对应的最简分数形式，如果分子是分母的倍数，直接输出一个整数

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 \_\_int128。
- 手写欧几里得算法求 gcd；同时检查 0 值、符号和 lcm 乘法溢出。
- 先确定分隔符、字符类别与多位数边界，再逐段转换。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：设小数点后非循环部分有 k 位、循环节有 r 位。若不存在循环节， 分数就是 A/10\^k；若存在，令 A 为非循环数字形成的整数、AB 为 “非循环+一遍循环节”形成的整数，则 x=(AB-A)/(10\^(k+r)-10\^k)。最后用最大公约数约分；分母约成 1 时只输出整数。这个公式来自把 x 分别乘 10\^k 和 10\^(k+r) 后相减， 循环尾部会完全抵消。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

每组 O(|s|+log V) 时间、O(|s|) 空间

## 易错点

- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
- 按上界估算中间量，相关变量不要退回 int。
