## 题意与输入输出

**题意摘要**：你每次可以选择连续的一些0翻转成1，请计算把数组中所有元素变成1所需的最小翻转次数。

**输入要点**：一个整数n，表示数组长度（1&lt;=n&lt;=200000） 一行n个0或1，用空格分隔。

**输出要点**：一个整数，表示最小翻转次数

## 零基础先修

- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。
- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：二进制翻转 根据题意只需要计算数组中连续的0的段数即是答案，注意到每个连续的0的段前面必定有一个1（如果起始为0单独计算），所以记录前1后0的位置的数量即是连续的0的段的数量。 c c++
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

通常为 O(n)

## 易错点

- 检查 0/1 起下标、n = 1、首尾元素和数组容量。
- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
