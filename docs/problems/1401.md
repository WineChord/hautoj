## 题意与输入输出

### 题意摘要

根据给定输入，输出占一行，分别输出每个人分得的能量（向下取整），中间用空格隔开

### 输入要点

第一行是战队的总能量整数n（$100 \le n \le 100000$）

第2\~6行分别是每个人 为战队贡献的点赞数x。 （$0 \le x \le 100000$)

### 输出要点

输出占一行，分别输出每个人分得的能量（向下取整），中间用空格隔开

### 题面提示

若两个人贡献的点赞相等，则他们分得的能量值相等。

## 零基础先修

- 把过程转成公式前，先在小数据上验证，再证明公式覆盖所有合法情况。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：点赞总数非零时，第 i 人得到 floor(n\*likes\[i\]/sumLikes)，乘法 先用 long long。若五人点赞全为 0，大家贡献相等，按均分规则每人 得到 floor(n/5)，这也是官方题解特别提醒的零分母边界。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

## 易错点

- 乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。
- 按上界估算中间量，相关变量不要退回 int。
