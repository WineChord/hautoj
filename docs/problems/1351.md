## 题意与输入输出

**题意摘要**：根据给定输入，如果Choide赢输出“Choice”,如果Bramble赢输出“Bramble”。

**输入要点**：输入数据有多组。 每组一行输入三个整数n,m,k(1 &lt;= n,m,k &lt;= 1e9)

**输出要点**：如果Choide赢输出“Choice”,如果Bramble赢输出“Bramble”。

**题面提示**：对于第一个案例Choice先把第一种糖果分成3堆，每堆个数都为5满足要求，因为只有一种糖果，Bramble不能再操作，所以Choice赢了。

## 零基础先修

- 先找终止态和每步改变的量，再判断奇偶、不变量或必胜/必败状态。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：每种糖果至多被操作一次，而且 n 种完全相同，因此游戏等价于有 n 个可取物品：若这一种能够合法等分，一次操作就取走一个。若可操作数 n 为偶数，后手赢；为奇数，先手赢。合法等分要求 m 存在一个满足 k≤d&lt;m 的因数 d（每堆 d 个且至少两堆）。最大的真因数是 m/最小质因数，找出它后与 k 比较即可。不能分时先手直接无步可走。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。
