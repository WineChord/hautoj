## 题意与输入输出

### 题意摘要

“草原上有一个兔子王国，里面有n只兔子公民，编号为1到n，公民在每年劳作之后要向国王缴纳税款，每只兔子缴纳的税款和自己的编号相同。但是国王的收税库被施了魔法，只能接受能把自己的容量整除的数量。现在国王想尽可能多的收税，但是不想提供过多的容量，请你给出一个最小的容量数吧\~”

### 输入要点

一个整数n。($1 \le n$ &lt;= 1e8)

### 输出要点

一个整数表示最小的容量数。由于答案可能过大，请把答案对1e9+7取模。

### 题面提示

补充样例：$n=20$ 时答案为 232792560。需要筛出不超过 n 的全部质数。

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 \_\_int128。
- C++ 的负数取模仍可能为负；减法后常用 (x - y + mod) % mod。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：容量必须同时被 1 到 n 的每个整数整除，所以最小容量正是 lcm(1,2,…,n)。对每个质数 p，只需乘入不超过 n 的最大质数幂p\^k；把这些质数幂相乘并随时对 $10^9$+7 取模即可。先用线性筛得到全部质数，并用除法判断下一次乘 p 是否仍不超过 n，避免溢出。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

O(n) 筛法时间、O(n) 空间

## 易错点

- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
- 减法结果可能为负，必要时先加模数再取模。
- 按上界估算中间量，相关变量不要退回 int。
