## 题意与输入输出

**题意摘要**：牛牛最近在组合游戏中经常会遇到求mex，于是他查百度得到：在组合游戏中计算状态的SG值时，我们常常会遇到mex函数。mex(S)的值为集合S中没有出现过的最小自然数。例如，mex({1,2}) =0、mex({0,1,2,3}) = 4。

**输入要点**：第一行输入一个整数n，表示集合S有n个元素。(1&lt;=n&lt;=100) 第二行依次输入a1,a2……an,n个整数，代表集合S的元素。(0&lt;=ai&lt;=1000)

**输出要点**：输出集合的mex（S）。

## 零基础先修

- 集合适合去重与成员查询；需要有序输出时使用 set 或最后排序。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 把条件翻译成分支或线性扫描，不引入题目没有要求的额外状态。
3. 核心处理：用布尔数组标记集合中出现过的非负整数。n 个元素最多只能覆盖 0..n-1，所以 mex 不会超过 n；从 0 向上找第一个未标记值即可。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 扫描前保存的信息与已经处理的输入完全对应。
- 每读入一个元素，分支覆盖其全部情况并正确更新累计状态。
- 扫描结束时所有输入恰好处理一次，累计状态即为所求。

## 复杂度

O(n+V) 时间、O(V) 空间
