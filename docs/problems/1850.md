## 零基础先修

- 输出也是答案的一部分：大小写、空格、换行、标点和小数位数都必须符合题意。
- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。
- string 可按下标访问字符；注意空串、大小写、标点和 getline 与 cin 的衔接。

## 思路推导

1. 确认题目没有输入，程序无需声明或读取测试数据。
2. 按题面关系完成常数处理：历经千辛万苦，只为得到你 签到题，直接输出即可。
3. 原样输出结果，逐字核对字符、标点和末尾换行。
4. 程序不依赖输入规模，不需要循环或额外数据结构。

## 正确性说明

- 题目没有输入，所有合法运行面对同一个固定任务。
- 程序输出的常量与题目要求逐字一致。
- 因此程序在所有运行中都得到正确结果。

## 复杂度

O(1) 时间、O(1) 空间

## 易错点

- 核对中英文标点、尾随空格和末尾换行。
- 检查 0/1 起下标、n = 1、首尾元素和数组容量。
- 避免下标越界；getline 前要处理上一次格式化读入留下的换行。
