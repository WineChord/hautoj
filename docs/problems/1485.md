## 题意与输入输出

**题意摘要**：根据给定输入，如果【欢】获胜输出“wula”，如果WX获胜输出“waha”。（输出只有字母不带引号）

**输入要点**：唯一的一行包含整数n (1 ≤ n ≤ 10^9)，游戏开始时的数字。

**输出要点**：如果【欢】获胜输出“wula”，如果WX获胜输出“waha”。（输出只有字母不带引号）

## 零基础先修

- 先找终止态和每步改变的量，再判断奇偶、不变量或必胜/必败状态。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：n 为偶数时，欢第一步可以直接取走 n（合法偶数）并获胜；n 为 奇数时，无论欢减去哪个偶数，都会留下奇数，WX 可在下一步取走全部 剩余数。因此答案只由 n 的奇偶决定。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。
