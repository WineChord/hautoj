## 题意与输入输出

### 题意摘要

由于结果可能过大，请输出结果对1e9+7取模后的值。

### 输入要点

第一行一个正整数ｎ（$1 \le n$&lt;=1e5）代表序列长度；

第二行为n个整数代表序列，每个数小于1e4。

### 输出要点

一行一个正整数，代表所有子序列和的和。

### 题面提示

对于样例中的序列有以下子序列：

序列 {1} 的和为1

序列 {3} 的和为3

序列 {4} 的和为4

序列 {1,3} 的和为4

序列 {1,4} 的和为5

序列 {3,4} 的和为7

序列 {1,3,4} 的和为8

所以所有子序列和的和为32

## 零基础先修

- C++ 的负数取模仍可能为负；减法后常用 (x - y + mod) % mod。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 把条件翻译成分支或线性扫描，不引入题目没有要求的额外状态。
3. 核心处理：对任意一个位置，选择它以后，其余 n-1 个位置都可独立选择或不选，所以该元素恰好出现在 2\^(n-1) 个子序列中。所有子序列元素和的总和等于序列总和乘 2\^(n-1)，全程对 $10^9$+7 取模。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 扫描前保存的信息与已经处理的输入完全对应。
- 每读入一个元素，分支覆盖其全部情况并正确更新累计状态。
- 扫描结束时所有输入恰好处理一次，累计状态即为所求。

## 复杂度

O(n+log n) 时间、O(1) 额外空间

## 易错点

- 减法结果可能为负，必要时先加模数再取模。
- 按上界估算中间量，相关变量不要退回 int。
