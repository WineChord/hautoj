## 题意与输入输出

### 题意摘要

根据给定输入，如果A获胜输出A，如果B获胜输出B

### 输入要点

输入一个正整数N（$N < 100$）

### 输出要点

如果A获胜输出A，如果B获胜输出B

### 题面提示

对于样例：一开始该A取石子，很显然A可以取走1颗,2颗或4颗，如果A选择拿2颗，那么会剩下3颗，这个时候B无论拿1颗石子还是2颗石子，A都可以取走最后1颗赢得游戏

## 零基础先修

- 先找终止态和每步改变的量，再判断奇偶、不变量或必胜/必败状态。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 把条件翻译成分支或线性扫描，不引入题目没有要求的额外状态。
3. 核心处理：2 的幂模 3 只会在 1、2 间交替。若石子数是 3 的倍数，无论当前 玩家取哪个合法幂，都会把非 3 倍数局面留给对手；若不是 3 的倍数， 当前玩家可按余数取 1 或 2，把 3 的倍数留给对手。于是 3 的倍数为 必败态，先手 A 在其他局面必胜。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 扫描前保存的信息与已经处理的输入完全对应。
- 每读入一个元素，分支覆盖其全部情况并正确更新累计状态。
- 扫描结束时所有输入恰好处理一次，累计状态即为所求。

## 复杂度

O(1) 时间、O(1) 空间
