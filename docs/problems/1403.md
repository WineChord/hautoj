## 题意与输入输出

**题意摘要**：你的任务是，判断当有N（N&lt;1*10^6)个硬币时，谁会获胜。

**输入要点**：一个整数N（N &lt; 10^6）。

**输出要点**：如果雷顿获胜，输出。 Hershel Layton will win. 否则： Hershel Layton will lose.

**题面提示**：当有三个硬币时，无论雷顿抓取几个，布洛涅夫都可以拿到最后一个硬币。

## 零基础先修

- 先找终止态和每步改变的量，再判断奇偶、不变量或必胜/必败状态。
- C++ 的负数取模仍可能为负；减法后常用 (x - y + mod) % mod。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 把条件翻译成分支或线性扫描，不引入题目没有要求的额外状态。
3. 核心处理：每次可取 1 或 2 枚，3 的倍数是必败态：无论先手取多少，后手 都能补成一轮合计 3。非 3 的倍数先取余数，即可把 3 的倍数留给 对手。因此 n%3≠0 时雷顿获胜。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 扫描前保存的信息与已经处理的输入完全对应。
- 每读入一个元素，分支覆盖其全部情况并正确更新累计状态。
- 扫描结束时所有输入恰好处理一次，累计状态即为所求。

## 复杂度

O(1) 时间、O(1) 空间

## 易错点

- 减法结果可能为负，必要时先加模数再取模。
- 按上界估算中间量，相关变量不要退回 int。
