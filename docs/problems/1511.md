## 题意与输入输出

**题意摘要**：现在给你经过若干次1，2变换后的这n-3个四元组，请还原这个序列.如果有多个答案，请输出字典序最小的答案 。

**输入要点**：样例数T(1&lt;=T&lt;=10) 每个样例第一行输出一个n（7&lt;=n&lt;=200）。 接下来n-3个四元组。

**输出要点**：满足条件的序列（如果有多个答案请输出字典序最小的答案）

## 零基础先修

- 输出不唯一时，要逐条验证长度、取值、互异性、相邻关系或总和等约束。
- set 有序去重，unordered_set 平均 O(1) 查询；先判断是否需要顺序。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 列出状态变量并按题面顺序更新；构造题同时维护每条输出约束。
3. 核心处理：原序列端点只出现在一个四元组中，次端点出现两次，第三个位置 出现三次，内部位置出现四次。选择两个频次为 1 的数中较小者作为 p1，可在正序与逆序中取得字典序更小者；其唯一四元组内其余三个数 按全局频次 2、3、4 排成 p2,p3,p4。之后每次寻找尚未使用且包含 最近三个数的四元组，第四个数就是下一项。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 构造只使用题目允许的元素与操作。
- 每一步都维持长度、取值、相邻关系或总和等约束。
- 结束时规模达到要求，因此输出是完整合法答案。

## 复杂度

每组 O(n²) 时间、O(n) 空间
