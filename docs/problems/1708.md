## 题意与输入输出

**题意摘要**：根据给定输入，一行一个正整数代表由n对括号可以构造出多少种不同的合法对称括号序列。

**输入要点**：一行一个正整数t，代表有t组数据； 随后t行每行一个正整数n，代表你有n对括号可以使用； 测试数据保证t组数据n的和&lt;=1e6。

**输出要点**：一行一个正整数代表由n对括号可以构造出多少种不同的合法对称括号序列。

**题面提示**：按照题目描述的规则，由3对括号构成的合法的对称序列共有以下三组： ()()() ((())) (()())

## 零基础先修

- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。

- string 可按下标访问字符；注意空串、大小写、标点和 getline 与 cin 的衔接。
