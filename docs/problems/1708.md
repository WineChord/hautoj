## 题意与输入输出

### 题意摘要

根据给定输入，一行一个正整数代表由n对括号可以构造出多少种不同的合法对称括号序列。

### 输入要点

一行一个正整数t，代表有t组数据；

随后t行每行一个正整数n，代表你有n对括号可以使用；

测试数据保证t组数据n的和&lt;=1e6。

### 输出要点

一行一个正整数代表由n对括号可以构造出多少种不同的合法对称括号序列。

### 题面提示

按照题目描述的规则，由3对括号构成的合法的对称序列共有以下三组：

()()()

((()))

(()())

## 零基础先修

- 用一句话定义 dp 状态，再写转移来源、初值、遍历顺序和最终答案。
- C++ 的负数取模仍可能为负；减法后常用 (x - y + mod) % mod。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 定义 dp 状态、初值和遍历顺序，只从合法状态转移。
3. 核心处理：设 f\[i\] 为使用 i 对括号、按题目规则能够构造出的序列数。在已有序列外包一对括号会从 f\[i-1\] 转移；在左右各添加一对则从 f\[i-2\] 转移，因此 $f_{i}=f$\[i-1\]+f\[i-2\]。预处理到所有测试中的最大 n，并对 $10^9$+7 取模。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。
- 转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。
- 处理完全部输入后，目标状态正好对应题目要求。

## 复杂度

预处理 O(max n) 时间、O(max n) 空间；每组查询 O(1)

## 易错点

- 初值不能默认全部可达；0/1 背包必须倒序遍历容量。
- 减法结果可能为负，必要时先加模数再取模。
- 按上界估算中间量，相关变量不要退回 int。
