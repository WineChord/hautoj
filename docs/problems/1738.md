## 题意与输入输出

**题意摘要**：例如{1，2，2}的子序列是{1}，{2}，{3}，{1，2}，{1，3}，{2，3}，{1，2，3} ，至于空集合由于元素异或值是0所以不影响结果，无论是否算上空集合。

**输入要点**：第一行一个整数n 第二行n个整数,s1,s2,...,si,....sn代表小圆面临的n个魔法值。 数据范围 1&lt;= n &lt;= 1e5,1 &lt;= si &lt;= 1e9 .

**输出要点**：一个整数，集合所有子序列的异或的和模以998244353

**题面提示**：样例解释 样例子序列有{1}，{2}，{3}，{1，2}，{1，3}，{2，3}，{1，2，3}， 每个子序列的异或值分别为1，2，3，3，2，1，0，所以答案就是1 + 2 + 3 + 3 + 2 + 1 = 12 .

## 正确性说明

- 扫描前保存的信息与已经处理的输入完全对应。
