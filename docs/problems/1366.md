3. 核心处理：第一句已经说明“题目是假的”。输出要求不是运行图片里的 C 程序， 而是原样输出六个汉字“图片中的代码”。这是固定输出题，图片、辛普森 积分和球面公式都是干扰信息；不要多加引号或解释。
