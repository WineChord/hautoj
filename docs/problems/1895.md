## 题意与输入输出

### 题意摘要

根据给定输入，对于每个询问输出一行，该行包含一个整数，表示 1 \~ n中”神奇的数字“ 个数

### 输入要点

第一行包含一个数 T （$1 \le T \le 1000$），表示询问数

接下来 T 行 ， 每行包含一个整数 n（$1 \le n \le 1000$）；

### 输出要点

对于每个询问输出一行，该行包含一个整数，表示 1 \~ n中”神奇的数字“ 个数

### 题面提示

请认真阅读题干，其实本题才是签到题

4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。
