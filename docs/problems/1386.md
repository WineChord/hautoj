## 题意与输入输出

### 题意摘要

根据给定输入，对每行输入，输出其对应的加密结果，单独占一行。

### 输入要点

第一行正整数N，接下来N（$0 < N \le 52$） 行字母 c （c 可以为大写，也可以为小写）

### 输出要点

对每行输入，输出其对应的加密结果，单独占一行。

### 题面提示

每行输入的行尾会有一个回车字符，例如：8，其实是 8'\\n'

## 零基础先修

- string 可按下标访问字符；注意空串、大小写、标点和 getline 与 cin 的衔接。
