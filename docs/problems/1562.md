## 思路推导

1. 确认题目没有输入，程序无需声明或读取测试数据。
2. 按题面关系完成常数处理：四道选择题依次为 A、C、D、A。把题面给出的程序原样编译运行， 其七个字符输出为 lcltql!；本题只要求输出结论，不应附加空格或 解释。
3. 原样输出结果，逐字核对字符、标点和末尾换行。
4. 程序不依赖输入规模，不需要循环或额外数据结构。

## 正确性说明

- 题目没有输入，所有合法运行面对同一个固定任务。
- 程序输出的常量与题目要求逐字一致。
- 因此程序在所有运行中都得到正确结果。
