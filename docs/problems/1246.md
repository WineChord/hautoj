## 题意与输入输出

### 题意摘要

根据给定输入，Print single integer — the last digit

### 输入要点

$$
The single line of input contains one integer n (0 \le n \le 10^9).
$$

### 输出要点

Print single integer — the last digit

## 零基础先修

- C++ 的负数取模仍可能为负；减法后常用 (x - y + mod) % mod。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 把条件翻译成分支或线性扫描，不引入题目没有要求的额外状态。
3. 核心处理：只关心 1378\^n 的个位，即 8\^n 的个位。正指数时按 8,4,2,6 周期 4 循环；$n=0$ 按定义结果为 1。可用数组按 n%4 查询， 其中余数 0 对应 6。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 扫描前保存的信息与已经处理的输入完全对应。
- 每读入一个元素，分支覆盖其全部情况并正确更新累计状态。
- 扫描结束时所有输入恰好处理一次，累计状态即为所求。

## 复杂度

O(1) 时间、O(1) 空间

## 易错点

- 减法结果可能为负，必要时先加模数再取模。
- 按上界估算中间量，相关变量不要退回 int。
