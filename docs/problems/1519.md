## 题意与输入输出

**题意摘要**：请帮助小EF求出其中第 k 大的分数

**输入要点**：第一行包含两个整数 n 和 k 第二行包含 n 个质数 pi (1≤n≤1000,1≤k≤1000,2≤pi≤1000)

**输出要点**：输出一个分数表示答案

**题面提示**：样例解释： 2得到的分数有1/2 3得到的分数有1/3， 2/3 5得到的分数有1/5， 2/5， 3/5， 4/5 分数排序后有：4/5， 2/3， 3/5， 1/2， 2/5， 1/3， 1/5 所以第3大分数是3/5

## 零基础先修

- 排序后应利用相邻性、前缀性质或单调性；并列时按题意添加次关键字。
- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。
- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 按主关键字排序；若存在并列规则，再加入次关键字。
3. 核心处理：第k大分数（简单版）暴力基础题 先把所有的形成的分数保存起来，然后按从大到小快排一遍，最后输出第 个即可kkk C++版代码
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

通常为 O(n log n)，主要来自排序

## 易错点

- 比较器必须满足严格弱序；相等时处理题目指定的次关键字。
- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
- 检查 0/1 起下标、n = 1、首尾元素和数组容量。
- 按上界估算中间量，相关变量不要退回 int。
