## 题意与输入输出

**题意摘要**：根据给定输入，对每行输入，输出其对应那个的八进制数，单独占一行。

**输入要点**：第一行一个正整数N（0&lt; N &lt;= 1024） 接下来 N 行正二进制数M（0&lt;= M &lt;= 1111111111）。

**输出要点**：对每行输入，输出其对应那个的八进制数，单独占一行。

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：数学（二）思路：从M的个位开始，每次取三位，转化成8进制数。举例： M=1001010111第一步： 取出111， M=1001010， 结果为7第二步：取出010， M=1001， 结果为27第三步：取出001， M=1， 结果为127第四步：取出1， M=0（M=0则结束）， 结果为1127最终结果为：1127参考代码
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度
