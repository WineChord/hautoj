## 题意与输入输出

### 题意摘要

一天汉斯教授收到了一个陌生的邮件，发现有绑匪绑架了他的孙女并且他们在邮件中留下了一些线索，汉斯教授需要根据这些线索救出他的孙女。线索是一个很大的正整数，数字越大线索的有效性就越大，现在汉斯教授需要重新排列这些线索并让它们首尾相连后组成的总线索的有效性尽量的大，请问有效性最大的总线索是多少？

### 输入要点

第一行输入一个正整数n，第二行输入n个正整数ai($1 \le i \le n$)。

### 输出要点

输出最大的组合数字。

### 题面提示

$n \le 30,ai$&lt;=1e31（不含前导0）

（输入的数据很大，考虑用字符串储存）

## 零基础先修

- string 可按下标访问字符；注意空串、大小写、标点和 getline 与 cin 的衔接。
- 把过程转成公式前，先在小数据上验证，再证明公式覆盖所有合法情况。
- 若中间乘积可能超过约 9e18，就要考虑 \_\_int128 或高精度。
- 排序后应利用相邻性、前缀性质或单调性；并列时按题意添加次关键字。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 按主关键字排序；若存在并列规则，再加入次关键字。
3. 核心处理：最大数也就是最大的约数 }
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

通常为 O(n log n)，主要来自排序

## 易错点

- 避免下标越界；getline 前要处理上一次格式化读入留下的换行。
- 乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。
- 比较器必须满足严格弱序；相等时处理题目指定的次关键字。
