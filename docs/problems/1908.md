## 题意与输入输出

### 题意摘要

对于每组询问，给定一个整数 n，求 n个圆（半径可以不同）可以分割的最大区域数为多少？

### 输入要点

第一行包含一个正整数 t($1 \le t \le 103$)------测试用例的数量。

接下来一行，t 个用空格隔开的整数 n($0 \le n \le 106$)，依次表示每组询问给定的圆形个数。

### 输出要点

一行，对于每次询问输出一个整数表示结果，每个整数之间用空格隔开
