## 题意与输入输出

**题意摘要**：根据给定输入，卷卷赢输出"火锅！" 聚聚赢输出"牛排!" （输出不带引号）

**输入要点**：第一行一个整数 n ( 1 &lt;= n &lt;= 100 )，表示石子堆数 接下来一行 n 个数，第 i 个数为 ai ( 1 &lt;= ai &lt;= 1e9 )，意义如上所述

**输出要点**：卷卷赢输出"火锅！" 聚聚赢输出"牛排!" （输出不带引号）

**题面提示**：学会 CTRL + C 和 CTRL + V

## 零基础先修

- 先找终止态和每步改变的量，再判断奇偶、不变量或必胜/必败状态。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：每次操作一定恰好拿走一颗石子；游戏最终会拿完全部石子，所以总 步数就是石子总数。总数为奇数时先手拿最后一颗并获胜，否则后手获胜。 只累计奇偶性即可，避免大数求和。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。
