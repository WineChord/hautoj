## 题意与输入输出

**题意摘要**：他希望你能帮他找到满足条件的最小正整数b，并且用c/b来表示这个小数0.a。

**输入要点**：多样例测试 第一行输入一个整数T（1&lt;=T&lt;=10^5） 接下来的n行每行输入一个小数a (0&lt;a&lt;10^18, a不含前导0)

**输出要点**：输出c/b来表示这个小数（b为满足条件的最小正整数）

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。
- std::gcd(a, b) 使用欧几里得算法；同时检查 0 值、符号和 lcm 乘法溢出。
- 先确定分隔符、字符类别与多位数边界，再逐段转换。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：把输入当字符串，取小数点后的数字作为分子 a，分母是 10^(小数位数)。用 gcd(a,denominator) 同除，所得分母最小；字符串 方式还能准确保留小数位数而不受浮点误差影响。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

每组 O(小数位数+log 值域) 时间、O(小数位数) 空间

## 易错点

- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
- 按上界估算中间量，相关变量不要退回 int。
