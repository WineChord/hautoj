## 题意与输入输出

**题意摘要**：给出一个数字 n 要求你分解他的质因数 ，且分解出来的质因数要求个数最少。

**输入要点**：输入包含 1 行 输入一个数字 n （1 &lt;= n &lt;= 1e6）

**输出要点**：输出包含一行 输出分解出来的 n 的质因数

**题面提示**：18 = 2 * 3 * 3

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：分解质因数 模拟操作即可 #include&lt;bits/stdc++.h&gt;
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。

## 复杂度

通常为 O(n)；若循环嵌套或迭代范围不同，应按代码重新核算

## 易错点

- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
- 按上界估算中间量，相关变量不要退回 int。
