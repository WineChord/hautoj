## 题意与输入输出

**题意摘要**：根据给定输入，输出Choice能带走的糖果的最大总价值，保留1位小数。输出占一行。

**输入要点**：输入多组数据。 每组第一组数据输入n，w.（1 &lt;= n &lt;= 1000, 1 &lt;= w &lt;= 10000） 接下来n行每行输入pi，mi代表第i种糖果的价格和数量。（1 &lt;= pi,mi &lt;= 1e4）

**输出要点**：输出Choice能带走的糖果的最大总价值，保留1位小数。输出占一行。

## 零基础先修

- 需要证明局部选择能延伸到全局最优，常用交换论证或下界与构造相遇。
- 排序后应利用相邻性、前缀性质或单调性；并列时按题意添加次关键字。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 按主关键字排序；若存在并列规则，再加入次关键字。
3. 核心处理：同一种糖果每颗价值相同，为 pi/mi。问题就是按单位价值做“可拆分 背包”：把所有种类按单颗价值从高到低排序，依次拿 min(剩余容量,mi) 颗，容量用完即停止。交换论证：若方案中拿了较便宜 的一颗却漏掉较贵的一颗，交换后价值只会增加，所以该贪心最优。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 每一步选择不占用额外未来资源，并达到当前可证明的最优边界。
- 任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。
- 反复交换即可得到与算法相同的最优解，所以算法全局最优。

## 复杂度
