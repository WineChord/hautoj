## 题意与输入输出

### 题意摘要

根据给定输入，输出【欢】的感受。

### 输入要点

输入一个整数为【欢】的情感层数n（$1 \le n \le 100$）。

### 输出要点

输出【欢】的感受。

## 零基础先修

- string 可按下标访问字符；注意空串、大小写、标点和 getline 与 cin 的衔接。
- 输出不唯一时，要逐条验证长度、取值、互异性、相邻关系或总和等约束。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 列出状态变量并按题面顺序更新；构造题同时维护每条输出约束。
3. 核心处理：第 i 层从 1 开始，奇数层输出 I hate，偶数层输出 I love； 最后一层后接 it，其余层后接 that。严格控制空格即可。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 构造只使用题目允许的元素与操作。
- 每一步都维持长度、取值、相邻关系或总和等约束。
- 结束时规模达到要求，因此输出是完整合法答案。

## 复杂度

O(n) 时间、O(1) 空间

## 易错点

- 避免下标越界；getline 前要处理上一次格式化读入留下的换行。
