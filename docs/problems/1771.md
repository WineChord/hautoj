## 题意与输入输出

**题意摘要**：根据给定输入，输出至少多少次操作后存在一种排序使得剩下的数排序后，在数值上严格递增。

**输入要点**：第一行给出 t （ 1 &lt;= t &lt;= 1000 ） 接下来 t 组，每组包括两行，每组的第一行给出一个 n （ 1 &lt;= n &lt;= 50 ），代表数的数量。第二行给出 数值 ai （ 0 &lt; ai &lt;= 10000 ）。

**输出要点**：输出至少多少次操作后存在一种排序使得剩下的数排序后，在数值上严格递增。

## 零基础先修

- set 有序去重，unordered_set 平均 O(1) 查询；先判断是否需要顺序。
- 需要证明局部选择能延伸到全局最优，常用交换论证或下界与构造相遇。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 确定局部选择，并用交换论证或下界说明它不会损失最优解。
3. 核心处理：最后能严格递增等价于“剩余元素互不相同”。设 n 个数中有 u 个 不同值，则至少要删掉 d=n-u 个重复副本。一次恰好删两个数，所以 至少 ceil(d/2) 次；若 d 为奇数，最后一次顺带删掉一个目前唯一的数 也不会制造重复，因而这个下界总能达到。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 每一步选择不占用额外未来资源，并达到当前可证明的最优边界。
- 任意最优解若首个选择不同，都可交换为本算法的选择而不使答案变差。
- 反复交换即可得到与算法相同的最优解，所以算法全局最优。

## 复杂度

每组 O(n log n) 时间、O(n) 空间
