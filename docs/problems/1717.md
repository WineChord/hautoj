## 题意与输入输出

### 题意摘要

现给出小m的初始华丽值n，请输出使华丽值变为0的方案数。由于方案数可能过多，所以请对最终答案取模1e9+7。

### 输入要点

一个正整数n。(n &lt;= 1e5)

### 输出要点

一个整数。

## 零基础先修

- 用一句话定义 dp 状态，再写转移来源、初值、遍历顺序和最终答案。
- C++ 的负数取模仍可能为负；减法后常用 (x - y + mod) % mod。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 定义 dp 状态、初值和遍历顺序，只从合法状态转移。
3. 核心处理：设 dp\[i\] 为华丽值 i 变为 0 的方案数。按题目允许的两种第一步，后续分别进入 i-1 与 floor(i/2)，因此 $dp_{i}=dp$\[i-1\]+dp\[floor(i/2)\]。从小到大预处理并对 $10^9$+7 取模，答案为 dp\[n\]。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 状态保存当前阶段所需的全部信息，初始状态与空前缀或空选择一致。
- 转移枚举所有合法来源，因此不漏解；取最优值时也不会保留劣解。
- 处理完全部输入后，目标状态正好对应题目要求。

## 复杂度

O(n) 时间、O(n) 空间

## 易错点

- 初值不能默认全部可达；0/1 背包必须倒序遍历容量。
- 减法结果可能为负，必要时先加模数再取模。
- 按上界估算中间量，相关变量不要退回 int。
