## 题意与输入输出

**题意摘要**：现给出小m的初始华丽值n，请输出使华丽值变为0的方案数。由于方案数可能过多，所以请对最终答案取模1e9+7。

**输入要点**：一个正整数n。(n &lt;= 1e5)

**输出要点**：一个整数。

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。
- 用一句话定义 dp 状态，再写转移来源、初值、遍历顺序和最终答案。
- 明确 0/1 起下标、合法范围、首尾元素和扫描过程中保存的信息。

## 易错点

- 检查 gcd/lcm 的 0 值、负数和乘法溢出。
- 初值不能默认全部可达；0/1 背包必须倒序遍历容量。
- 检查 0/1 起下标、n = 1、首尾元素和数组容量。
- 按上界估算中间量，相关变量不要退回 int。
