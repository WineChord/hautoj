## 题意与输入输出

**题意摘要**：美雪给葵一个整数 x 。葵的任务是找出任意一个整数y，使得gcd(x,y)+y最大。(1&lt;=y&lt;=x)

**输入要点**：一个整数x。（1&lt;=x&lt;=500000）

**输出要点**：gcd(x,y)+y的最大值。

**题面提示**：&#91;图片：https://acm.haut.edu.cn/upload/acm.haut.edu.cn/image/20241116/20241116175833_18328.png&#93;

## 零基础先修

- 常用整除、gcd/lcm、质数与同余；乘法前先估算是否需要 long long 或 __int128。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 从定义推导公式或不变量，并用小数据验证边界、奇偶与整除关系。
3. 核心处理：君と彼女と彼女の恋 ∵ y 最大可以等于 x ∴ gcd(x,y) 最大 = x 直接输出 2∗x 即可
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 推导把原过程转换为等价的公式或不变量。
- 算法直接计算该等价量，并使用足够宽的数据类型处理边界。
- 因此计算结果就是题目定义的答案。
