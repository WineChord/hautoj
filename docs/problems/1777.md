## 题意与输入输出

**题意摘要**：根据给定输入，输出 t 行，每行输出符合题目要求的一种答案，如果存在多种答案，输出任意一种即可。如果无解，输出 k 个 0 即可。

**输入要点**：第一行给出一个 t （ 1 &lt;= t &lt;=1000 ）,代表有 t 组询问。 每组包括两个数 n 和 k。 （ 1 &lt;= n &lt;=1e9, 1 &lt;= k &lt;= 100 ）

**输出要点**：输出 t 行，每行输出符合题目要求的一种答案，如果存在多种答案，输出任意一种即可。如果无解，输出 k 个 0 即可。

## 零基础先修

- 输出不唯一时，要逐条验证长度、取值、互异性、相邻关系或总和等约束。
- 把过程转成公式前，先在小数据上验证，再证明公式覆盖所有合法情况。
- 只关心奇偶时可化为 x % 2；和的奇偶等于各项奇偶的异或。

## 思路推导

1. 按输入说明读取数据，并用最小样例手算一次，确认每个变量的含义。
2. 列出状态变量并按题面顺序更新；构造题同时维护每条输出约束。
3. 核心处理：正整数按奇偶只可能用 1 或 2 作为前 k-1 项。先尝试 k-1 个 1， 若末项 n-k+1 为正奇数就成立；否则尝试 k-1 个 2，若末项 n-2(k-1) 为正偶数就成立。两种都不行时按题意输出 k 个 0。
4. 按题目要求输出，并检查最小值、最大值、重复值、单元素和格式边界。

## 正确性说明

- 构造只使用题目允许的元素与操作。
- 每一步都维持长度、取值、相邻关系或总和等约束。
- 结束时规模达到要求，因此输出是完整合法答案。

## 复杂度

每组 O(k) 时间、O(1) 额外空间

## 易错点

- 样例只是一个合法答案；本地检查约束，不要逐字比对。
- 乘积使用足够宽的数据类型；除法前处理除数为 0 和整数截断。
- 按上界估算中间量，相关变量不要退回 int。
